## Step 1: map
Kind: read

Arrays have their own `map`, like the one on `Option` in the last lesson, and it takes a closure too.
It calls the closure on each element and gives back a new array of the results.
Line 3 doubles each price, and line 4 turns each one into a string, so `labels` is a `string[]`.
Neither changes `prices`, which line 7 prints as it was.
Press Run.

```lugha
fun main() {
    let prices = [3, 5, 8];
    let doubled = prices.map(fun(p) = p * 2);
    let labels = prices.map(fun(p) = "{p} coins");
    println(doubled);
    println(labels);
    println(prices);
}
```

Output:

```text
[6, 10, 16]
["3 coins", "5 coins", "8 coins"]
[3, 5, 8]
```

## Step 2: filter
Kind: read

`filter` also takes a closure, one that returns a `bool`, and keeps the elements for which it's `true`, in order, in a new array.
Line 3 keeps the even numbers.
`filter` and `map` both give back arrays, so one can follow the other: line 5 keeps the evens, then squares them.

```lugha
fun main() {
    let numbers = [1, 2, 3, 4, 5, 6];
    let evens = numbers.filter(fun(n) = n % 2 == 0);
    println(evens);
    println(numbers.filter(fun(n) = n % 2 == 0).map(fun(n) = n * n));
}
```

Output:

```text
[2, 4, 6]
[4, 16, 36]
```

## Step 3: fold
Kind: read

To turn a whole array into one value, use `fold`.
It starts from the value you give it, and calls its closure with the result so far and each element in turn, left to right.
Line 3 starts from `0` and adds each number.
Line 4 starts from the first number and keeps the larger of the two each time.
Press Run.

```lugha
fun main() {
    let numbers = [4, 9, 2, 7];
    let total = numbers.fold(0, fun(sum, n) = sum + n);
    let largest = numbers.fold(numbers[0], fun(best, n) = if n > best { n } else { best });
    println(total);
    println(largest);
}
```

Output:

```text
22
9
```

## Step 4: any and all
Kind: read

`any` and `all` take the same kind of closure as `filter`, but give back one `bool`.
`any` on line 3 is `true` because one age, `17`, is under 18, and it stops looking there.
`all` on line 4 is `false` because of that same age, and on line 5 it's `true`, since every age is above `0`.

```lugha
fun main() {
    let ages = [34, 17, 52];
    println(ages.any(fun(a) = a < 18));
    println(ages.all(fun(a) = a < 18));
    println(ages.all(fun(a) = a > 0));
}
```

Output:

```text
true
false
true
```

## Step 5: Sorting
Kind: fix (start gives E0419 "`Person` doesn't satisfy `Ord`", help "give `Person` a `fun cmp(self, other: Person): Ordering` to order it")

`sort` gives back a new array in ascending order, for numbers and for strings, as lines 4 and 5 show.
Line 7 sorts people, and there's no order for two `Person`s to follow.

That's E0419, "`Person` doesn't satisfy `Ord`".
Its help suggests giving `Person` an order of its own, which comes in chapter 8.
`sort_by` takes the rule as a closure instead, one that says whether `a` comes before `b`.
It gives back a new array too, and people of the same age keep their order:

```lugha {7}
struct Person { name: string, age: i64 }

fun main() {
    println([3, 1, 2].sort());
    println(["pear", "fig", "apple"].sort());
    let people = [Person { name: "Ann", age: 31 }, Person { name: "Ben", age: 25 }];
    println(people.sort_by(fun(a, b) = a.age < b.age));
}
```

Sort the people by age on line 7, or press Solve.

Start:

```lugha
struct Person { name: string, age: i64 }

fun main() {
    println([3, 1, 2].sort());

```

Solution:

```lugha
struct Person { name: string, age: i64 }

fun main() {
    println([3, 1, 2].sort());
    println(["pear", "fig", "apple"].sort());
    let people = [Person { name: "Ann", age: 31 }, Person { name: "Ben", age: 25 }];
    println(people.sort_by(fun(a, b) = a.age < b.age));
}
```

Output (solution):

```text
[1, 2, 3]
["apple", "fig", "pear"]
[Person { name: "Ben", age: 25 }, Person { name: "Ann", age: 31 }]
```
