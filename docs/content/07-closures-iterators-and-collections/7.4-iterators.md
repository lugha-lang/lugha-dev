## Step 1: Iterators
Kind: read

Besides arrays, `for … of` steps through iterators, values that give back one value at a time.
`range(1, 4)` on line 2 gives `1` to `3`, and `chars()` on line 5 gives a string's characters.
`iter()` on line 8 makes an iterator over an array, from its own copy of the array.
Press Run.

```lugha
fun main() {
    for n of range(1, 4) {
        println(n);
    }
    for c of "hé".chars() {
        println(c);
    }
    let it = [10, 20].iter();
    for x of it {
        println(x);
    }
}
```

Output:

```text
1
2
3
h
é
10
20
```

## Step 2: Chaining iterators
Kind: read

Iterators have `map` and `filter` too, and each gives back another iterator, so they line up one after another.
Line 2 takes the numbers from 1 to 9, keeps the multiples of 3 and squares them.
`collect()` at the end puts the results in an array.
`chain` on line 4 gives one iterator's values, then another's.
Press Run.

```lugha
fun main() {
    let squares = range(1, 10).filter(fun(n) = n % 3 == 0).map(fun(n) = n * n).collect();
    println(squares);
    let all = [1, 2].iter().chain([3, 4].iter()).collect();
    println(all);
}
```

Output:

```text
[9, 36, 81]
[1, 2, 3, 4]
```

## Step 3: enumerate
Kind: read

`enumerate()` pairs each value with its position, counting from 0.
Each item it gives has two fields, `i` for the position and `value` for the value, and line 4 reads both.
Press Run.

```lugha
fun main() {
    let names = ["Ann", "Ben", "Cy"];
    for p of names.iter().enumerate() {
        println("{p.i}: {p.value}");
    }
}
```

Output:

```text
0: Ann
1: Ben
2: Cy
```

## Step 4: zip
Kind: read

`zip` walks two iterators side by side and gives tuples, which line 4 takes apart into `name` and `age`.
`names` has three names and `ages` only two numbers.
Will `Cy` be printed?
Press Run.

It isn't: `zip` stops at the end of the shorter one.

```lugha
fun main() {
    let names = ["Ann", "Ben", "Cy"];
    let ages = [31, 25];
    for (name, age) of names.iter().zip(ages.iter()) {
        println("{name} is {age}");
    }
}
```

Output:

```text
Ann is 31
Ben is 25
```

## Step 5: collect, sum, count and find
Kind: read

Some helpers give back one answer instead of another iterator, worked out from every value they pull.
`sum()` and `count()` on lines 3 and 4 add the values up and count them.
`find` on line 5 gives the first value its closure returns `true` for, as an `Option`, since there may be none.
`min`, `max` and `position` on lines 6 to 8 give `Option`s for the same reason.
`collect()` on line 9 is one of them too, and `fold`, `any` and `all` from Array helpers work on iterators as well.
Press Run.

Every line uses the same `scores`, because a helper works on its own copy of the iterator and leaves `scores` as it was.

```lugha
fun main() {
    let scores = [7, 3, 9, 4].iter();
    println(scores.sum());
    println(scores.count());
    println(scores.find(fun(s) = s > 8));
    println(scores.min());
    println(scores.max());
    println(scores.position(fun(s) = s == 9));
    println(scores.filter(fun(s) = s > 5).collect());
}
```

Output:

```text
23
4
Some(9)
Some(3)
Some(9)
Some(2)
[7, 9]
```

## Step 6: Laziness
Kind: read

On an array, `map` runs its closure at once and makes a new array, as in Array helpers.
On an iterator, line 2 only wraps `iter()` with a closure that prints each number it doubles.
Will any `doubling` line come before `made the iterator`?
Press Run.

None does: `map` on an iterator runs nothing yet.
The closure runs only when line 7 pulls values, and `take(2)` pulls two, so `3` is never doubled.
That's why line 8 can start from a range up to a billion, because `take(3)` stops pulling once it has three.

```lugha
fun main() {
    let doubled = [1, 2, 3].iter().map(fun(n: i64): i64 {
        println("doubling {n}");
        n * 2
    });
    println("made the iterator");
    println(doubled.take(2).collect());
    println(range(10, 1000000000).filter(fun(n) = n % 7 == 0).skip(1).take(3).collect());
}
```

Output:

```text
made the iterator
doubling 1
doubling 2
[2, 4]
[21, 28, 35]
```

## Step 7: Custom iterators
Kind: fix (start gives E0205 "struct literal in a condition must be in parentheses", help "wrap it in parentheses: `(Countdown { … })`")

Any type with a method `next(mut self): Option<T>` is an iterator, and `for … of` calls `next` until it gives `None`.
The `next` on lines 4 to 10 makes `Countdown` count down from `n`.
Line 14 loops over a new `Countdown`, written as a struct literal.
Press Run.

`lughac` stops at line 14 with E0205, "struct literal in a condition must be in parentheses".
A `for` header is read like an `if` condition, as in Struct literals in conditions.
Put the literal in parentheses:

```lugha {14}
struct Countdown { n: i64 }

impl Countdown {
    fun next(mut self): Option<i64> {
        if self.n == 0 {
            return None;
        }
        self.n -= 1;
        Some(self.n + 1)
    }
}

fun main() {
    for n of (Countdown { n: 3 }) {
        println(n);
    }
}
```

Wrap line 14's literal in parentheses, or press Solve.

Start:

```lugha

struct Countdown { n: i64 }

impl Countdown {
    fun next(mut self): Option<i64> {
        if self.n == 0 {
            return None;
        }
        self.n -= 1;
        Some(self.n + 1)
    }
}

fun main() {
    for n of (Countdown { n: 3 }) {
        println(n);
    }
}
```

Output (solution):

```text
3
2
1
```

## Step 8: More adapters
Kind: read

A few more adapters work like `map` and `filter`.
`take_while` on line 3 takes values while its closure holds, and stops at the first that fails, the `9`.
`skip_while` on line 4 skips values until that same `9`, and gives everything from it on.
`flat_map` on line 6 turns each value into an iterator of its own and gives their values in turn, here each word's characters.
`bytes()` on line 7 is a source like `chars()` in the first step, and gives a string's bytes as `u8` numbers.
Press Run.

```lugha
fun main() {
    let temps = [3, 5, 9, 4, 8];
    println(temps.iter().take_while(fun(t) = t < 9).collect());
    println(temps.iter().skip_while(fun(t) = t < 9).collect());
    let words = ["ab", "cd"];
    println(words.iter().flat_map(fun(w) = w.chars()).collect());
    println("hi".bytes().collect());
}
```

Output:

```text
[3, 5]
[9, 4, 8]
['a', 'b', 'c', 'd']
[104, 105]
```
