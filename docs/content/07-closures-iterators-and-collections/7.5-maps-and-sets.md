## Step 1: Map literals
Kind: read

A map holds values under keys, written `#{key: value}`.
The `#` tells a map from a block, which `{` alone starts.
`ages` on line 2 is a `Map<string, i64>`.
`ages["ann"]` on line 3 reads a value, and line 4 adds a key by assigning to it.
Line 5 changes a value where it is, with `+=`.
An empty `#{}` takes its type from where it's used, as `[]` does, and line 7 writes it out.
Press Run.

```lugha
fun main() {
    let mut ages = #{"ann": 31, "bo": 40};
    println(ages["ann"]);
    ages["cy"] = 25;
    ages["bo"] += 1;
    println(ages);
    let none_yet: Map<string, i64> = #{};
    println(none_yet);
}
```

Output:

```text
31
#{"ann": 31, "bo": 41, "cy": 25}
#{}
```

## Step 2: Missing keys
Kind: read

`get` on line 3 gives an `Option`: `Some` with the value, or `None` when the key isn't there, as on line 4.
`has` on line 5 only asks whether the key is there.
Line 6 reads a missing key with `[…]`, which panics with `no key "dee" in the map`.
When a key may be missing, use `get` or `has`.
Press Run.

```lugha
fun main() {
    let ages = #{"ann": 31, "bo": 40};
    println(ages.get("ann"));
    println(ages.get("dee"));
    println(ages.has("dee"));
    println(ages["dee"]);
}
```

Output (exit code 101):

```text
Some(31)
None
false
panic: no key "dee" in the map at src/main.la:6:17
```

## Step 3: Iterating a map
Kind: fix (start gives E0442 "`for … of mut` can't change a `Map<string, i64>` in place", help "loop over `m.keys()` and assign `m[k] = …`"; also E0501 on line 4)

A map can be looped over like an array: each entry is a tuple of key and value, in the order the keys were added.
Line 3 loops with `mut`, meaning to double each price where it is.
Press Run.

`lughac` stops at line 3 with E0442: `for … of mut` can't change a map in place, and the E0501 on line 4 follows from it.
Loop over `prices.keys()` instead, and assign each `prices[item]`.
Then a plain `for (item, price) of prices` on line 6 reads the entries, and `values()` on line 9 gives the values in the same order.

```lugha {3,4,6,7,8,9}
fun main() {
    let mut prices = #{"tea": 3, "milk": 2};
    for item of prices.keys() {
        prices[item] *= 2;
    }
    for (item, price) of prices {
        println("{item}: {price}");
    }
    println(prices.values());
}
```

Change lines 3 and 4, or press Solve.

Start:

```lugha

        price *= 2;

}
```

Solution:

```lugha

        prices[item] *= 2;
    }
    for (item, price) of prices {
        println("{item}: {price}");
    }
    println(prices.values());
}
```

Output (solution):

```text

milk: 4
[6, 4]
```

## Step 4: Sets
Kind: read

A set holds distinct values, written `#{a, b}` without colons.
`has` on line 3 asks whether a value is in it, and `insert` on lines 4 and 5 returns `true` only when the value is new.
`remove` on line 6 returns `true` when there was something to remove.
Maps have `remove` too, giving back the removed value as an `Option` on line 9, and both have `clear`, which empties them.
Press Run.

```lugha
fun main() {
    let mut seen = #{"red", "blue"};
    println(seen.has("red"));
    println(seen.insert("green"));
    println(seen.insert("red"));
    println(seen.remove("blue"));
    println(seen);
    let mut ages = #{"ann": 31, "bo": 40};
    println(ages.remove("bo"));
    ages.clear();
    println(ages);
}
```

Output:

```text
true
true
false
true
#{"red", "green"}
Some(40)
#{}
```

## Step 5: Set operations
Kind: read

`union` on line 4 gives the values in either set.
`intersect` on line 5 keeps the ones in both, and `minus` on line 6 keeps the ones in `a` that aren't in `b`.
Sets and maps keep the order values were added, and line 7 compares two sets written in different orders.
Will it print `true`?
Press Run.

It does: `==` compares the values and ignores their order, and line 8 shows the same for two maps.

```lugha
fun main() {
    let a = #{1, 2, 3};
    let b = #{2, 3, 4};
    println(a.union(b));
    println(a.intersect(b));
    println(a.minus(b));
    println(#{1, 2} == #{2, 1});
    println(#{"a": 1, "b": 2} == #{"b": 2, "a": 1});
}
```

Output:

```text
#{1, 2, 3, 4}
#{2, 3}
#{1}
true
true
```

## Step 6: collect_map and collect_set
Kind: read

An iterator can end in a set or a map instead of an array.
`collect_set()` on line 3 keeps each name once.
`collect_map()` on line 5 needs tuples of key and value, and when a key comes twice, its later value wins, so `ann` ends up with `3`.
Press Run.

```lugha
fun main() {
    let names = ["ann", "bo", "ann"];
    println(names.iter().collect_set());
    let scores = [("ann", 1), ("bo", 2), ("ann", 3)];
    println(scores.iter().collect_map());
}
```

Output:

```text
#{"ann", "bo"}
#{"ann": 3, "bo": 2}
```

## Step 7: Key types
Kind: fix (start gives E0441 "a map's keys can't hold a float: `f64`", help "`NaN != NaN`, so a float key could never be found again; use an integer")

Keys can be integers, strings, `bool`s, `char`s and the types built from them, but never a float.
Line 2 uses cup sizes in litres as keys.
Press Run.

`lughac` stops at line 2 with E0441, "a map's keys can't hold a float".
Its help gives the reason: `NaN != NaN`, so a float key could never be found again.
Use whole millilitres instead:

```lugha {2,3}
fun main() {
    let cups = #{250: "small", 500: "large"};
    println(cups[500]);
}
```

Solution:


```text

```
