# 1.1 Hello, world

## Objectives

After this lesson the learner can:

- Write `fun main()`, run it, and print with `println`.
- Return an exit code with `fun main(): i32`.
- Write comments: `//`, `/* … */` (they nest), and `/** … */` doc comments. [L279–285]
- Know every statement ends with `;`, since newlines mean nothing. [L279]
- Surprises: block comments nest; `main` can only be `fun main()` or `fun main(): i32`. [L281, L1417]

## Step 1: The main function
Kind: read

A Lugha program starts at `main`, and this one has a single line: `println` prints what it's given, then a newline.
Line 1 is a doc comment, `/** … */`, which editors show beside the item that follows it.
Press Run.

The output ends with the exit code, 0.
This `main` returns nothing, so the program ends with 0 when it reaches the end of `main`.

```lugha
/** Says hello. */
fun main() {
    println("Hello, world");
}
```

Output:

```text
Hello, world
```

## Step 2: Semicolons
Kind: fix (start gives E0201 "expected `;`, found identifier `println`")

Now there are two `println` lines, and line 2 has no semicolon.
Will the line break after it do instead?
Decide, then press Run.

If you said no, you've got it.
If you expected it to run, you were expecting a line break to end a statement.
Lugha reads a line break the same as a space, so a statement ends at its `;`, not at the end of a line:

```lugha {2}
fun main() {
    println("one");
    println("two");
}
```

Add the `;` on line 2 and run again.
It's also why two statements can share one line, as long as each has its `;`.

Start:

```lugha
fun main() {
    println("one")
    println("two");
}
```

Solution:

```lugha
fun main() {
    println("one");
    println("two");
}
```

Output (solution):

```text
one
two
```

## Step 3: Comments
Kind: read

`//` turns the rest of a line into a comment, as on line 2, and `/* … */` can cover several lines.
In Lugha a `/*` comment can hold another one: line 3 opens a comment, and line 4 opens a second inside it.
Which of `two`, `three`, `four` and `five` will print?
Run it and see.

Only `five`.
Block comments nest, so the `*/` on line 4 closes only the inner comment, and the outer one runs on to line 5.
If you expected `four`, or an error at the `*/` on line 5, you were expecting the first `*/` to close everything before it.
So you can comment out code that already has a comment in it.

```lugha
fun main() {
    println("one"); // a comment to the end of the line
    /* println("two");
       /* println("three"); */
       println("four"); */
    println("five");
}
```

Output:

```text
one
five
```

## Step 4: Exit codes
Kind: fix (start runs, prints the same line, exits with 1)

`main` can also return an `i32`, which becomes the program's exit code.
Here line 3, `1`, has no `;` because it isn't a statement: the last expression in a body, written without a `;`, is the value the body gives back.
Press Run, and the program exits with code 1, which whatever ran it reads as a failure.

```lugha {3}
fun main(): i32 {
    println("checking the input");
    0
}
```

Change line 3 to `0` and run again, or press Solve.
`main` comes in only these two forms, and `lughac` refuses any other with E0304.
Return nothing and the program ends with 0, or return an `i32` and choose the code yourself.

Start:

```lugha
fun main(): i32 {
    println("checking the input");
    1
}
```

Solution:

```lugha
fun main(): i32 {
    println("checking the input");
    0
}
```

Output (start, exit code 1; solution, exit code 0):

```text
checking the input
```
