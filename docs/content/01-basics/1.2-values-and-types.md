# 1.2 Values and types

## Objectives

After this lesson the learner can:

- Name the built-in types: `i8 … i64`, `u8 … u64`, `f32`, `f64`, `bool`, `char`, `string`, and read an integer type's limits with `MIN` and `MAX`. [L526–540, L965]
- Write literals: `1_000_000`, `0xFF`, `0b1010`, `0o17`, `2.0e5`, `'a'`, `"tab:\tend"`, `true`. [L300–325, L717]
- Know how floats print: always with a `.` (`2.0`), and with an exponent from `1e16`. [L1124]
- Surprises:
  - `2e5` is an error: a float needs a digit on both sides of its `.` (`2.0e5`). [L314]
  - A leading zero is still decimal: `017` is seventeen (warning W0107). [L313]
  - Strings can't span lines; write `\n`. [L321]

(Moved out after the reader check: "there's no null" goes to 4.4 Option, where a missing value can be shown; "a `u8` prints as a number" was cut, since no test reader expected otherwise.)

## Step 1: Integer types
Kind: read

So far every value has been text or an exit code, and now for the types values come in.
Whole numbers have eight: `i8` to `i64` hold negative numbers too, and `u8` to `u64` start at zero.
The number in each name is the size in bits, and each type knows its own limits, which you read off its name as `MIN` and `MAX`.
Press Run.

Line 4 prints `255`, the largest number 8 bits can hold, and line 5 shows how far `i64` goes.

```lugha
fun main() {
    println(i8.MIN);
    println(i8.MAX);
    println(u8.MAX);
    println(i64.MAX);
}
```

Output:

```text
-128
127
255
9223372036854775807
```

## Step 2: Floating-point types
Kind: read

Numbers with a fraction are floats, and they come in two types, `f32` and `f64`.
Line 2 prints `2.0`.
Will it come out as `2` or as `2.0`?

It prints `2.0`.
If you expected `2`, you were expecting a float with nothing after its point to print like a whole number.
A float always prints with its point, so you can tell the two apart.
Line 3 is written out in full and prints as `1.0e16`, because from `1e16` up a float prints with an exponent.
Line 4 is the last kind of number-like value, a `bool`, which is `true` or `false`.

```lugha
fun main() {
    println(2.0);
    println(10000000000000000.0);
    println(true);
}
```

Output:

```text
2.0
1.0e16
true
```

## Step 3: Integer literals
Kind: read

Whole numbers print in plain decimal, however you write them.
`_` separates digits, and `0x`, `0b` and `0o` start hex, binary and octal, on lines 2 to 5.
Line 6 writes `017`.
Before you run it, decide what it prints.

It prints `17`, with warning W0107.
If you expected `15`, you were expecting a leading zero to mean octal, the way `0o` does on line 5.
In Lugha a leading zero changes nothing, so octal is always written `0o17`.

```lugha
fun main() {
    println(1_000_000);
    println(0xFF);
    println(0b1010);
    println(0o17);
    println(017);
}
```

Output (with warning W0107, "a leading zero doesn't make an octal number: this is 17"):

```text
1000000
255
10
15
17
```

## Step 4: Float literals
Kind: fix (start gives E0107 "float literal needs a fractional part")

Back to floats: line 2 tries to write two hundred thousand as `2e5`.
Press Run.

An exponent makes a float, and a float in Lugha needs a digit on both sides of its `.`, so `lughac` refuses `2e5` with E0107:

```lugha {2}
fun main() {
    println(2.0e5);
}
```

Write `2.0e5` on line 2 and run again, or press Solve.

Start:

```lugha
fun main() {
    println(2e5);
}
```

Solution:

```lugha
fun main() {
    println(2.0e5);
}
```

Output (solution):

```text
200000.0
```

## Step 5: Characters and strings
Kind: fix (start gives E0102 "unterminated string", twice)

That leaves text, which has two types.
A `char` in single quotes is one character, as on line 2.
A `string` in double quotes is any text, with escapes such as `\t` for a tab on line 3.
The string on line 4 runs on to line 5.
Press Run.

`lughac` reports E0102 twice, once for each line, because a string ends on the line it starts.
A line break inside a string is written `\n`:

```lugha {4}
fun main() {
    println('a');
    println("tab:\tend");
    println("first line\nsecond line");
}
```

Join lines 4 and 5 with `\n` and run again.

Start:

```lugha
fun main() {
    println('a');
    println("tab:\tend");
    println("first line
second line");
}
```

Solution:

```lugha
fun main() {
    println('a');
    println("tab:\tend");
    println("first line\nsecond line");
}
```

Output (solution):

```text
a
tab:	end
first line
second line
```
