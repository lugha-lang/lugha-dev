## Step 1: Arithmetic operators
Kind: fix (start gives E0404 "cannot apply `+` to Vec2" on line 6, and "cannot apply `+=` to Vec2" on line 7)

An operator on a struct of your own calls a method of the first value's type.
`+` calls `add`, `-` calls `sub`, `*` calls `mul`, `/` calls `div`, `%` calls `rem`, and a leading `-` calls `neg`.
Line 6 adds two `Vec2`s, and `Vec2` has no `add` yet.
Press Run.

`lughac` gives E0404, "cannot apply `+` to Vec2", on line 6, and the same for line 7's `+=`.
An `add` with a plain `self`, one parameter and a result makes `+` work.
`b += a` on line 7 is then `b = b.add(a)`, and `-=` and the others go through their methods the same way:

```lugha {3,4,5}
struct Vec2 { x: f64, y: f64 }

impl Vec2 {
    fun add(self, other: Vec2): Vec2 = Vec2 { x: self.x + other.x, y: self.y + other.y };
}

fun main() {
    let a = Vec2 { x: 1.0, y: 2.0 };
    let mut b = Vec2 { x: 3.0, y: 4.0 };
    println(a + b);
    b += a;
    println(b);
}
```

Add the `impl` with `add`; Solve does it for you.

## Step 2: Mixed operands
Kind: read

`mul` can be written more than once, each time for another type of second operand.
The one on line 4 takes an `f64`, so `v * 2.0` scales the vector.
The one on line 5 takes a `Vec2`, so `v * v` gives a number.
The second operand picks one by its exact type, so `v * 2` would be E0401: `2` is an integer.
For a number before `*`, the `impl f64` on line 8, with a `mul` that takes a `Vec2`, makes `2.0 * v` work too.
The methods can be called by name as well, and `v.mul(2.0)` on line 17 picks the same one `v * 2.0` does.
Press Run.

```lugha
struct Vec2 { x: f64, y: f64 }

impl Vec2 {
    fun mul(self, k: f64): Vec2 = Vec2 { x: self.x * k, y: self.y * k };
    fun mul(self, other: Vec2): f64 = self.x * other.x + self.y * other.y;
}

impl f64 {
    fun mul(self, v: Vec2): Vec2 = v * self;
}

fun main() {
    let v = Vec2 { x: 1.0, y: 2.0 };
    println(v * 2.0);
    println(2.0 * v);
    println(v * v);
    println(v.mul(2.0));
}
```

Output:

```text
Vec2 { x: 2.0, y: 4.0 }
Vec2 { x: 2.0, y: 4.0 }
5.0
Vec2 { x: 2.0, y: 4.0 }
```

## Step 3: Index operators
Kind: read

`[ ]` is an operator too.
`set_index` makes `grid[1, 0] = 5` on line 17 write a value, and `index` makes line 19 read it back.
`set_index` takes `mut self`, so `grid` needs `let mut`, as an array does.
Several indexes, as in `grid[1, 0]`, arrive as one tuple, which lines 5 and 10 take apart, and a single index is a plain parameter, such as `at: i64`.
They're ordinary methods too: lines 20 and 21 call `set_index` and `index` by name, with the tuple written out.
Press Run.

```lugha
struct Grid { width: i64, cells: i64[] }

impl Grid {
    fun index(self, at: (i64, i64)): i64 {
        let (x, y) = at;
        self.cells[y * self.width + x]
    }

    fun set_index(mut self, at: (i64, i64), value: i64) {
        let (x, y) = at;
        self.cells[y * self.width + x] = value;
    }
}

fun main() {
    let mut grid = Grid { width: 3, cells: [0; 6] };
    grid[1, 0] = 5;
    grid[2, 1] = 7;
    println(grid[1, 0]);
    grid.set_index((0, 1), 9);
    println(grid.index((0, 1)));
    println(grid.cells);
}
```

Output:

```text
5
9
[0, 5, 0, 9, 0, 7]
```
