## Step 1: Interface declaration
Kind: read

A bound such as `Num` says what a type must support, and an interface is a bound you write yourself.
`Shape` on lines 1 to 4 lists two methods, with their signatures and no bodies.
`Circle` on line 8 has both methods, and line 15 calls them.
An interface's methods can use `Self` for the type that meets it, as in `fun bigger(self, other: Self): bool`.
The `next` method in Custom iterators matches one the prelude declares, in an interface named `Iter<T>`.
Press Run.

```lugha
interface Shape {
    fun area(self): f64;
    fun name(self): string;
}

struct Circle { r: f64 }

impl Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
    fun name(self): string = "circle";
}

fun main() {
    let c = Circle { r: 1.0 };
    println("{c.name()}: {c.area()}");
}
```

Output:

```text
circle: 3.14
```

## Step 2: Implementing an interface
Kind: fix (start gives E0422 "`Square` doesn't satisfy `Shape`", help "no method `name`")

A type meets an interface by having every one of its methods, with the same signatures.
`describe` on line 18 takes any `T: Shape`, and line 22 passes it a `Square`.
Press Run.

`lughac` gives E0422, "`Square` doesn't satisfy `Shape`", and its help names what's missing: no method `name`.
Give `Square` the method `Shape` lists:

```lugha {16}
interface Shape {
    fun area(self): f64;
    fun name(self): string;
}

struct Circle { r: f64 }
struct Square { side: f64 }

impl Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
    fun name(self): string = "circle";
}

impl Square {
    fun area(self): f64 = self.side * self.side;
    fun name(self): string = "square";
}

fun describe<T: Shape>(s: T): string = "{s.name()} of area {s.area()}";

fun main() {
    println(describe(Circle { r: 1.0 }));
    println(describe(Square { side: 2.0 }));
}
```

## Step 3: Interfaces as bounds
Kind: read

With `T: Shape`, a generic function can call the interface's methods on a `T`.
`total` on line 11 adds up the areas in an array of any one type that is a `Shape`.
Only methods a bound declares can be called: `s.perimeter()` in `total` would be E0421, "no bound of `T` declares `perimeter`".
Press Run.

```lugha
interface Shape {
    fun area(self): f64;
}

struct Square { side: f64 }

impl Square {
    fun area(self): f64 = self.side * self.side;
}

fun total<T: Shape>(shapes: T[]): f64 = shapes.fold(0.0, fun(sum, s) = sum + s.area());

fun main() {
    println(total([Square { side: 1.0 }, Square { side: 2.0 }]));
}
```

Output:

```text
5.0
```

## Step 4: Default methods
Kind: read

An interface can give a method a body, which is then its default.
`describe` on line 3 has one, and it calls `area` on `self`.
`Circle` has no `describe`, so line 19 uses the default.
Line 20 calls `Square`'s own, from line 15.
Press Run.

```lugha
interface Shape {
    fun area(self): f64;
    fun describe(self): string = "a shape of area {self.area()}";
}

struct Circle { r: f64 }
struct Square { side: f64 }

impl Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
}

impl Square {
    fun area(self): f64 = self.side * self.side;
    fun describe(self): string = "a square with side {self.side}";
}

fun main() {
    println(Circle { r: 1.0 }.describe());
    println(Square { side: 2.0 }.describe());
}
```

Output:

```text
a shape of area 3.14
a square with side 2.0
```
