## Step 1: Struct declaration
Kind: read

A struct is a type you declare yourself, with a name for each of its fields.
Line 1 declares `Point`, a struct with two fields, each with its type.
`Point` sits outside `main`, because a struct is declared at the top level, and it's a type like `i64`.
Line 4 builds one, naming each field, and `p.x` on line 5 reads the field `x`.
Press Run.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3, y: 4 };
    println(p.x);
    println(p.y);
}
```

Output:

```text
3
4
```

## Step 2: Printing structs
Kind: read

Line 5 prints `p` itself.
Press Run.

It prints the struct's name, then each field and its value in braces, in the order `Point` declares them.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3, y: 4 };
    println(p);
}
```

Output:

```text
Point { x: 3, y: 4 }
```

## Step 3: Struct literals
Kind: fix (start gives E0413 "missing field `y` in `Point`")

`Point { x: 3, y: 4 }` is a struct literal, and line 4 now writes one with only `x`.
Will `y` start at `0`?

There's no default: `lughac` gives E0413, "missing field `y` in `Point`".
A struct literal gives every field a value, once, in any order:

```lugha {4}
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3, y: 0 };
    println(p);
}
```

Add `y: 0` on line 4.

Start:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3 };
    println(p);
}
```

Solution:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3, y: 0 };
    println(p);
}
```

Output (solution):

```text
Point { x: 3, y: 0 }
```

## Step 4: Field assignment
Kind: fix (start gives E0501 "cannot assign to `p`: it is not mutable", help "make it mutable: `let mut p`")

Line 5 changes one field, `p.x = 5`.
`p` was declared with plain `let`, but can its fields still change?

E0501 names `p` itself: "cannot assign to `p`: it is not mutable".
A field has no `mut` of its own, so changing one changes the struct, and the variable that holds it needs `let mut`:

```lugha {4}
struct Point { x: i64, y: i64 }

fun main() {
    let mut p = Point { x: 3, y: 4 };
    p.x = 5;
    println(p);
}
```

Add `mut` on line 4.

Start:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3, y: 4 };
    p.x = 5;
    println(p);
}
```

Solution:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let mut p = Point { x: 3, y: 4 };
    p.x = 5;
    println(p);
}
```

Output (solution):

```text
Point { x: 5, y: 4 }
```

## Step 5: Struct update syntax
Kind: read

Another way to get a changed point is to build a new one from the old.
Line 5 writes `x` and ends with `..p`, which takes every field not written, here `y`, from `p`, the one way to leave fields unwritten.
Does that change `p`?

It doesn't: line 6 prints the new point, and line 7 prints `p` as it was.
`..p` has to come last, after the fields you write.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 3, y: 4 };
    let shifted = Point { x: 10, ..p };
    println(shifted);
    println(p);
}
```

Output:

```text
Point { x: 10, y: 4 }
Point { x: 3, y: 4 }
```

## Step 6: Struct literals in conditions
Kind: fix (start gives E0205 "struct literal in a condition must be in parentheses", help "wrap it in parentheses: `(Point { … })`")

`==` compares two structs field by field.
Line 5 uses it to check whether `p` is the origin.
Since the parentheses around a condition are optional, will this `if` compile?

It doesn't: the `{` after `Point` could start the literal or the `if`'s block, so `lughac` gives E0205, "struct literal in a condition must be in parentheses".
Inside parentheses there's no doubt left:

```lugha {5}
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 0, y: 0 };
    if p == (Point { x: 0, y: 0 }) {
        println("at the origin");
    }
}
```

Put the literal on line 5 in parentheses, or press Solve.

Start:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 0, y: 0 };
    if p == Point { x: 0, y: 0 } {
        println("at the origin");
    }
}
```

Solution:

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let p = Point { x: 0, y: 0 };
    if p == (Point { x: 0, y: 0 }) {
        println("at the origin");
    }
}
```

Output (solution):

```text
at the origin
```
