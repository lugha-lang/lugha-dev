## Step 1: if let
Kind: read

A `match` with only one case worth handling can be written as an `if let`.
Line 3 tests one pattern, `Some(n)`, against what `parse_i64` gives back.
When it matches, the block runs with `n` in scope, and otherwise the `else` block on line 5 runs.
There's no `None` arm to write, because an `if let` doesn't have to cover every case.
The `else` is optional, and without it nothing runs when the pattern doesn't match.
Press Run.

```lugha
fun main() {
    for typed of ["12", "twelve"] {
        if let Some(n) = parse_i64(typed) {
            println("{n} doubled is {n * 2}");
        } else {
            println("{typed} isn't a number");
        }
    }
}
```

Output:

```text
12 doubled is 24
twelve isn't a number
```

## Step 2: while let
Kind: read

`while let` repeats for as long as its pattern matches.
Line 3 pops from `stack` before each pass, and `top` takes each element in turn, from the last.
Once the array is empty, `pop` gives `None` and the loop ends, so line 6 prints `[]`.
Press Run.

```lugha
fun main() {
    let mut stack = [1, 2, 3];
    while let Some(top) = stack.pop() {
        println(top);
    }
    println(stack);
}
```

Output:

```text
3
2
1
[]
```

## Step 3: let else
Kind: fix (start gives E0429 "the `else` of a `let … else` must not finish", help "end it with `return`, `break`, `continue`, `panic(…)` or `exit(…)`")

`let … else` keeps its bindings in scope for the rest of the block, not only inside a block of their own.
Its `else` runs when the pattern doesn't match.
Line 2 names the number `n`, and the `println` after the `else` uses it.

As written, it's E0429, "the `else` of a `let … else` must not finish".
If the `else` block ended normally, that `println` would run with no `n` to read.
So the block has to leave, here with `return;`, which ends `report` without a value:

```lugha {4}
fun report(typed: string) {
    let Some(n) = parse_i64(typed) else {
        println("{typed} isn't a number");
        return;
    };
    println("{n} doubled is {n * 2}");
}

fun main() {
    report("12");
    report("twelve");
}
```

Add `return;` as line 4, or press Solve.

## Step 4: Nested patterns
Kind: read

`describe` on line 7 takes an `Option<Shape>`.
In `Some(Circle(r))` on line 9, the data inside the `Some` is matched with a pattern of its own.
The arm matches only a `Some` holding a circle, and names its radius `r`.
The arms cover each shape inside a `Some`, and then `None`.
Line 18 pops the one circle from `shapes`, and line 19 pops again from the empty array.
Press Run.

```lugha
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun describe(s: Option<Shape>): string {
    match s {
        Some(Circle(r)) => "a circle of radius {r}",
        Some(Rect(w, h)) => "a {w} by {h} rectangle",
        Some(Empty) => "an empty shape",
        None => "nothing",
    }
}

fun main() {
    let mut shapes = [Shape.Circle(1.5)];
    println(describe(shapes.pop()));
    println(describe(shapes.pop()));
}
```

Output:

```text
a circle of radius 1.5
nothing
```

## Step 5: mut bindings
Kind: fix (start gives E0501 "cannot assign to `n`: it is not mutable", help "match bindings are immutable; copy it into a `let mut`")

Names in a pattern are read-only, like parameters.
Line 5 adds 1 to `n`, the number inside `count`.
That's E0501, "cannot assign to `n`: it is not mutable", and its help suggests copying `n` into a `let mut`.
`mut` before the name in the pattern does that in one place, giving the arm its own copy to change, and `count` itself stays `Some(4)`, as line 10 shows:

```lugha {4}
fun main() {
    let count: Option<i64> = Some(4);
    match count {
        Some(mut n) => {
            n += 1;
            println(n);
        }
        None => println("no count"),
    }
    println(count);
}
```

Change line 4 to `Some(mut n) => {`, or press Solve.

## Step 6: Variants and bindings
Kind: fix (start compiles with W0103 "unused binding `Emtpy`" on line 9 and W0102 "unreachable match arm" on lines 10 and 11, and prints `an empty shape`)

Line 17 describes a circle, but the program prints `an empty shape`.
`Emtpy` on line 9 is misspelled, and a name inside a pattern that isn't a variant becomes a binding.
A binding matches any shape in a `Some`, and line 9 comes first, so every shape stops there.
`lughac` warns about it with W0103, "unused binding `Emtpy`", and marks lines 10 and 11 unreachable with W0102.
At the top of a `match` on `Shape`, a misspelled name can only be a variant, and so can one with data after it, as in `Cirle(r)`.
Either way it's E0415, "no variant … on `Shape`".

```lugha {9}
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun describe(s: Option<Shape>): string {
    match s {
        Some(Empty) => "an empty shape",
        Some(Circle(r)) => "a circle of radius {r}",
        Some(Rect(w, h)) => "a {w} by {h} rectangle",
        None => "nothing",
    }
}

fun main() {
    println(describe(Some(Shape.Circle(1.5))));
}
```

Change `Emtpy` to `Empty` on line 9, or press Solve.
