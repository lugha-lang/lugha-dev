## Step 1: Enum declaration
Kind: fix (start gives E0207 "`::` is not Lugha syntax", help "write `Shape.Circle`")

An enum is a type whose value is one of a list of variants.
`Shape` on lines 1 to 5 is a circle with a radius, a rectangle with a width and a height, or empty.
Each variant lists the types of the data it carries, if any.
Line 8 builds a circle with `Shape::Circle(2.0)`.

`lughac` stops at E0207, "`::` is not Lugha syntax".
A variant is built through its enum's name and a dot, as `Shape.Rect` is on line 9, and `Shape.Empty` on line 12 needs no parentheses:

```lugha {8}
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun main() {
    let wheel = Shape.Circle(2.0);
    let door = Shape.Rect(1.0, 2.0);
    println(wheel);
    println(door);
    println(Shape.Empty);
}
```

Change `::` to `.` on line 8, or press Solve.

Start:


## Step 2: Matching on enums
Kind: fix (start gives E0417 "non-exhaustive match: `Empty` not covered", help "add the missing arms, or `_ => …`")

To use a variant's data, `match` on the value.
In an arm, a variant is written without the enum's name.
Names in its parentheses take its data, so `Circle(r)` on line 9 gives the radius the name `r`.
`main` never passes an empty shape to `area`, and the `match` has no arm for `Empty`.

`lughac` refuses it with E0417, "non-exhaustive match: `Empty` not covered".
A `match` on an enum must cover every variant, whatever the program happens to pass it:

```lugha {11}
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun area(s: Shape): f64 {
    match s {
        Circle(r) => 3.14 * r * r,
        Rect(w, h) => w * h,
        Empty => 0.0,
    }
}

fun main() {
    println(area(Shape.Circle(2.0)));
    println(area(Shape.Rect(1.0, 2.0)));
}
```

Add the `Empty` arm as line 11.

Start:

## Step 3: Recursive enums
Kind: read

A variant's data can be the enum itself.
`List` on lines 1 to 4 is either `Nil`, the end, or `Cons`, a number followed by the rest of the list.
`Cons` on line 3 names `List` as its second type, with nothing else written to make that work.
Line 14 builds `1`, `2`, `3` by nesting: the innermost value is `List.Nil`, and each `Cons` puts one number in front of it.
`sum` adds each number to the sum of the rest, calling itself until it reaches `Nil`.
Press Run.

```lugha
enum List {
    Nil,
    Cons(i64, List),
}

fun sum(list: List): i64 {
    match list {
        Nil => 0,
        Cons(head, rest) => head + sum(rest),
    }
}

fun main() {
    let numbers = List.Cons(1, List.Cons(2, List.Cons(3, List.Nil)));
    println(numbers);
    println(sum(numbers));
}
```

Output:

```text
Cons(1, Cons(2, Cons(3, Nil)))
6
```
