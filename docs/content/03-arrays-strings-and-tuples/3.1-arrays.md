## Step 1: Array literals
Kind: read

An array holds values of one type in order, written in square brackets, as on line 2.
Line 3 uses the other way to write one, `[value; count]`.
What will `[0; 4]` hold?
Press Run.

It prints `[0, 0, 0, 0]`: four elements, each a copy of `0`.
`.len` on line 6, written without parentheses, is the number of elements.
`scores` is an `i64[]`, an array of `i64`.

```lugha
fun main() {
    let scores = [70, 85, 90];
    let zeros = [0; 4];
    println(scores);
    println(zeros);
    println(scores.len);
}
```

Output:

```text
[70, 85, 90]
[0, 0, 0, 0]
3
```

## Step 2: Indexing
Kind: fix (start gives E0501 "cannot assign to `scores`: it is not mutable", help "make it mutable: `let mut scores`")

`scores[0]` on line 4 is the first element, because indexes count from `0`.
Line 3 tries to change the second, in an array declared with plain `let`.
Can one element change when the array can't?

E0501 says no: "cannot assign to `scores`: it is not mutable".
Changing one element changes the array, so the array needs `let mut`, like any variable you change:

```lugha {2}
fun main() {
    let mut scores = [70, 85, 90];
    scores[1] = 88;
    println(scores[0]);
    println(scores);
}
```

Add `mut` on line 2.

```lugha
fun main() {

    println(scores[0]);
    println(scores);
}
```

Solution:

```lugha
fun main() {
    let mut scores = [70, 85, 90];
    scores[1] = 88;
    println(scores[0]);
    println(scores);
}
```

## Step 4: push and clear
Kind: read

An array can grow and shrink.
`push` on line 3 adds an element at the end, and `clear` on line 6 removes them all.
Both change `list`, so it's declared with `let mut`.

```lugha
fun main() {
    let mut list = ["milk"];
    list.push("bread");
    println(list);
    println(list.len);
    list.clear();
    println(list.len);
}
```

Output:

```text
["milk", "bread"]
2
0
```

## Step 6: for … of loops
Kind: fix (start gives E0201 "expected `..`, found `{`")

Line 3 loops over `scores` with `for score in scores`.
`for … in` counted over a range in Loops, so will it go through an array too?

It doesn't: after `in`, `lughac` wants a range such as `0..3`, so it gives E0201, "expected `..`, found `{`".
`of` goes through an array, giving each element in turn:

```lugha {3}
fun main() {
    let scores = [70, 85, 90];
    for score of scores {
        println(score);
    }
}
```

Change `in` to `of` on line 3, or press Solve.

```lugha
    }
}
```

## Step 7: Changing elements in a loop
Kind: fix (start gives E0501 "cannot assign to `score`: it is not mutable", help "loop variables are immutable; copy it into a `let mut`")

Line 4 tries to add 5 to every score as the loop goes through them.
`scores` is `let mut`, so can the loop change its elements?

The loop variable is the problem: E0501, "cannot assign to `score`: it is not mutable".
A loop variable can't be assigned to.
The help suggests a copy in a `let mut`, which would change only the copy, so to change the array itself, loop over it with `of mut`:

```lugha {3}
fun main() {
    let mut scores = [70, 85, 90];
    for score of mut scores {
        score += 5;
    }
    println(scores);
}
```

Then `score` is each element itself, and adding to it adds to that element.
Add `mut` after `of` on line 3.

Start:

```lugha
fun main() {
    let mut scores = [70, 85, 90];
    for score of scores {
        score += 5;
    }
    println(scores);
}
```

Solution:

```lugha
fun main() {
    let mut scores = [70, 85, 90];
    for score of mut scores {
        score += 5;
    }
    println(scores);
}
```

Output (solution):

```text
[75, 90, 95]
```

## Step 8: Array concatenation and equality
Kind: read

`+` on line 4 joins two arrays of the same type into a new one.
Line 6 compares the result with `==`.
Will `==` compare the elements, or ask whether both sides are the same array?

It prints `true`, because `==` compares arrays element by element, in order.

```lugha
fun main() {
    let first = [1, 2];
    let second = [3];
    let both = first + second;
    println(both);
    println(both == [1, 2, 3]);
}
```

Output:

```text
[1, 2, 3]
true
```
