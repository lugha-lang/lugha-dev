## Step 1: panic
Kind: read

`panic` stops the program with a message.
`check_age` on line 1 panics on line 3 when it's given a negative age, and line 10 passes it `-1`.
Press Run.

The panic prints its message and where it happened, `src/main.la:3:9`, and the program exits with code 101.
Nothing in the program can stop a panic once it starts, so line 11 never prints `done`.

```lugha
fun check_age(age: i64): i64 {
    if age < 0 {
        panic("age can't be negative");
    }
    age
}

fun main() {
    println(check_age(30));
    println(check_age(-1));
    println("done");
}
```

Output (exit code 101):

```text
30
panic: age can't be negative at src/main.la:3:9
```

## Step 2: unwrap and expect
Kind: read

`unwrap` takes the value out of a `Some` or an `Ok`, and panics when there isn't one.
Line 2 unwraps `parse_i64("42")`, which is `Some(42)`, so `n` is `42`.
`parse_i64("forty")` is `None`, so `expect` on line 4 panics, with the message you gave it.
`unwrap` would have panicked there too, with `unwrap on None`, and on an `Err` its message includes the error.
Press Run.

```lugha
fun main() {
    let n = parse_i64("42").unwrap();
    println(n);
    let m = parse_i64("forty").expect("the count must be a number");
    println(m);
}
```

Output (exit code 101):

```text
42
panic: the count must be a number at src/main.la:4:32
```

## Step 3: Stack overflow
Kind: fix (start panics with `stack overflow`, exit code 101)

`sum` on line 6 is the recursive sum from Recursive enums, and lines 14 to 17 build a list of a million `1`s.
Every call to `sum` waits for the next one to finish, and a million waiting calls don't fit in the program's stack.
It panics with `stack overflow`, the one panic that can't say where it happened.
Walk a long list with a loop instead: `while let` on line 9 takes one node at a time, and line 11 moves `rest` on to the next:

```lugha {7,8,9,10,11,12,13}
enum List {
    Nil,
    Cons(i64, List),
}

fun sum(list: List): i64 {
    let mut total = 0;
    let mut rest = list;
    while let Cons(head, next) = rest {
        total += head;
        rest = next;
    }
    total
}

fun main() {
    let mut list = List.Nil;
    for _ in 0..1000000 {
        list = List.Cons(1, list);
    }
    println(sum(list));
}
```

Replace the body of `sum`, or press Solve.

Start:

```lugha
enum List {
    Nil,
    Cons(i64, List),
}

fun sum(list: List): i64 {
    match list {
        Nil => 0,
        Cons(head, rest) => head + sum(rest),
    }
}

fun main() {
    let mut list = List.Nil;
    for _ in 0..1000000 {
        list = List.Cons(1, list);
    }
    println(sum(list));
}
```

Output (start, exit code 101):

```text
panic: stack overflow
```

Solution:

```lugha
enum List {
    Nil,
    Cons(i64, List),
}

fun sum(list: List): i64 {
    let mut total = 0;
    let mut rest = list;
    while let Cons(head, next) = rest {
        total += head;
        rest = next;
    }
    total
}

fun main() {
    let mut list = List.Nil;
    for _ in 0..1000000 {
        list = List.Cons(1, list);
    }
    println(sum(list));
}
```

Output (solution):

```text
1000000
```
