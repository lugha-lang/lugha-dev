## Step 1: Ok and Err
Kind: read

A function that can fail returns a `Result`, so its caller can tell whether it worked.
`divide` on line 1 returns a `Result<i64, string>`: an `i64` answer, or a `string` saying why there isn't one.
Line 3 returns that string in an `Err` for a zero divisor, and line 5 wraps the answer in `Ok`.
Like `Some`, `Ok` and `Err` are written without a prefix.
The type a variant doesn't name, such as the error type `string` for the `Ok` on line 5, comes from the return type.
Press Run.

```lugha
fun divide(a: i64, b: i64): Result<i64, string> {
    if b == 0 {
        return Err("division by zero");
    }
    Ok(a / b)
}

fun main() {
    println(divide(10, 2));
    println(divide(1, 0));
}
```

Output:

```text
Ok(5)
Err("division by zero")
```

## Step 2: Matching on Result
Kind: read

Line 9 tries both divisors, and line 10 matches on each `Result`.
`Ok(q)` on line 11 names the answer, and `Err(e)` on line 12 names the message.
Leave out the `Err` arm and the `match` is E0417, "`Err` not covered".
Press Run.

```lugha
fun divide(a: i64, b: i64): Result<i64, string> {
    if b == 0 {
        return Err("division by zero");
    }
    Ok(a / b)
}

fun main() {
    for b of [2, 0] {
        match divide(10, b) {
            Ok(q) => println("10 / {b} is {q}"),
            Err(e) => println("10 / {b} failed: {e}"),
        }
    }
}
```

Output:

```text
10 / 2 is 5
10 / 0 failed: division by zero
```

## Step 3: Reading files
Kind: fix (start prints `can't read notes.txt: No such file or directory`)

`read_file` reads a whole file into a string, and since that can fail, it gives a `Result<string, string>`.
Line 2 matches on it: `Ok` holds the file's text, and `Err` the system's message.
Each run starts with no files, so there's no `notes.txt` yet, and the program prints the error.

Write the file first, on a new line 2, with `write_file`.
It gives a `Result` too, `Ok` with the number of bytes written, and line 2 prints it:

```lugha {2}
fun main() {
    println(write_file("notes.txt", "milk\neggs\n"));
    match read_file("notes.txt") {
        Ok(text) => print(text),
        Err(e) => println("can't read notes.txt: {e}"),
    }
}
```

## Step 4: map_err
Kind: read

`map_err` changes the error inside an `Err`, and leaves an `Ok` as it is.
It takes a function from the old error to the new one, here `explain` on line 1, passed by name as `update` took `add_one`.
This run starts with no `notes.txt` too, so line 5 prints the failed read as it is.
Line 6 prints it again with the file's name added to the message.
Press Run.

```lugha
fun explain(e: string): string = "couldn't read notes.txt: {e}";

fun main() {
    let read = read_file("notes.txt");
    println(read);
    println(read.map_err(explain));
}
```

Output:

```text
Err("No such file or directory")
Err("couldn't read notes.txt: No such file or directory")
```

## Step 5: ok, unwrap_or, is_ok and is_err
Kind: read

Line 2 writes `notes.txt`, so line 3's read works, and line 4's, of a file that isn't there, fails.
`ok()` on lines 5 and 6 turns a `Result` into an `Option`, dropping the error.
`unwrap_or` on lines 7 and 8 gives the file's text, or `(no notes)` when the read failed.
`is_ok()` and `is_err()` on lines 9 and 10 tell whether a read worked or failed.
Press Run.

```lugha
fun main() {
    println(write_file("notes.txt", "milk"));
    let notes = read_file("notes.txt");
    let other = read_file("other.txt");
    println(notes.ok());
    println(other.ok());
    println(notes.unwrap_or("(no notes)"));
    println(other.unwrap_or("(no notes)"));
    println(notes.is_ok());
    println(other.is_err());
}
```

Output:

```text
Ok(4)
Some("milk")
None
milk
(no notes)
true
true
```
