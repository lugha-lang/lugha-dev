## Step 1: defer
Kind: read

`defer` sets a statement aside to run when the block it's in is left.
Line 3 defers a `println` that reads `n`, and line 4 changes `n` after it.
Which `n` will the deferred line print?
Press Run.

It prints `2`.
The deferred line runs when `main` ends, after line 5, and reads `n` as it is then.

```lugha
fun main() {
    let mut n = 1;
    defer println("deferred: n is {n}");
    n = 2;
    println("end of main: n is {n}");
}
```

Output:

```text
end of main: n is 2
deferred: n is 2
```

## Step 2: defer and early returns
Kind: read

A defer runs on every way out of its block, a `return` or a `?` included.
`first_line` defers `closing {path}` on line 3, before line 4 reads the file with `?`.
For `other.txt` the `?` returns the `Err` at once, and `closing other.txt` still prints right before it does.
So cleanup written as a `defer` near the top of a function also runs when a later `?` returns early.
Press Run.

```lugha
fun first_line(path: string): Result<string, string> {
    println("opening {path}");
    defer println("closing {path}");
    let text = read_file(path)?;
    Ok(text.split("\n")[0])
}

fun main() {
    println(write_file("notes.txt", "milk\neggs\n"));
    println(first_line("notes.txt"));
    println(first_line("other.txt"));
}
```

Output:

```text
Ok(10)
opening notes.txt
closing notes.txt
Ok("milk")
opening other.txt
closing other.txt
Err("No such file or directory")
```

## Step 3: Defer order
Kind: read

When a block has several defers, they run last first, so line 3's runs before line 2's.
A defer inside a loop belongs to the loop's block, so line 5's runs at the end of each pass, not at the end of `main`.
Press Run.

```lugha
fun main() {
    defer println("first defer");
    defer println("second defer");
    for i in 1..3 {
        defer println("end of pass {i}");
        println("pass {i}");
    }
    println("end of main");
}
```

Output:

```text
pass 1
end of pass 1
pass 2
end of pass 2
end of main
second defer
first defer
```

## Step 4: When defers don't run
Kind: read

A panic ends the program at once, so pending defers don't run.
Line 4 reads past the end of `ages`, so the program panics, and `cleaning up` from line 2 never prints.
`exit`, which ends the program with the code you give it, skips them too.
Press Run.

```lugha
fun main() {
    defer println("cleaning up");
    let ages = [30, 41];
    println(ages[2]);
}
```

Output (exit code 101):

```text
panic: index out of bounds: the length is 2 but the index is 2 at src/main.la:4:17
```

## Step 5: Deferred values
Kind: fix (start gives E0456 "a deferred statement must have type (), found Result<i64, string>", help "handle the error inside it, or discard it on purpose: `defer { fs.remove_file(tmp); }`")

Line 2 defers a `write_file`, which gives back a `Result`.
That's E0456: a deferred statement must have type `()`, so a deferred call's `Result` can't be dropped without the code saying so.
Write the call in a block, with a `;` after it, to discard the `Result` on purpose:

```lugha {2}
fun main() {
    defer { write_file("log.txt", "done"); }
    println("working");
}
```

Wrap line 2's call in braces with a `;` after it, or press Solve.

Start:

```lugha
fun main() {
    defer write_file("log.txt", "done");
    println("working");
}
```

Solution:

```lugha
fun main() {
    defer { write_file("log.txt", "done"); }
    println("working");
}
```

Output (solution):

```text
working
```
