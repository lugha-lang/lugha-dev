## Step 1: Copies
Kind: read

In Lugha, assigning a struct, an array or an enum gives you your own copy.
`b` on line 5 starts as a copy of `a`, and line 6 changes `b.x`.
Press Run and look at what `a` prints.

`a` still has `x: 1`.
Changing `b` never touched it: they are two separate values.

```lugha
struct Point { x: i64, y: i64 }

fun main() {
    let a = Point { x: 1, y: 2 };
    let mut b = a;
    b.x = 9;
    println(a);
    println(b);
}
```

Output:

```text
Point { x: 1, y: 2 }
Point { x: 9, y: 2 }
```

## Step 2: Mutable copies
Kind: fix (start gives E0501 "cannot assign to `b`: it is not mutable", help "make it mutable: `let mut b`")

This time `a` is declared `let mut`, and its copy `b` on line 5 has no `mut`.
Does `b` take its `mut` from `a`?
Press Run.

It doesn't, and E0501 says `b` is not mutable.
Your copy is its own value, so it needs its own `mut`, whatever `a` has:

```lugha {5}
struct Point { x: i64, y: i64 }

fun main() {
    let mut a = Point { x: 1, y: 2 };
    let mut b = a;
    b.x = 9;
    println(a);
    println(b);
}
```

Add `mut` on line 5 and run again, or press Solve.

## Step 3: Copying arrays
Kind: read

Arrays follow the same rule.
`ys` on line 3 starts as a copy of `xs`, and line 4 pushes onto `ys`.
What will line 5, `println(xs)`, print?
Press Run.

It prints `[5, 6]`, because `ys = xs` gave `ys` an array of its own, not a second name for the one in `xs`.

```lugha
fun main() {
    let xs = [5, 6];
    let mut ys = xs;
    ys.push(1);
    println(xs);
    println(ys);
}
```

Output:

```text
[5, 6]
[5, 6, 1]
```

## Step 4: Passing by value
Kind: fix (start prints `[5, 6]`)

Function arguments follow the same rule.
`add_one` can't change its parameter, so line 2 copies `xs` into `ys`, and it pushes onto that and returns it.
Line 9 calls `add_one` but throws away what it returns, so line 10 prints `xs` as it was, `[5, 6]`.

Make line 10 print `[5, 6, 1]` by keeping the result:

```lugha {9}
fun add_one(xs: i64[]): i64[] {
    let mut ys = xs;
    ys.push(1);
    ys
}

fun main() {
    let mut xs = [5, 6];
    xs = add_one(xs);
    println(xs);
}
```

Change line 9 and run again, or press Solve.
A function can't reach back and change its caller's values.
It returns its results, and the caller decides what to keep.

## Step 6: Copy-on-write
Kind: read

Copying an array takes the same time however long it is, because at first the copy shares the original's memory.
Line 3 copies `big`, a million numbers, that way.
Line 4 writes to `copy`, so that's where it gets a million numbers of its own.
This is called copy-on-write, and no program can tell it from a full copy: line 5 still prints `0`.
Press Run.

```lugha
fun main() {
    let big = [0; 1000000];
    let mut copy = big;
    copy[0] = 1;
    println(big[0]);
    println(copy[0]);
}
```

Output:

```text
0
1
```
