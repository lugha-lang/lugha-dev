## Step 1: Memory safety
Kind: read

In a Lugha program, a name always reaches a value that's still there, unless the program calls C code.
`numbers` on line 1 builds an array on line 2 and returns it, and line 7 keeps it in `kept` after `numbers` has finished.
The array stays as long as `kept` holds it, so line 8 prints it whole.
The same goes for two checks you've met: there's no null, as Option showed, and reading past the end of an array stops the program, as in Bounds checking.
Press Run.

```lugha
fun numbers(): i64[] {
    let xs = [1, 2, 3];
    xs
}

fun main() {
    let kept = numbers();
    println(kept);
}
```

Output:

```text
[1, 2, 3]
```

## Step 2: Variable initialization
Kind: fix (start gives E0201 "expected `=`, found `;`")

Lugha also rules out reading a variable that was never set.
`total` on line 2 has a type but no value, and the loop adds each number to it.
What will line 6 print?
Press Run.

Nothing: `lughac` stops at line 2 with E0201, "expected `=`, found `;`".
A `let` always gives its variable a value, so no line can read one that was never set.
Give `total` its starting value:

```lugha {2}
fun main() {
    let mut total: i64 = 0;
    for n of [3, 4, 5] {
        total += n;
    }
    println(total);
}
```

Add `= 0` on line 2, or press Solve.

Start:

```lugha
fun main() {
    let mut total: i64;
    for n of [3, 4, 5] {
        total += n;
    }
    println(total);
}
```

Solution:

```lugha
fun main() {
    let mut total: i64 = 0;
    for n of [3, 4, 5] {
        total += n;
    }
    println(total);
}
```

Output (solution):

```text
12
```

## Step 3: Garbage collection
Kind: read

Step 1's array outlived `numbers`, so something has to give its memory back once nothing needs it.
Line 4 makes a new array of 100 numbers on every pass, a hundred thousand in all, and the program never gives one back.
A garbage collector, linked into every program, takes back memory once it can tell nothing holds it.
It's cautious, so it can hold on to some memory nothing uses, though that never makes the program behave wrongly.
Press Run.

It prints `10000000`, and the program never had to say which arrays it was done with.

```lugha
fun main() {
    let mut total = 0;
    for i in 0..100000 {
        let row = [i; 100];
        total += row.len;
    }
    println(total);
}
```

Output:

```text
10000000
```
