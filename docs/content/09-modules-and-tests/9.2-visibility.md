# 9.2 Visibility

## Objectives

After this lesson the learner can (one step each, titles from the outline):

1. **private**: an item only its own module sees; E0313. [L1366–1374]
2. **Package visibility**: nothing written means the whole package, not private. [L1366–1372]
3. **public**: visible to other packages; a `public` declaration mentions only `public` types (E0318). [L1366–1377]
4. **Private fields**: a struct with a `private` field is built through its functions. [L1374–1376]

---

## Step 1: private
Kind: fix (start gives E0313 "`square` is private to module `shapes`" on line 6)

`private` in front of an item keeps it inside its own module.
In `shapes.la`, line 7 declares `square` as `private`, and `area` on line 3 uses it there.
Line 6 of `main.la` calls `shapes.square`.
Press Run.

That's E0313, "`square` is private to module `shapes`".
`main.la` is another module, so it can't reach `square`, but it can call `area`, which calls `square` from inside `shapes`.
The fixed `main.la`:

```lugha {6}
import shapes;

fun main() {
    let s = shapes.Square { side: 3.0 };
    println(shapes.describe(s));
    println(shapes.area(s));
}
```

Change line 6 to call `shapes.area(s)`, or press Solve.

Start:

`src/main.la`:

```lugha
import shapes;

fun main() {
    let s = shapes.Square { side: 3.0 };
    println(shapes.describe(s));
    println(shapes.square(s.side));
}
```

`src/shapes.la`:

```lugha
struct Square { side: f64 }

fun area(s: Square): f64 = square(s.side);

fun describe(s: Square): string = "a square of side {s.side}";

private fun square(x: f64): f64 = x * x;
```

Solution:

`src/main.la`:

```lugha
import shapes;

fun main() {
    let s = shapes.Square { side: 3.0 };
    println(shapes.describe(s));
    println(shapes.area(s));
}
```

`src/shapes.la`:

```lugha
struct Square { side: f64 }

fun area(s: Square): f64 = square(s.side);

fun describe(s: Square): string = "a square of side {s.side}";

private fun square(x: f64): f64 = x * x;
```

Output (solution):

```text
a square of side 3.0
9.0
```

## Step 2: Package visibility
Kind: read

Without `private`, an item is visible in every module of its package, not only its own.
`lugha.toml`, in the file list, names this package `geometry`, and both `.la` files belong to it.
A program without a `lugha.toml` is one package too.
So `main.la` can build a `shapes.Square` on line 4, read its `side` field on line 5 and call `shapes.area` on line 6.
Press Run.

`src/main.la`:

```lugha
import shapes;

fun main() {
    let s = shapes.Square { side: 3.0 };
    println(s.side);
    println(shapes.area(s));
}
```

`src/shapes.la`:

```lugha
struct Square { side: f64 }

fun area(s: Square): f64 = square(s.side);

fun describe(s: Square): string = "a square of side {s.side}";

private fun square(x: f64): f64 = x * x;
```

`lugha.toml`:

```toml
[package]
name = "geometry"
version = "0.1.0"
source = "src"
```

Output:

```text
3.0
9.0
```

## Step 3: public
Kind: fix (start gives E0318 "`shapes.Square` is not `public`, but this declaration is" on line 3 of shapes.la)

`public` makes an item visible to other packages too, the ones that import its module.
Line 3 of `shapes.la` declares `unit` as `public`, but it returns a `Square`, which has no keyword.
Press Run.

That's E0318: another package could call `unit` but couldn't name the `Square` it returns.
A `public` declaration may mention only structs, enums and interfaces that are `public` too, so `Square` needs the keyword.
`side` still has none, so another package could hold a `Square` but not read its `side`.
The fixed `shapes.la`:

```lugha {1}
public struct Square { side: f64 }

public fun unit(): Square = Square { side: 1.0 };
```

Add `public` before `struct Square` on line 1; Solve does it for you.

Start:

`src/main.la`:

```lugha
import shapes;

fun main() {
    let s = shapes.unit();
    println(s.side);
}
```

`src/shapes.la`:

```lugha
struct Square { side: f64 }

public fun unit(): Square = Square { side: 1.0 };
```

Solution:

`src/main.la`:

```lugha
import shapes;

fun main() {
    let s = shapes.unit();
    println(s.side);
}
```

`src/shapes.la`:

```lugha
public struct Square { side: f64 }

public fun unit(): Square = Square { side: 1.0 };
```

Output (solution):

```text
1.0
```

## Step 4: Private fields
Kind: fix (start gives E0313 "`hi` is private to module `range`" on line 4)

A field can be `private` too, and then only its own module can set or read it.
`Range` in `range.la` keeps `lo` no larger than `hi`: its `new` swaps them when needed.
Line 4 of `main.la` writes a `Range` literal with `lo` above `hi`.
Press Run.

It's E0313 again, this time for a field: "`hi` is private to module `range`".
Outside its module, a struct literal needs every field visible, so a `Range` has to be built with `new`.
The fixed `main.la`:

```lugha {4}
import range;

fun main() {
    let r = range.Range.new(5, 1);
    println(r.size());
}
```

Change line 4 to `range.Range.new(5, 1)`, or press Solve.

Only `range.la` can set `lo` and `hi`, so every `Range` built anywhere else has come through `new`, with `lo` no larger than `hi`.

Start:

`src/main.la`:

```lugha
import range;

fun main() {
    let r = range.Range { lo: 5, hi: 1 };
    println(r.size());
}
```

`src/range.la`:

```lugha
struct Range { private lo: i64, private hi: i64 }

impl Range {
    fun new(a: i64, b: i64): Range =
        if a <= b { Range { lo: a, hi: b } } else { Range { lo: b, hi: a } };

    fun size(self): i64 = self.hi - self.lo;
}
```

Solution:

`src/main.la`:

```lugha
import range;

fun main() {
    let r = range.Range.new(5, 1);
    println(r.size());
}
```

`src/range.la`:

```lugha
struct Range { private lo: i64, private hi: i64 }

impl Range {
    fun new(a: i64, b: i64): Range =
        if a <= b { Range { lo: a, hi: b } } else { Range { lo: b, hi: a } };

    fun size(self): i64 = self.hi - self.lo;
}
```

Output (solution):

```text
4
```
