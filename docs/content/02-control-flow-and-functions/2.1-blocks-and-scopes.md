# 2.1 Blocks and scopes

## Objectives

After this lesson the learner can:

- Know a block `{ … }` has a value: its last expression without `;`. [L987]
- Know a `;` turns an expression into a statement and throws its value away. [L1049]
- Know a variable lives until the `}` of its block. [L987]
- Know `()` is the value of a block with nothing at the end. [L545, L561]

## Step 1: Block expressions
Kind: read

In the first lesson, `main`'s last line, written without a `;`, was the value it gave back.
Any block in braces works the same way, and lines 2 to 6 are one, with its value going into `total`.
Will line 2 compile, with a whole block after its `=`?
Press Run.

It does, and line 7 prints `46`.
If you expected an error, you were expecting braces to hold only statements.
A block's value is its last expression, written without a `;`, here `price + tax` on line 5.

```lugha
fun main() {
    let total = {
        let price = 40;
        let tax = 6;
        price + tax
    };
    println(total);
}
```

Output:

```text
46
```

## Step 2: Statements and ()
Kind: fix (start runs, prints `()`, with warning W0106 "`total` holds `()`")

Now line 5 ends with a `;`.
Will `total` still be `46`?
Press Run.

It prints `()`, with warning W0106, which says `total` holds `()`.
If you expected `46`, you were expecting the last line to count even with a `;` after it.
A `;` turns an expression into a statement, and whatever value it had is thrown away, so the block ends with nothing.
A block like that gives `()`, the value that means nothing was given back:

```lugha {5}
fun main() {
    let total = {
        let price = 40;
        let tax = 6;
        price + tax
    };
    println(total);
}
```

Remove the `;` on line 5 and run again, or press Solve.

## Step 3: Variable scope
Kind: fix (start gives E0301 "cannot find `price` in this scope")

`price` is declared inside the block, on line 3, and line 6 tries to print it after the block's `}`.
Press Run.

`lughac` refuses it with E0301, "cannot find `price` in this scope".
A variable declared in a block ends at the `}` that closes it, so by line 6 `price` doesn't exist.
What's left of the block is its value, in `total`:

```lugha {6}
fun main() {
    let total = {
        let price = 40;
        price + 6
    };
    println(total);
}
```

Print `total` on line 6 and run again.

Start:

```lugha
fun main() {
    let total = {
        let price = 40;
        price + 6
    };
    println(price);
}
```

Solution:

```lugha
fun main() {
    let total = {
        let price = 40;
        price + 6
    };
    println(total);
}
```

Output (solution):

```text
46
```
