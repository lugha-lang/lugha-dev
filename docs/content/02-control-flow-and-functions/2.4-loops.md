## Step 1: while loops
Kind: read

Where an `if` runs its block once, `while` runs it again and again while its condition is true, checking it before each run.
`seconds` starts at `3`, and line 5 takes one off each time round, so the loop runs three times and stops when `seconds > 0` is false.
Press Run.

```lugha
fun main() {
    let mut seconds = 3;
    while seconds > 0 {
        println(seconds);
        seconds -= 1;
    }
    println("go");
}
```

Output:

```text
3
2
1
go
```

## Step 2: for loops over ranges
Kind: read

`for` does the counting for you: `for i in 1..4` runs its block once for each number in the range `1..4`, with `i` set to that number.
Will the last one printed be `4`?
Press Run.

It prints `1`, `2` and `3`.
A range includes its first number and stops before its second, so `1..4` holds three numbers.
A range whose first number isn't smaller than its last, such as `4..4`, is empty, and the block doesn't run at all.

```lugha
fun main() {
    for i in 1..4 {
        println(i);
    }
}
```

Output:

```text
1
2
3
```

## Step 3: break and continue
Kind: read

Both loops can be cut short from inside.
`continue` skips the rest of the block and goes on to the next turn, and `break` ends the loop.
Here line 4 skips every multiple of 3, and line 7 ends the loop once `i` is past 7, though the range goes up to 9.
Run it and see where it stops.

```lugha
fun main() {
    for i in 1..10 {
        if i % 3 == 0 {
            continue;
        }
        if i > 7 {
            break;
        }
        println(i);
    }
}
```

Output:

```text
1
2
4
5
7
```

## Step 4: loop and break with a value
Kind: read

`loop` runs its block again and again until something leaves it, usually a `break`.
Like `if` and `match`, it's an expression, and `break n;` on line 6 ends it with `n` as its value.
Here it doubles `n` until it passes 100, so it prints `128`, the first number to do so.

A `while` or `for` can't give a value like this.
`break` with a value inside one is E0514 and won't compile, because those loops can also end without reaching a `break`.

```lugha
fun main() {
    let mut n = 1;
    let first = loop {
        n = n * 2;
        if n > 100 {
            break n;
        }
    };
    println(first);
}
```

Output:

```text
128
```

## Step 5: Loop labels
Kind: fix (start runs and prints seven lines, `1 1` to `3 3` without `2 2` and `2 3`)

One `for` runs inside another, printing each `row` and `col` pair, and line 5 should stop everything at the first pair whose product is 4.
The `break` there ends only the inner loop, the one it's in, so row 2 prints `2 1` and stops, and row 3 runs as normal.
To leave the outer loop, give it a label, a name followed by `:`, before its `for`, and name it after `break`:

```lugha {2,5}
fun main() {
    outer: for row in 1..4 {
        for col in 1..4 {
            if row * col == 4 {
                break outer;
            }
            println("{row} {col}");
        }
    }
}
```

`continue outer;` works the same way, going on to the outer loop's next turn.
Add `outer:` on line 2 and `outer` after `break` on line 5, or press Solve.

Start:

```lugha
fun main() {
    for row in 1..4 {
        for col in 1..4 {
            if row * col == 4 {
                break;
            }
            println("{row} {col}");
        }
    }
}
```

Solution:

```lugha
fun main() {
    outer: for row in 1..4 {
        for col in 1..4 {
            if row * col == 4 {
                break outer;
            }
            println("{row} {col}");
        }
    }
}
```

Output (start):

```text
1 1
1 2
1 3
2 1
3 1
3 2
3 3
```

Output (solution):

```text
1 1
1 2
1 3
2 1
```
