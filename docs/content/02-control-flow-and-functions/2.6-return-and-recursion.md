## Step 1: Early return
Kind: read

So far a function's value has been its last expression, but `return` ends a function straight away and gives back the value after it.
In `distance`, line 3 returns `from - to` when `to` is smaller, and the rest of the body is skipped.
Otherwise the function goes on to line 5, its last expression.
Press Run.

It prints `7` twice, once from each path.
`return to - from;` on line 5 would work too, but a function that reaches its end gives back its last expression without one.

```lugha
fun distance(from: i64, to: i64): i64 {
    if to < from {
        return from - to;
    }
    to - from
}

fun main() {
    println(distance(3, 10));
    println(distance(10, 3));
}
```

Output:

```text
7
7
```

## Step 2: Return checking
Kind: fix (start gives E0503 "`distance` may end without returning a value of type i64", help "end the body with a value, or `return` on every path")

Now the `if`s on lines 2 and 5 each hold a `return`.
Every pair of numbers takes one of the two, so is that enough for a function that promises an `i64`?

It gives E0503, "`distance` may end without returning a value of type i64", with the help "end the body with a value, or `return` on every path".
An `if` without an `else` never counts as returning, whatever its condition, so `lughac` sees a way to reach the last `}` with nothing to give back.
An `if` with an `else` counts when both branches return, and a last expression needs no `return` at all:

```lugha {5}
fun distance(from: i64, to: i64): i64 {
    if to < from {
        return from - to;
    }
    to - from
}

fun main() {
    println(distance(3, 10));
    println(distance(10, 3));
}
```

Replace lines 5 to 7 with `to - from`, or press Solve.

Start:

```lugha
fun distance(from: i64, to: i64): i64 {
    if to < from {
        return from - to;
    }
    if to >= from {
        return to - from;
    }
}

fun main() {
    println(distance(3, 10));
    println(distance(10, 3));
}
```

Solution:

```lugha
fun distance(from: i64, to: i64): i64 {
    if to < from {
        return from - to;
    }
    to - from
}

fun main() {
    println(distance(3, 10));
    println(distance(10, 3));
}
```

Output (solution):

```text

```

## Step 3: Returning from a loop
Kind: fix (start gives E0503 "`first_over` may end without returning a value of type i64", help "`while true` never counts as returning (spec §6); write `loop { … }`, which does when no `break` leaves it")

A loop can hide the same problem.
`first_over` doubles `n` until it passes `limit`, and returns it from inside a `while true` loop.
The condition is always true, so the loop can only end at the `return`.

`lughac` still gives E0503, "`first_over` may end without returning a value of type i64", because it never counts a `while` loop as returning, even `while true`.
As with the two `if`s in step 2, `lughac` doesn't look at the condition.
A `loop` that no `break` leaves does count, since the only way out is the `return`.
Write `loop` on line 3:

```lugha {3}
fun first_over(limit: i64): i64 {
    let mut n = 1;
    loop {
        n = n * 2;
        if n > limit {
            return n;
        }
    }
}

fun main() {
    println(first_over(100));
}
```

Start:

```lugha
fun first_over(limit: i64): i64 {
    let mut n = 1;
    while true {
        n = n * 2;
        if n > limit {
            return n;
        }
    }
}

fun main() {
    println(first_over(100));
}
```

Solution:

```lugha
fun first_over(limit: i64): i64 {
    let mut n = 1;
    loop {
        n = n * 2;
        if n > limit {
            return n;
        }
    }
}

fun main() {
    println(first_over(100));
}
```

Output (solution):

```text
128
```

## Step 4: Recursion
Kind: read

A function can also call itself, as long as one path gives a value without calling it again.
`factorial` on line 1 multiplies `n` by `factorial(n - 1)`, a call to itself.
Its body is one `if` expression, so it uses the `=` form from Functions.

Run it and it prints `120`, which is 5 × 4 × 3 × 2 × 1.
When `n` is `1` or less, the `if` gives `1` and doesn't call `factorial` again, so the calls stop there.

```lugha
fun factorial(n: i64): i64 = if n <= 1 { 1 } else { n * factorial(n - 1) };

fun main() {
    println(factorial(5));
}
```

Output:

```text
120
```
