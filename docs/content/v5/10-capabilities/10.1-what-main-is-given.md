## Step 1: Capabilities in main
Kind: read

Every program so far has taken `console: Console` and printed its output through it.
Files, the clock, environment variables, randomness, other programs and the network are reached the same way: through a value `main` is given, called a capability.
`debug` and `panic` write to standard error without one.
`main` takes the ones it needs as parameters, matched by type, with any names, in any order: `Console`, `Fs`, `Clock`, `Env`, `Entropy`, `Proc` and `Net`, and `string[]` for the program's arguments.
`main` on line 1 takes a `Clock` and then the `Console`, and line 2 reads the clock.
Press Run.

`monotonic_ms()` is a time for measuring how long something took; the rest of `Clock` is in Clock, Env and Entropy.

```lugha
fun main(clock: Clock, console: Console) {
    let start = clock.monotonic_ms();
    console.println("hello");
    console.println(clock.monotonic_ms() >= start);
}
```

Output:

```text
hello
true
```

## Step 2: Each one once
Kind: fix (start gives E0304 "`main` takes only `string[]`, the capabilities (`Console`, `Fs`, `Clock`, `Env`, `Proc`, `Entropy`, `Net`) and the root `Scope`, each at most once, and returns `()` or `i32`", help "for example `fun main(args: string[], console: Console): i32`")

Line 1 asks for two consoles, `console` and `out`.
Press Run.

`lughac` gives E0304: `main` takes each capability at most once, and nothing else except `string[]` and the root `Scope`, which Concurrency uses.
A parameter `main` can't be given, such as `n: i64`, is E0304 too.
Remove `, out: Console` from line 1, or press Solve.

Start:

```lugha
fun main(console: Console, out: Console) {
    console.println("hello");
}
```

Solution:

```lugha
fun main(console: Console) {
    console.println("hello");
}
```

Output (solution):

```text
hello
```

## Step 3: Passing capabilities on
Kind: read

As `greet` took the console in Functions, `timed` on line 1 takes a `Console` and a `Clock` as ordinary parameters, and `main` passes its own on line 9.
There's no `println`, clock or file function to call without one: as in Hello, world, a bare `println` is E0471.
Press Run.

```lugha
fun timed(console: Console, clock: Clock, label: string) {
    let start = clock.monotonic_ms();
    console.println("working on {label}");
    let took = clock.monotonic_ms() - start;
    console.println(took >= 0);
}

fun main(console: Console, clock: Clock) {
    timed(console, clock, "the report");
}
```

Output:

```text
working on the report
true
```

## Step 4: Arguments
Kind: read

`args: string[]` on line 1 is what the program was started with, the program's own path first.
Line 2 prints how many there are, and lines 3 to 6 stop with exit code 1 when no name follows the path.
Line 7 greets each name, skipping the path with `skip(1)` from Iterators.
Here the program is started with no arguments after its path.
Press Run.

So it prints the usage line and exits with 1.
In the Playground, the input tab passes arguments: with `Ann Ben` it prints `3`, `hello, Ann` and `hello, Ben`.

```lugha
fun main(args: string[], console: Console): i32 {
    console.println(args.len);
    if args.len < 2 {
        console.println("usage: greet NAME");
        return 1;
    }
    for name of args.iter().skip(1) {
        console.println("hello, {name}");
    }
    0
}
```

Output (exit 1):

```text
1
usage: greet NAME
```
