1. **Capabilities are interfaces**: `impl Clock for FixedClock`. [capabilities]
2. **Using a fake**: a function taking `Clock` gets the fake. [capabilities]

## Step 1: Capabilities are interfaces
Kind: fix (start gives E0422 "`impl Clock for FixedClock` doesn't match `Clock`" on line 3, help "no method `local_offset`")

Each capability is an interface, so a type of your own can implement it.
`FixedClock` on line 1 is a clock that always says the same time, and `impl Clock for FixedClock` on lines 3 to 6 gives it `now_ms` and `monotonic_ms`.
Line 11 puts one in a variable of type `Clock`, an interface value.
Press Run.

The program doesn't run.
E0422 on line 3 says the `impl` "doesn't match `Clock`", and its help names what's missing: "no method `local_offset`".
Besides the two methods shown earlier, `Clock` has a third, `local_offset`: the local time's offset from UTC at a moment, in seconds.
An `impl` has to write every method the interface doesn't give a default for.
After line 5, add `fun local_offset(self, ms: i64): Result<i64, string> = Ok(0);`, an offset of 0, and run again, or press Solve.

Error note: `impl Clock for FixedClock` has to write every method of `Clock`, and `Clock` has three. Lines 4 and 5 write `now_ms` and `monotonic_ms`, but nothing writes `local_offset`.

Start:

```lugha
struct FixedClock { at: i64 }

impl Clock for FixedClock {
    fun now_ms(self): i64 = self.at;
    fun monotonic_ms(self): i64 = 0;
}

fun main(console: Console) {
    let clock = FixedClock { at: 1767225600000 };
    console.println(clock.now_ms());
    let as_clock: Clock = clock;
    console.println(as_clock.monotonic_ms());
}
```

Solution:

```lugha
struct FixedClock { at: i64 }

impl Clock for FixedClock {
    fun now_ms(self): i64 = self.at;
    fun monotonic_ms(self): i64 = 0;
    fun local_offset(self, ms: i64): Result<i64, string> = Ok(0);
}

fun main(console: Console) {
    let clock = FixedClock { at: 1767225600000 };
    console.println(clock.now_ms());
    let as_clock: Clock = clock;
    console.println(as_clock.monotonic_ms());
}
```

Output (solution):

```text
1767225600000
0
```

## Step 2: Using a fake
Kind: read

`greeting` on line 9 takes a `Clock`, works out the hour in UTC from `now_ms()` on line 10, and picks a greeting on line 11.
It only calls `now_ms()`, so any `Clock` will do.
Lines 15 and 16 give it a `FixedClock` at 08:00 and at 14:00 UTC on 1 January 2026, and line 17 the real clock `main` was given.
Press Run.

The fake at 08:00 gives `good morning`, and the one at 14:00 `good afternoon`.
The real clock's answer depends on when the program runs, so line 18 prints only whether it's one of the two, and it is: `true`.

```lugha
struct FixedClock { at: i64 }

impl Clock for FixedClock {
    fun now_ms(self): i64 = self.at;
    fun monotonic_ms(self): i64 = 0;
    fun local_offset(self, ms: i64): Result<i64, string> = Ok(0);
}

fun greeting(clock: Clock): string {
    let hour = clock.now_ms() / 3600000 % 24;
    if hour < 12 { "good morning" } else { "good afternoon" }
}

fun main(console: Console, clock: Clock) {
    console.println(greeting(FixedClock { at: 1767254400000 }));
    console.println(greeting(FixedClock { at: 1767276000000 }));
    let now = greeting(clock);
    console.println(now == "good morning" || now == "good afternoon");
}
```

Output:

```text
good morning
good afternoon
true
```
