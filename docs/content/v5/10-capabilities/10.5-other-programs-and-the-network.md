## Step 1: Proc
Kind: read

A `Proc` starts other programs.
`proc.run(cmd, args)` on line 2 runs `echo` with two arguments, `hello` and `$HOME; rm -rf /`, and gives an `Ok(ProcessOutput)`, with its exit `code`, its `stdout` and its `stderr`.
`run_with` on line 4 also writes to the program's input, here two lines for `sort`.
Line 6 starts `sh` as an ordinary program, with `-c` and `exit 3` as its arguments, to get an exit code of 3, and line 8 names a program that doesn't exist.
Press Run.

Line 3 prints `$HOME; rm -rf /` exactly as it was written: each argument goes to the program as it is, with no shell in between, so `$HOME` isn't replaced and `;` doesn't start a second command.
Line 7 prints `3`: any exit code counts as `Ok`, so `unwrap` on line 6 gets the output.
Line 8's program doesn't exist, so it couldn't be started: that's an `Err`, holding the system's own message, as in Files.

```lugha
fun main(console: Console, proc: Proc) {
    let out = proc.run("echo", ["hello", "$HOME; rm -rf /"]).unwrap();
    console.println("{out.code} {out.stdout.trim()}");
    let sorted = proc.run_with("sort", [], "pear\napple\n").unwrap();
    console.println(sorted.stdout.lines().join(","));
    let failed = proc.run("sh", ["-c", "exit 3"]).unwrap();
    console.println(failed.code);
    console.println(proc.run("no-such-program-x", []).debug());
}
```

Output:

```text
0 hello $HOME; rm -rf /
apple,pear
3
Err("no-such-program-x: No such file or directory")
```

## Step 2: Net
Kind: read

A `Net` reaches the network: `net.connect("example.com:80")` on line 2 opens a connection to a host and port, and gives `Ok(Conn)` or an `Err`.
The programs on this site run without a network.
Press Run.

So the connection is an `Err`, and line 4 prints the system's own message: the name `example.com` couldn't be looked up.

```lugha
fun main(console: Console, net: Net) {
    match net.connect("example.com:80") {
        .Ok(_) => console.println("connected"),
        .Err(e) => console.println("can't connect: {e}"),
    }
}
```

Output:

```text
can't connect: Temporary failure in name resolution
```

- Every program was run in the drafting sandbox (lughac 0.18.0 at m239).
- **Objective 3, "What a started program can do", was dropped (owner, 2026-11-21): it can't be shown in the sandbox.** The spec (process lockdown, m189) says a started program gets only the kinds of access `main` took: without `Fs` it can't open files (Landlock), and without `Net` it can't make a socket (seccomp). Run in the sandbox: with only `Console` and `Proc`, `cat src/main.la` exits 0 and prints the file, and `sh -c "echo hi > made.txt"` writes it (gVisor doesn't apply Landlock); `bash -c 'exec 3<>/dev/tcp/127.0.0.1/9'` is "socket: Operation not permitted" both without `Net` and with it (the container refuses sockets itself), so the difference never shows. A step built on these runs would show the opposite of the objective, or nothing.
