## Step 1: Clock
Kind: read

A `Clock` tells the time two ways.
`now_ms()` on line 2 is the current time, as milliseconds since the start of 1970 (UTC), and line 3 checks it's past mid-November 2023.
`monotonic_ms()` on lines 4 and 9 counts from no particular moment, but never goes back, so the difference between two readings is how long the loop on lines 6 to 8 took.
Line 10 prints the loop's total, so the loop has real work to do.
How long it took changes from run to run, so line 11 prints only whether it's at least 0.
Press Run.

```lugha
fun main(console: Console, clock: Clock) {
    let now = clock.now_ms();
    console.println(now > 1700000000000);
    let start = clock.monotonic_ms();
    let mut total = 0;
    for i in 0..1000000 {
        total += i % 7;
    }
    let took = clock.monotonic_ms() - start;
    console.println(total);
    console.println(took >= 0);
}
```

Output:

```text
true
2999997
true
```

## Step 2: Env
Kind: read

An `Env` reads the program's environment variables.
`get(name)` gives an `Option<string>`: `Some` with the value, or `None` when the variable isn't set (or can't be read as text), so `greeting` on line 1 matches on it, and line 11 prints what it gives.
Line 9 asks whether `PATH` is set, and line 10 asks for a variable nobody sets.
`env.only(["HOME"])` on line 12 gives a narrower `Env` that reads only `HOME`, and line 13 asks it for `PATH`.
Here the program runs with `PATH` set and `USER` not set.
Press Run.

So `greeting` takes its `None` arm, and through `narrow`, `PATH` looks unset.

```lugha
fun greeting(env: Env): string {
    match env.get("USER") {
        .Some(name) => "hello, {name}",
        .None => "hello, whoever you are",
    }
}

fun main(console: Console, env: Env) {
    console.println(env.get("PATH").is_some());
    console.println(env.get("NO_SUCH_VARIABLE").debug());
    console.println(greeting(env));
    let narrow = env.only(["HOME"]);
    console.println(narrow.get("PATH").debug());
}
```

Output:

```text
true
None
hello, whoever you are
None
```

## Step 3: Entropy and random numbers
Kind: read

An `Entropy` gives random bytes from the system: `entropy.bytes(16)` on line 4 is 16 of them, the kind to use for keys and tokens.
For ordinary random numbers, `import std.random;` on line 1 brings in the standard library's `random` module, used as `random.` on lines 6, 9 and 10 (Modules covers `import`), and `random.from_entropy(entropy)` on line 6 seeds a generator from the system.
`rng.between(1, 7)` on line 7 is a whole number from 1 up to 6, which can change from run to run, and `rng` is `let mut` because every `Rng` method takes `mut self`: each call moves it on.
`random.seeded(42)` on lines 9 and 10 seeds from a number instead: two generators with the same seed give the same numbers in the same order, so line 11 compares two equal rolls.
Press Run.

```lugha
import std.random;

fun main(console: Console, entropy: Entropy) {
    let key = entropy.bytes(16);
    console.println(key.len);
    let mut rng = random.from_entropy(entropy);
    let roll = rng.between(1, 7);
    console.println(roll >= 1 && roll < 7);
    let mut fixed = random.seeded(42);
    let mut again = random.seeded(42);
    console.println(fixed.between(1, 7) == again.between(1, 7));
}
```

Output:

```text
16
true
true
```
