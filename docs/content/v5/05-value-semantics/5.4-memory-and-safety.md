# 5.4 Memory and safety (v5, Lugha v18)

## Objectives

1. **Memory safety** *(v4 kept)*: no null, no dangling pointer, no reading past an array. [values-and-types]
2. **Variable initialization** *(v4 kept)*: `let total: i64;` is E0201. [values-and-types]
3. **Reference counting** *(changed; was "Garbage collection")*: each value is freed when its last holder goes; you never free anything. [m193]

## Step 1: Memory safety
Kind: read

`numbers` on line 1 builds an array on line 2 and returns it, and line 7 keeps it in `kept` after `numbers` has finished.
The array stays as long as `kept` holds it.
Press Run.

It prints `[1, 2, 3]`: the array's memory is given back only once nothing holds it, so `kept` doesn't reach memory that was freed.
Option showed that there's no null, and Bounds checking that reading past the end of an array stops the program.

```lugha
fun numbers(): i64[] {
    let xs = [1, 2, 3];
    xs
}

fun main(console: Console) {
    let kept = numbers();
    console.println(kept.debug());
}
```

Output:

```text
[1, 2, 3]
```

## Step 2: Variable initialization
Kind: fix (start gives E0201 "expected `=`, found `;`")

`total` on line 2 has a type but no value, and the loop adds each number to it.
Press Run.

`lughac` stops at line 2 with E0201, "expected `=`, found `;`".
A `let` always gives its variable a value, so no line can read one that was never set.
Add `= 0` after `i64` on line 2, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let mut total: i64;
    for n of [3, 4, 5] {
        total += n;
    }
    console.println(total);
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut total: i64 = 0;
    for n of [3, 4, 5] {
        total += n;
    }
    console.println(total);
}
```

Output (solution):

```text
12
```

## Step 3: Reference counting
Kind: read

Step 1's array outlived `numbers`, so something has to give its memory back once nothing needs it.
Every variable, field or element that holds an array, a string or a box counts as one of its holders, and when the last one lets go, its memory is freed.
Line 4 makes a new array of 100 numbers on every pass, a hundred thousand in all, and only `row` holds it.
`row` is last used on line 5, at the end of the pass, so each array is freed there, before the next is made.
Press Run.

It prints `10000000`, and the program never had to say which arrays it was done with: the compiler puts in the counting.

```lugha
fun main(console: Console) {
    let mut total = 0;
    for i in 0..100000 {
        let row = [i; 100];
        total += row.len;
    }
    console.println(total);
}
```

Output:

```text
10000000
```
