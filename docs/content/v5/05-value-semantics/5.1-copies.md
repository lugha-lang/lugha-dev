## Step 1: Copies
Kind: read

Assigning a struct, an array or an enum gives you your own copy.
`b` on line 5 starts as a copy of `a`, and line 6 changes `b.x`.
Press Run and look at what `a` prints.

`a` still has `x: 1`.
Changing `b` never touched it: they are two separate values.

```lugha
struct Point { x: i64, y: i64 }

fun main(console: Console) {
    let a = Point { x: 1, y: 2 };
    let mut b = a;
    b.x = 9;
    console.println(a.debug());
    console.println(b.debug());
}
```

Output:

```text
Point { x: 1, y: 2 }
Point { x: 9, y: 2 }
```

## Step 2: Mutable copies
Kind: fix (start gives E0501 "cannot assign to `b`: it is not mutable", help "make it mutable: `let mut b`")

This time `a` is declared `let mut`, and its copy `b` on line 5 has no `mut`.
Line 6 changes `b.x`.
Press Run.

E0501 says `b` is not mutable: it doesn't take its `mut` from `a`.
`mut` belongs to a variable, and `b` is a variable of its own, so it needs its own `mut` whatever `a` has.
Add `mut` after `let` on line 5, or press Solve.

Start:

```lugha
struct Point { x: i64, y: i64 }

fun main(console: Console) {
    let mut a = Point { x: 1, y: 2 };
    let b = a;
    b.x = 9;
    console.println(a.debug());
    console.println(b.debug());
}
```

Solution:

```lugha
struct Point { x: i64, y: i64 }

fun main(console: Console) {
    let mut a = Point { x: 1, y: 2 };
    let mut b = a;
    b.x = 9;
    console.println(a.debug());
    console.println(b.debug());
}
```

Output (solution):

```text
Point { x: 1, y: 2 }
Point { x: 9, y: 2 }
```

## Step 3: Copying arrays
Kind: read

Arrays follow the same rule.
`ys` on line 3 starts as a copy of `xs`, and line 4 pushes onto `ys`.
Press Run.

Line 5 prints `[5, 6]`, because `let mut ys = xs` gave `ys` an array of its own, not a second name for the one in `xs`.

```lugha
fun main(console: Console) {
    let xs = [5, 6];
    let mut ys = xs;
    ys.push(1);
    console.println(xs.debug());
    console.println(ys.debug());
}
```

Output:

```text
[5, 6]
[5, 6, 1]
```

## Step 4: Passing by value
Kind: fix (start prints `[5, 6]`)

Function arguments follow the same rule: a parameter written without `mut`, like `xs` here, is a copy of what the caller passed.
`add_one` can't change its parameter, so line 2 copies `xs` into `ys`, and it pushes onto that and returns it.
Line 9 calls `add_one` but throws away what it returns.
Press Run.

Line 10 prints `xs` as it was, `[5, 6]`.
To keep the result, assign it back: make line 9 `xs = add_one(xs);`, or press Solve.
Through a plain parameter a function can't change its caller's values, so to keep what `add_one` built, the caller assigns what it returns.

Start:

```lugha
fun add_one(xs: i64[]): i64[] {
    let mut ys = xs;
    ys.push(1);
    ys
}

fun main(console: Console) {
    let mut xs = [5, 6];
    add_one(xs);
    console.println(xs.debug());
}
```

Output (start):

```text
[5, 6]
```

Solution:

```lugha
fun add_one(xs: i64[]): i64[] {
    let mut ys = xs;
    ys.push(1);
    ys
}

fun main(console: Console) {
    let mut xs = [5, 6];
    xs = add_one(xs);
    console.println(xs.debug());
}
```

Output (solution):

```text
[5, 6, 1]
```

## Step 5: Copies in a function call
Kind: read

Line 9 passes `xs` to `add_one` and names what comes back `zs`.
Lines 10 and 11 print both.
Press Run.

Line 10 prints `xs` as it was, since `add_one` changed only its own copy, and line 11 prints `zs`, with the `1` pushed on.

```lugha
fun add_one(xs: i64[]): i64[] {
    let mut ys = xs;
    ys.push(1);
    ys
}

fun main(console: Console) {
    let xs = [5, 6];
    let zs = add_one(xs);
    console.println(xs.debug());
    console.println(zs.debug());
}
```

Output:

```text
[5, 6]
[5, 6, 1]
```

## Step 6: Copy-on-write
Kind: read

Copying an array takes the same time however long it is, because at first the copy shares the original's memory.
Line 3 copies `big`, a million numbers, that way.
Line 4 writes to `copy`, so line 4 is where `copy` gets a million numbers of its own.
This is called copy-on-write, and no program can tell it from a full copy.
Press Run.

Line 5 still prints `0`.

```lugha
fun main(console: Console) {
    let big = [0; 1000000];
    let mut copy = big;
    copy[0] = 1;
    console.println(big[0]);
    console.println(copy[0]);
}
```

Output:

```text
0
1
```
