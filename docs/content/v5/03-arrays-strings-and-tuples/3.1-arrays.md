# 3.1 Arrays (v5, Lugha v18)

## Objectives

1. **Array literals** *(v4 kept)*: `[1, 2, 3]`, `[0; 10]`, and `.len`. [collections]
2. **Printing arrays** *(new)*: an array has no `Display`: `console.println(xs)` is E0422, `xs.debug()` gives `[1, 2, 3]`. [collections; m170]
3. **Indexing** *(v4 kept)*: `xs[i]`, and writing needs `let mut`. [collections]
4. **Bounds checking** *(v4 kept)*: the program stops with the length and the index. [collections]
5. **push and clear** *(v4 kept)*. [collections]
6. **Empty arrays** *(v4 kept)*: `let xs: i64[] = [];`. [collections]
7. **for … of loops** *(changed)*: `for x of xs`; `in` is for ranges only; the loop goes over the array as it was when it started, so the body may change `xs`. [collections; m224]
8. **Changing elements in a loop** *(v4 kept)*: `for x of mut xs`; changing `xs` itself there is E0507. [collections]
9. **Array concatenation and equality** *(v4 kept)*: `+` and `==`. [collections]
10. **debug** *(new)*: `debug(x)` writes `[file:line] x = …` to stderr and gives `x` back, so it goes inside an expression; no `Console` needed. [m170]

## Step 1: Array literals
Kind: read

An array holds values of one type in order, written in square brackets, as on line 2.
Line 3 uses the other way to write one, `[value; count]`: four elements, each a copy of `0`.
`.len`, written without parentheses, is the number of elements.
Press Run.

It prints `3` and `4`.
`scores` is an `i64[]`, an array of `i64`.

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    let zeros = [0; 4];
    console.println(scores.len);
    console.println(zeros.len);
}
```

Output:

```text
3
4
```

## Step 2: Printing arrays
Kind: fix (start gives E0422 "`i64[]` doesn't implement `Display`" on lines 4 and 5, help "it has no text of its own: show its debug form with `.debug()`")

Lines 4 and 5 now print the arrays themselves.
Press Run.

`lughac` gives E0422 for both: an array has no text of its own to print.
`.debug()` gives an array's debug form, the way a programmer reads it, as a string `console.println` can print.
Add `.debug()` after `scores` on line 4 and after `zeros` on line 5, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    let zeros = [0; 4];
    console.println(scores);
    console.println(zeros);
}
```

Solution:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    let zeros = [0; 4];
    console.println(scores.debug());
    console.println(zeros.debug());
}
```

Output (solution):

```text
[70, 85, 90]
[0, 0, 0, 0]
```

## Step 3: Indexing
Kind: fix (start gives E0501 "cannot assign to `scores`: it is not mutable", help "make it mutable: `let mut scores`")

Line 3 tries to change the second element of an array declared with plain `let`.
Line 4 reads the first, `scores[0]`, because indexes count from `0`.
Press Run.

E0501 says "cannot assign to `scores`: it is not mutable".
Changing one element changes the array, so the array needs `let mut`, like any variable you change.
Add `mut` after `let` on line 2, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    scores[1] = 88;
    console.println(scores[0]);
    console.println(scores.debug());
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut scores = [70, 85, 90];
    scores[1] = 88;
    console.println(scores[0]);
    console.println(scores.debug());
}
```

Output (solution):

```text
70
[70, 88, 90]
```

## Step 4: Bounds checking
Kind: fix (start prints `70`, then panics "index out of bounds: the length is 3 but the index is 3", exit 101)

Line 4 tries to print the last score with `scores[scores.len]`.
Press Run.

After `70`, the program panics with "index out of bounds: the length is 3 but the index is 3" and exits with code 101.
With indexes counting from `0`, the last one is `.len - 1`.
Change line 4's index to `scores.len - 1`, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    console.println(scores[0]);
    console.println(scores[scores.len]);
}
```

Output (start; stderr `panic: index out of bounds: the length is 3 but the index is 3 at src/main.la:4:27`, exit 101):

```text
70
```

Solution:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    console.println(scores[0]);
    console.println(scores[scores.len - 1]);
}
```

Output (solution):

```text
70
90
```

## Step 5: push and clear
Kind: read

An array can grow and shrink.
`push` on line 3 adds an element at the end, and `clear` on line 6 removes them all.
Both change `list`, so it's declared with `let mut`.
Press Run.

A string inside a debug form keeps its quotes, so line 4 prints `["milk", "bread"]`.

```lugha
fun main(console: Console) {
    let mut list = ["milk"];
    list.push("bread");
    console.println(list.debug());
    console.println(list.len);
    list.clear();
    console.println(list.len);
}
```

Output:

```text
["milk", "bread"]
2
0
```

## Step 6: Empty arrays
Kind: fix (start gives E0412 "cannot infer the element type of `[]`", help "annotate it: `let xs: i64[] = [];`")

Now the list starts empty, and line 3 pushes a string into it.
Press Run.

E0412 says `lughac` "cannot infer the element type of `[]`".
`[]` has no elements to take a type from, and `lughac` doesn't look ahead to line 3 for one.
Write the type after a colon: add `: string[]` after `list` on line 2, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let mut list = [];
    list.push("milk");
    console.println(list.debug());
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut list: string[] = [];
    list.push("milk");
    console.println(list.debug());
}
```

Output (solution):

```text
["milk"]
```

## Step 7: for … of loops
Kind: fix (start gives E0201 "expected `..`, found `{`")

Line 3 loops over `scores` with `for score in scores`, the way the Loops lesson counted over a range.
Press Run.

After `in`, `lughac` wants a range such as `0..3`, so it reads `scores` as the start of one and gives E0201, "expected `..`, found `{`".
`of` goes through an array, giving each element in turn.
Change `in` to `of` on line 3, or press Solve.
A `let mut` array can grow inside its own loop: the loop goes over the array as it was when it began, so it still ends.

Start:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    for score in scores {
        console.println(score);
    }
}
```

Solution:

```lugha
fun main(console: Console) {
    let scores = [70, 85, 90];
    for score of scores {
        console.println(score);
    }
}
```

Output (solution):

```text
70
85
90
```

## Step 8: Changing elements in a loop
Kind: fix (start gives E0501 "cannot assign to `score`: it is not mutable", help "loop variables are immutable; copy it into a `let mut`")

Line 4 tries to add 5 to every score as the loop goes through them, and `scores` is `let mut`.
Press Run.

The loop variable is the problem: E0501, "cannot assign to `score`: it is not mutable".
The help suggests a copy in a `let mut`, which would change only the copy.
To change the array itself, loop over it with `of mut`: then `score` is each element itself, and adding to it adds to that element.
Add `mut` after `of` on line 3, or press Solve.
Inside a `for … of mut` the array can't grow or shrink, and `scores.push(1)` there is E0507.

Start:

```lugha
fun main(console: Console) {
    let mut scores = [70, 85, 90];
    for score of scores {
        score += 5;
    }
    console.println(scores.debug());
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut scores = [70, 85, 90];
    for score of mut scores {
        score += 5;
    }
    console.println(scores.debug());
}
```

Output (solution):

```text
[75, 90, 95]
```

## Step 9: Array concatenation and equality
Kind: read

`+` on line 4 joins two arrays of the same type into a new one.
Line 6 compares the result with `==`.
Press Run.

It prints `true`, because `==` compares arrays element by element, in order.

```lugha
fun main(console: Console) {
    let first = [1, 2];
    let second = [3];
    let both = first + second;
    console.println(both.debug());
    console.println(both == [1, 2, 3]);
}
```

Output:

```text
[1, 2, 3]
true
```

## Step 10: debug
Kind: read

`debug(x)` on line 3 writes `x` to standard error, with the file and line, and gives `x` back.
It needs no `Console`, so any function can use it, and since it gives `x` back it can go inside an expression.
Press Run.

Line 3 writes `[src/main.la:3] price * 3 = 30`, and `debug` gives `30` back, so `total` is `31`.
Unlike `.debug()`, it writes the value out itself and gives back the value, not a string.
The output pane shows standard error as well, which is where this line goes.

```lugha
fun main(console: Console) {
    let price = 10;
    let total = debug(price * 3) + 1;
    console.println(total);
}
```

Output (stdout; stderr `[src/main.la:3] price * 3 = 30`):

```text
31
```
