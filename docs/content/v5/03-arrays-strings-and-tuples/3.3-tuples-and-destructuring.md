## Step 1: Tuples
Kind: read

A tuple groups a fixed number of values, each with its own type.
Line 2 makes one from a string and a number, in parentheses.
A tuple prints through `.debug()`, as an array does, and `console.println(item)` alone is E0422.
Its elements are read by position, with `.0` and `.1` on lines 4 and 5.
Press Run.

In the tuple's debug form the string keeps its quotes, but `item.0` on line 4 prints `milk` without them.

```lugha
fun main(console: Console) {
    let item = ("milk", 2);
    console.println(item.debug());
    console.println(item.0);
    console.println(item.1);
}
```

Output:

```text
("milk", 2)
milk
2
```

## Step 2: Multiple return values
Kind: read

A function can give back more than one value by returning a tuple.
`divmod` on line 1 gives back the quotient and the remainder together, so its return type is the tuple type `(i64, i64)`.
A tuple type lists each element's type, so step 1's `item` has the type `(string, i64)`.
Press Run.

The caller gets both at once, and the next step names them.

```lugha
fun divmod(a: i64, b: i64): (i64, i64) = (a / b, a % b);

fun main(console: Console) {
    let result = divmod(17, 5);
    console.println(result.debug());
}
```

Output:

```text
(3, 2)
```

## Step 3: Destructuring with let
Kind: fix (start gives E0201 "expected variable name, found `(`")

Instead of `.0` and `.1`, a `let` can give each element a name of its own.
Line 4 names both parts of `divmod(17, 7)` with `let mut (weeks, days)`, because line 5 adds a day.
Press Run.

`lughac` gives E0201, "expected variable name, found `(`": `mut` can't go before the parentheses.
It goes inside them, before each name that will change, and here only `days` does.
Make line 4 `let (weeks, mut days)`, or press Solve.

Start:

```lugha
fun divmod(a: i64, b: i64): (i64, i64) = (a / b, a % b);

fun main(console: Console) {
    let mut (weeks, days) = divmod(17, 7);
    days += 1;
    console.println("{weeks} weeks and {days} days");
}
```

Solution:

```lugha
fun divmod(a: i64, b: i64): (i64, i64) = (a / b, a % b);

fun main(console: Console) {
    let (weeks, mut days) = divmod(17, 7);
    days += 1;
    console.println("{weeks} weeks and {days} days");
}
```

Output (solution):

```text
2 weeks and 4 days
```

## Step 4: Destructuring in loops
Kind: read

The same parentheses work after `for`.
`people` on line 2 is an array of tuples, and line 3 names the two elements of each tuple `name` and `age`.
Press Run.

```lugha
fun main(console: Console) {
    let people = [("Ann", 31), ("Ben", 25)];
    for (name, age) of people {
        console.println("{name} is {age}");
    }
}
```

Output:

```text
Ann is 31
Ben is 25
```

## Step 5: Tuple patterns
Kind: read

A `match` can look inside a tuple too, and line 2 puts `x` and `y` into one so that a single `match` checks both.
Each arm's pattern is a tuple of patterns, and `_` inside one matches anything in that position.
`(0, _)` on line 4 matches any point whose `x` is `0`, the origin included.
Arms are tried from the top, so `(0, 0)` on line 3 comes first, or the origin would land in the y-axis arm.
As in any `match`, the arms must cover every case, which the `_` on line 6 does.
Press Run.

```lugha
fun describe(x: i64, y: i64): string {
    match (x, y) {
        (0, 0) => "the origin",
        (0, _) => "on the y axis",
        (_, 0) => "on the x axis",
        _ => "somewhere else",
    }
}

fun main(console: Console) {
    console.println(describe(0, 4));
    console.println(describe(2, 3));
}
```

Output:

```text
on the y axis
somewhere else
```
