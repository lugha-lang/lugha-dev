## Step 1: if let
Kind: read

A `match` with only one case worth handling can be written as an `if let`.
Line 3 tests one pattern, `.Some(n)`, with its dot as in any pattern, against what `parse_i64` gives back.
When it matches, the block runs with `n` in scope, and otherwise line 5, in the `else` block, runs.
There's no `.None` arm to write, because an `if let` doesn't have to cover every case.
The `else` is optional, and without it nothing runs when the pattern doesn't match.
Press Run.

```lugha
fun main(console: Console) {
    for typed of ["12", "twelve"] {
        if let .Some(n) = parse_i64(typed) {
            console.println("{n} doubled is {n * 2}");
        } else {
            console.println("{typed} isn't a number");
        }
    }
}
```

Output:

```text
12 doubled is 24
twelve isn't a number
```

## Step 2: while let
Kind: read

`while let` repeats for as long as its pattern matches.
Line 3 pops from `stack` before each pass, and `top` takes each element in turn, from the last.
Once the array is empty, `pop` gives `None` and the loop ends.
Press Run.

Line 6 prints the array, empty now.

```lugha
fun main(console: Console) {
    let mut stack = [1, 2, 3];
    while let .Some(top) = stack.pop() {
        console.println(top);
    }
    console.println(stack.debug());
}
```

Output:

```text
3
2
1
[]
```

## Step 3: let else
Kind: fix (start gives E0429 "the `else` of a `let … else` must not finish", help "end it with `return`, `break`, `continue`, `panic(…)` or `exit(…)`")

`let … else` keeps its bindings in scope for the rest of the block, where `if let`'s `n` exists only inside its own block.
Its `else` runs when the pattern doesn't match, and the whole `let … else` ends with `;` on line 4.
Line 2 names the number `n`, and the `console.println` on line 5 uses it.
Press Run.

E0429: "the `else` of a `let … else` must not finish".
If the `else` block ended normally, line 5 would run with no `n` to read.
So the block has to leave, here with `return;`, which ends `report` without a value.
Add `return;` as a new line after line 3, or press Solve.

Start:

```lugha
fun report(console: Console, typed: string) {
    let .Some(n) = parse_i64(typed) else {
        console.println("{typed} isn't a number");
    };
    console.println("{n} doubled is {n * 2}");
}

fun main(console: Console) {
    report(console, "12");
    report(console, "twelve");
}
```

Solution:

```lugha
fun report(console: Console, typed: string) {
    let .Some(n) = parse_i64(typed) else {
        console.println("{typed} isn't a number");
        return;
    };
    console.println("{n} doubled is {n * 2}");
}

fun main(console: Console) {
    report(console, "12");
    report(console, "twelve");
}
```

Output (solution):

```text
12 doubled is 24
twelve isn't a number
```

## Step 4: Nested patterns
Kind: read

`describe` on line 7 takes an `Option<Shape>`.
In `.Some(.Circle(r))` on line 9, the data inside the `Some` is matched with a pattern of its own, with its own dot.
The arm matches only a `Some` holding a circle, and names its radius `r`.
The arms cover each shape inside a `Some`, and then `.None`.
Line 18 pops the one circle from `shapes`, and line 19 pops again from the empty array.
Press Run.

```lugha
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun describe(s: Option<Shape>): string {
    match s {
        .Some(.Circle(r)) => "a circle of radius {r}",
        .Some(.Rect(w, h)) => "a {w} by {h} rectangle",
        .Some(.Empty) => "an empty shape",
        .None => "nothing",
    }
}

fun main(console: Console) {
    let mut shapes = [Shape.Circle(1.5)];
    console.println(describe(shapes.pop()));
    console.println(describe(shapes.pop()));
}
```

Output:

```text
a circle of radius 1.5
nothing
```

## Step 5: mut bindings
Kind: fix (start gives E0501 "cannot assign to `n`: it is not mutable", help "match bindings are immutable; copy it into a `let mut`")

Line 5 adds 1 to `n`, the number inside `count`.
Press Run.

E0501 says `n` is not mutable: names in a pattern are read-only, like parameters.
The help suggests copying `n` into a `let mut`.
`mut` before the name in the pattern does that in one step, giving the arm its own copy to change.
`count` itself stays `Some(4)`, as line 10 shows.
Change `.Some(n)` on line 4 to `.Some(mut n)`, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let count: Option<i64> = Some(4);
    match count {
        .Some(n) => {
            n += 1;
            console.println(n);
        }
        .None => console.println("no count"),
    }
    console.println(count.debug());
}
```

Solution:

```lugha
fun main(console: Console) {
    let count: Option<i64> = Some(4);
    match count {
        .Some(mut n) => {
            n += 1;
            console.println(n);
        }
        .None => console.println("no count"),
    }
    console.println(count.debug());
}
```

Output (solution):

```text
5
Some(4)
```

## Step 6: Names in patterns
Kind: fix (start runs with warnings W0103 "unused binding `Emtpy`", help "if you meant a variant, write it with a dot and check its spelling; otherwise write `_`", and W0102 "unreachable match arm" on lines 10 and 11)

Line 16 describes a circle.
Press Run.

It prints `an empty shape`.
`Emtpy` on line 9 is misspelled and has no dot, and a bare name in a pattern is always a new binding, even when it is the whole pattern rather than part of a variant.
Spelled right, a bare `Empty` is E0468, as in Enums, but `Emtpy` is no variant's name, so it's read as a binding.
A binding matches any shape, and line 9 comes first, so every shape stops there.
`lughac` warns with W0103, "unused binding `Emtpy`", and marks lines 10 and 11 unreachable with W0102.
With the dot, a misspelling is an error instead: `.Emtpy` is E0415, "no variant `Emtpy` on `Shape`".
Write `.Empty` on line 9, or press Solve.
A bare name written on purpose, as in `other =>`, catches every value the arms above it didn't and names it.

Start:

```lugha
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun describe(s: Shape): string {
    match s {
        Emtpy => "an empty shape",
        .Circle(r) => "a circle of radius {r}",
        .Rect(w, h) => "a {w} by {h} rectangle",
    }
}

fun main(console: Console) {
    console.println(describe(Shape.Circle(1.5)));
}
```

Output (start):

```text
an empty shape
```

Solution:

```lugha
enum Shape {
    Circle(f64),
    Rect(f64, f64),
    Empty,
}

fun describe(s: Shape): string {
    match s {
        .Empty => "an empty shape",
        .Circle(r) => "a circle of radius {r}",
        .Rect(w, h) => "a {w} by {h} rectangle",
    }
}

fun main(console: Console) {
    console.println(describe(Shape.Circle(1.5)));
}
```

Output (solution):

```text
a circle of radius 1.5
```
