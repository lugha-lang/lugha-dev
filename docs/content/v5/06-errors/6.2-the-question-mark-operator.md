## Step 1: ? on Result
Kind: read

`?` after a `Result` gives the value inside an `Ok`, or returns the `Err` from the function at once.
`average` on line 8 divides with `divide(total, count)?` on line 9, so `avg` is a plain `i64`.
Line 10 prints what it divided, and line 11 wraps the answer back in `Ok`.
Lines 15 and 16 call `average` with a count of `2`, then `0`.
Press Run.

Line 10 prints only for the count of `2`: the failed division returns its `Err` at line 9, and nothing after the `?` runs.

```lugha
fun divide(a: i64, b: i64): Result<i64, string> {
    if b == 0 {
        return Err("division by zero");
    }
    Ok(a / b)
}

fun average(console: Console, total: i64, count: i64): Result<i64, string> {
    let avg = divide(total, count)?;
    console.println("divided {total} by {count}");
    Ok(avg)
}

fun main(console: Console) {
    console.println(average(console, 10, 2).debug());
    console.println(average(console, 10, 0).debug());
}
```

Output:

```text
divided 10 by 2
Ok(5)
Err("division by zero")
```

## Step 2: ? on Option
Kind: read

In a function that returns an `Option`, `?` works on an `Option` the same way: it gives the value inside a `Some`, or returns `None`.
`sum_two` parses two strings on lines 2 and 3, and either `?` returns `None` when its string isn't a number.
Line 4 adds the numbers only when both parsed.
Press Run.

```lugha
fun sum_two(a: string, b: string): Option<i64> {
    let x = parse_i64(a)?;
    let y = parse_i64(b)?;
    Some(x + y)
}

fun main(console: Console) {
    console.println(sum_two("2", "3").debug());
    console.println(sum_two("2", "three").debug());
}
```

Output:

```text
Some(5)
None
```

## Step 3: Error types
Kind: fix (start gives E0424 "`?` can't return here", help "a missing value isn't an error by itself: handle the `Option` with `match`")

`?` returns a failure from the function it's in, so the failure has to fit that function's return type.
`doubled` on line 1 returns a `Result<i64, string>`, and line 2 uses `?` on the `Option` that `parse_i64` gives.
Press Run.

`lughac` stops at line 2 with E0424, "`?` can't return here".
A `None` has no error in it to return, and the help suggests a `match`, but `ok_or("not a number")` is shorter.
It turns the `Option` into a `Result`, with that string as its error, and then `?` works.
Add `.ok_or("not a number")` before the `?` on line 2, or press Solve.
On a `Result` the error type has to fit too: in this function, `?` on a `Result<i64, i64>` is E0424, "the error types must match: `i64` and `string`", and `map_err` can change the error first.

Start:

```lugha
fun doubled(text: string): Result<i64, string> {
    let n = parse_i64(text)?;
    Ok(n * 2)
}

fun main(console: Console) {
    console.println(doubled("21").debug());
    console.println(doubled("x").debug());
}
```

Solution:

```lugha
fun doubled(text: string): Result<i64, string> {
    let n = parse_i64(text).ok_or("not a number")?;
    Ok(n * 2)
}

fun main(console: Console) {
    console.println(doubled("21").debug());
    console.println(doubled("x").debug());
}
```

Output (solution):

```text
Ok(42)
Err("not a number")
```

## Step 4: Errors in main
Kind: fix (start gives E0424 "`?` can't return here", help "`main` can't return an error: handle it with `match`")

`main` gives back nothing or an `i32` exit code, never a `Result`, so a `?` in it has no way to return an `Err`.
Line 7 uses `?` there anyway.
Press Run.

E0424 again: the help says `main` can't return an error, and to handle it with `match`.
Replace lines 7 to 9 with a `match` on `doubled("x")`, with no `;` after it, so that it's `main`'s last expression and its value is the exit code.
Its `.Ok(n)` arm is a block that prints `n` with `console.println` and ends with `0`, as the `.Some(mut n)` arm in mut bindings was a block.
Its `.Err(e)` arm is a block that prints `"error: {e}"` and ends with `1`, the exit code for a failure.
Write that `match`, or press Solve.

Start:

```lugha
fun doubled(text: string): Result<i64, string> {
    let n = parse_i64(text).ok_or("not a number")?;
    Ok(n * 2)
}

fun main(console: Console): i32 {
    let n = doubled("x")?;
    console.println(n);
    0
}
```

Solution:

```lugha
fun doubled(text: string): Result<i64, string> {
    let n = parse_i64(text).ok_or("not a number")?;
    Ok(n * 2)
}

fun main(console: Console): i32 {
    match doubled("x") {
        .Ok(n) => {
            console.println(n);
            0
        }
        .Err(e) => {
            console.println("error: {e}");
            1
        }
    }
}
```

Output (solution; exit 1):

```text
error: not a number
```
