## Step 1: Block expressions
Kind: read

In the first lesson, the last expression in `main`, written without a `;`, was the value `main` gave back.
Any block in braces works the same way.
Lines 2 to 6 are a block, and its value goes into `total`.
Press Run.

Line 7 prints `46`.
A block's value is its last expression, written without a `;`, here `price + tax` on line 5.

```lugha
fun main(console: Console) {
    let total = {
        let price = 40;
        let tax = 6;
        price + tax
    };
    console.println(total);
}
```

Output:

```text
46
```

## Step 2: Statements and ()
Kind: fix (start gives warning W0106 "`total` holds `()`" and E0422 "`()` doesn't implement `Display`", help "it has no text of its own: show its debug form with `.debug()`")

Now line 5 ends with a `;`.
Press Run.

It doesn't compile: W0106 warns that `total` holds `()`, and E0422 on line 7 is the error, because `()` can't be printed.
A `;` turns an expression into a statement and throws its value away, so the block has no last expression.
A block like that gives `()`, the value that means nothing was given back.
The help's `.debug()` would print it; it comes in Arrays.
Remove the `;` on line 5 and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let total = {
        let price = 40;
        let tax = 6;
        price + tax;
    };
    console.println(total);
}
```

Solution:

```lugha
fun main(console: Console) {
    let total = {
        let price = 40;
        let tax = 6;
        price + tax
    };
    console.println(total);
}
```

Output (solution):

```text
46
```

## Step 3: Variable scope
Kind: fix (start gives E0301 "cannot find `price` in this scope")

`price` is declared inside the block, on line 3, and line 6 tries to print it after the block's `}`.
Press Run.

`lughac` refuses it with E0301, "cannot find `price` in this scope".
A variable declared in a block ends at the `}` that closes it, so `price` doesn't exist on line 6.
What's left of the block is its value, in `total`.
Print `total` on line 6 instead and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let total = {
        let price = 40;
        price + 6
    };
    console.println(price);
}
```

Solution:

```lugha
fun main(console: Console) {
    let total = {
        let price = 40;
        price + 6
    };
    console.println(total);
}
```

Output (solution):

```text
46
```
