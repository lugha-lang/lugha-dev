## Step 1: while loops
Kind: read

Where an `if` runs its block once, `while` checks its condition, runs its block if it's true, then checks again, until the condition is false.
`seconds` starts at `3`, and line 5 takes one off each time round, so the loop runs three times.
`seconds -= 1` is short for `seconds = seconds - 1`, and `+=`, `*=` and the rest work the same way.
Press Run.

```lugha
fun main(console: Console) {
    let mut seconds = 3;
    while seconds > 0 {
        console.println(seconds);
        seconds -= 1;
    }
    console.println("go");
}
```

Output:

```text
3
2
1
go
```

## Step 2: for loops over ranges
Kind: read

`for` does the counting for you: `for i in 1..4` runs its block once for each number in the range `1..4`, with `i` set to that number.
Press Run.

It prints `1`, `2` and `3`.
A range includes its first number and stops before its second, so `1..4` holds three numbers.
A range whose first number isn't smaller than its second, such as `4..4`, is empty, and the block doesn't run at all.

```lugha
fun main(console: Console) {
    for i in 1..4 {
        console.println(i);
    }
}
```

Output:

```text
1
2
3
```

## Step 3: break and continue
Kind: read

Both loops can be cut short from inside.
`continue` skips the rest of the block and goes on to the next turn, and `break` ends the loop.
Here line 4 skips every multiple of 3, and line 7 ends the loop when `i` reaches 8, though the range goes up to 9.
Press Run.

It prints `1`, `2`, `4`, `5` and `7`, and ends at `8` without printing it.

```lugha
fun main(console: Console) {
    for i in 1..10 {
        if i % 3 == 0 {
            continue;
        }
        if i > 7 {
            break;
        }
        console.println(i);
    }
}
```

Output:

```text
1
2
4
5
7
```

## Step 4: loop and break with a value
Kind: read

`loop` runs its block again and again until something leaves it, usually a `break`.
Like `if` and `match`, it's an expression, and `break n;` on line 6 ends it with `n` as its value.
Press Run.

It doubles `n` until it passes 100, so it prints `128`, the first number to do so.
A `while` or `for` can't give a value like this.
`break` with a value inside one is E0514 and won't compile, because those loops can also end without reaching a `break`.

```lugha
fun main(console: Console) {
    let mut n = 1;
    let first = loop {
        n = n * 2;
        if n > 100 {
            break n;
        }
    };
    console.println(first);
}
```

Output:

```text
128
```

## Step 5: Loop labels
Kind: fix (start prints seven pairs)

One `for` runs inside another, and line 7 prints each `row` and `col` pair, putting both numbers into the text with `{…}`.
Line 5 should stop everything at the first pair whose product is 4.
Press Run.

The `break` there ends only the inner loop, the one it's in, so row 2 prints `2 1` and stops, and row 3 runs as normal.
To leave the outer loop, give it a label, a name followed by `:`, before its `for`, and name it after `break`.
Add `outer:` before `for` on line 2 and `outer` after `break` on line 5, or press Solve.
`continue outer;` works the same way, going on to the outer loop's next turn.

Start:

```lugha
fun main(console: Console) {
    for row in 1..4 {
        for col in 1..4 {
            if row * col == 4 {
                break;
            }
            console.println("{row} {col}");
        }
    }
}
```

Output (start):

```text
1 1
1 2
1 3
2 1
3 1
3 2
3 3
```

Solution:

```lugha
fun main(console: Console) {
    outer: for row in 1..4 {
        for col in 1..4 {
            if row * col == 4 {
                break outer;
            }
            console.println("{row} {col}");
        }
    }
}
```

Output (solution):

```text
1 1
1 2
1 3
2 1
```
