# 2.5 Functions (v5, Lugha v18)

## Objectives

1. **Function declaration** *(v4 kept)*: typed parameters and a return type, always written; order in a file doesn't matter. [functions]
2. **Return values** *(v4 kept)*: a trailing `;` is E0503. [functions]
3. **Expression bodies** *(v4 kept)*. [functions]
4. **Immutable parameters** *(v4 kept)*: E0501, `let mut n = n;`. [functions]
5. **No overloading** *(v4 kept)*: no overloading or defaults (E0302). [functions]
6. **Passing the console** *(new)*: a function prints only through a `Console` it's given. A fix step: a function calling `console.println` without the parameter is E0301. [capabilities]

---

## Step 1: Function declaration
Kind: read

So far `main` has been the only function, and a new one is declared the same way.
After `fun` and the name come its parameters with their types, and after the `)` a `:` and the type it gives back.
`main` calls `area` on line 6.
Press Run.

It prints `21`.
`area` comes first here, but the order of functions in a file doesn't matter, so `main` could be at the top instead.
`lughac` works out a `let`'s type from its value, but a function's parameter types are always written, and so is its return type when it gives a value back.
Leave the return type off, as `main` does on line 5, and the function gives back `()`, which means nothing.

```lugha
fun area(width: i64, height: i64): i64 {
    width * height
}

fun main(console: Console) {
    console.println(area(7, 3));
}
```

Output:

```text
21
```

## Step 2: Return values
Kind: fix (start gives E0503 "`area` may end without returning a value of type i64", help "remove this semicolon to make it the result")

`area`'s body is a block, so what it gives back is its last expression, as in Blocks and scopes.
Line 2 now ends with a `;`.
Press Run.

This time the `;` is an error, E0503, because line 1 promises an `i64` and the body no longer gives one.
Its help says to remove the semicolon: remove the `;` on line 2 and run again, or press Solve.

Start:

```lugha
fun area(width: i64, height: i64): i64 {
    width * height;
}

fun main(console: Console) {
    console.println(area(7, 3));
}
```

Solution:

```lugha
fun area(width: i64, height: i64): i64 {
    width * height
}

fun main(console: Console) {
    console.println(area(7, 3));
}
```

Output (solution):

```text
21
```

## Step 3: Expression bodies
Kind: read

A body that is a single expression can be written after `=` instead of between braces, as on line 1.
Press Run.

It prints `21` again, because `= width * height;` means the same as a body in braces holding `width * height`.
Its final `;` ends the declaration, so it doesn't throw the value away the way the `;` in step 2 did.
The return type is still written in this form.

```lugha
fun area(width: i64, height: i64): i64 = width * height;

fun main(console: Console) {
    console.println(area(7, 3));
}
```

Output:

```text
21
```

## Step 4: Immutable parameters
Kind: fix (start gives E0501 "cannot assign to `price`: it is not mutable", help "parameters are immutable; shadow it: `let mut price = price;`")

`with_tax` adds a tenth to `price` on line 2.
Press Run.

It gives E0501 for line 2, because a parameter is like a `let` without `mut`.
Its help suggests shadowing, which you met in Variables.
`let mut price = price;` makes a copy you can change, and from the next line on, `price` means the copy.
Add it as a new line 2, or press Solve.

Start:

```lugha
fun with_tax(price: i64): i64 {
    price = price + price / 10;
    price
}

fun main(console: Console) {
    console.println(with_tax(200));
}
```

Solution:

```lugha
fun with_tax(price: i64): i64 {
    let mut price = price;
    price = price + price / 10;
    price
}

fun main(console: Console) {
    console.println(with_tax(200));
}
```

Output (solution):

```text
220
```

## Step 5: No overloading
Kind: fix (start gives E0302 "`area` is defined more than once" and E0405 "`area` takes 2 arguments but 1 was given")

Lines 1 and 3 both declare a function called `area`, one with two parameters and one with one, and line 7 calls `area` with a single number.
Press Run.

It gives E0302, "`area` is defined more than once", and E0405 for line 7, which says the call gives one argument to an `area` that takes two.
Two functions can't share a name, whatever their parameters, and a parameter can't have a default value either, so each way of calling needs its own function.
Rename the second one `square_area` on lines 3 and 7, or press Solve.

Start:

```lugha
fun area(width: i64, height: i64): i64 = width * height;

fun area(side: i64): i64 = side * side;

fun main(console: Console) {
    console.println(area(7, 3));
    console.println(area(4));
}
```

Solution:

```lugha
fun area(width: i64, height: i64): i64 = width * height;

fun square_area(side: i64): i64 = side * side;

fun main(console: Console) {
    console.println(area(7, 3));
    console.println(square_area(4));
}
```

Output (solution):

```text
21
16
```

## Step 6: Passing the console
Kind: fix (start gives E0301 "cannot find `console` in this scope")

`greet` on line 1 prints a line, and `main` calls it on line 6.
Press Run.

`lughac` gives E0301 on line 2, "cannot find `console` in this scope".
`console` is a parameter of `main`, and a parameter belongs to its own function, the way a `let` belongs to its block.
There is no `println` without a `Console`, as Hello, world showed.
So `greet` needs a `console: Console` parameter of its own, and `main` passes it the console it was given.
Write `console: Console` between the parentheses on line 1 and `console` between them on line 6, or press Solve.

Start:

```lugha
fun greet() {
    console.println("Hello");
}

fun main(console: Console) {
    greet();
}
```

Solution:

```lugha
fun greet(console: Console) {
    console.println("Hello");
}

fun main(console: Console) {
    greet(console);
}
```

Output (solution):

```text
Hello
```
