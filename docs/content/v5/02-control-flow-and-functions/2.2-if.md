## Step 1: if expressions
Kind: read

Like a block, an `if` has a value, the value of whichever branch ran.
Here lines 3 to 9 put one of three strings into `advice`, and `else if` on line 5 adds a second condition to check.
Press Run.

It prints `stay inside`, because `temperature > 30` is true and the other branches are skipped.
Change `31` on line 2 to `25` or `10` and run again to see the other two.

```lugha
fun main(console: Console) {
    let temperature = 31;
    let advice = if temperature > 30 {
        "stay inside"
    } else if temperature > 20 {
        "go for a walk"
    } else {
        "take a jacket"
    };
    console.println(advice);
}
```

Output:

```text
stay inside
```

## Step 2: Branch types
Kind: fix (start gives E0403 "`if` and `else` have different types", labels "this is string" on line 4 and "this is i64" on the `else` block)

This `if` has two branches: line 4 gives a string, and line 6, in the `else`, gives `0`, a number.
Press Run.

`lughac` refuses it with E0403, "`if` and `else` have different types", and its notes say "this is string" for line 4 and "this is i64" for the `else`.
`advice` gets the type of the `if`, and an `if` has one type, so every branch has to give a value of it.
`lughac` checks both branches before the program runs, even the one that won't be taken.
Change line 6 to a string, such as `"go out"`, and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let temperature = 31;
    let advice = if temperature > 30 {
        "stay inside"
    } else {
        0
    };
    console.println(advice);
}
```

Solution:

```lugha
fun main(console: Console) {
    let temperature = 31;
    let advice = if temperature > 30 {
        "stay inside"
    } else {
        "go out"
    };
    console.println(advice);
}
```

Output (solution):

```text
stay inside
```

## Step 3: Boolean conditions
Kind: fix (start gives E0403 "expected bool, found i64")

`unread` is `3`, and line 3 uses it as the condition.
Press Run.

`lughac` gives E0403 again, the code for a value of the wrong type, this time "expected bool, found i64".
A condition must be a `bool`, and a number is never read as one, so the comparison with `0` has to be written out.
Write `unread > 0` on line 3 and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let unread = 3;
    if unread {
        console.println("you have mail");
    }
}
```

Solution:

```lugha
fun main(console: Console) {
    let unread = 3;
    if unread > 0 {
        console.println("you have mail");
    }
}
```

Output (solution):

```text
you have mail
```

## Step 4: Braces and parentheses
Kind: fix (start gives E0201 "expected `{`, found identifier `console`")

Line 3 puts the condition in parentheses and leaves out the braces.
Press Run.

`lughac` gives E0201, "expected `{`, found identifier `console`": the braces are what's missing.
Parentheses around a condition are optional, so `if (unread > 0)` means the same as `if unread > 0`.
The code after the condition is always a block in braces, even when it holds one line.
So is the code after `else`, unless it's another `if`.
Put line 3's `console.println` in braces and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let unread = 3;
    if (unread > 0) console.println("you have mail");
}
```

Solution:

```lugha
fun main(console: Console) {
    let unread = 3;
    if (unread > 0) {
        console.println("you have mail");
    }
}
```

Output (solution):

```text
you have mail
```
