## Step 1: within
Kind: read

`within 500` after a scope's name, as on lines 9 and 14, gives it a deadline: 500 milliseconds from when it starts.
If the scope is still running then, its body and tasks are cancelled, and its value is an `Err` whose `f.kind` is `.Deadline`, unless a task failed first.
The first scope's task takes 100 milliseconds, and the second's would take three seconds.
The `match` on lines 18 to 25 is like `report`'s in Failure and cancellation, with `.Ok(text)` printing the text.
For a deadline, `f.task` names the scope, by its handle `s`, not a task.
Press Run.

The first scope finishes in time, with `Ok`, and the second is cut off at 500 milliseconds.

```lugha
import std.task;

fun fetch(ms: i64): string {
    task.sleep(ms);
    "fetched in {ms} ms"
}

fun main(console: Console) {
    let quick = scope s within 500 {
        let t = s.spawn(fetch(100));
        t.join().unwrap()
    };
    console.println(quick.debug());
    let late = scope s within 500 {
        let t = s.spawn(fetch(3_000));
        t.join().unwrap()
    };
    match late {
        .Ok(text) => console.println(text),
        .Err(f) => match f.kind {
            .Deadline => console.println("{f.task} ran out of time"),
            .Error(e) => console.println("error: {e}"),
            .Panic(m) => console.println("panic: {m}"),
        },
    }
}
```

Output:

```text
Ok("fetched in 100 ms")
s ran out of time
```

## Step 2: shield
Kind: fix (start prints `saving` and `true`, and never `saved`)

`save` on line 3 prints `saving`, sleeps 200 milliseconds on line 5, standing in for the saving, then prints `saved` and `after saving`.
Line 11's scope has a deadline of 100 milliseconds.
Press Run.

The deadline cancels `save` in its sleep on line 5, so `saved` never prints.
`shield within 500 { … }` holds cancellation off for its block, for at most 500 milliseconds, so that work which shouldn't stop halfway can finish.
The cancellation that was held off applies after the block, so `after saving` still doesn't print.
Put lines 5 and 6 inside `shield within 500 {` and a closing `}`, or press Solve.

Start:

```lugha
import std.task;

fun save(console: Console) {
    console.println("saving");
    task.sleep(200);
    console.println("saved");
    console.println("after saving");
}

fun main(console: Console) {
    let r = scope s within 100 {
        s.spawn(save(console));
    };
    console.println(r.is_err());
}
```

Output (start):

```text
saving
true
```

Solution:

```lugha
import std.task;

fun save(console: Console) {
    console.println("saving");
    shield within 500 {
        task.sleep(200);
        console.println("saved");
    }
    console.println("after saving");
}

fun main(console: Console) {
    let r = scope s within 100 {
        s.spawn(save(console));
    };
    console.println(r.is_err());
}
```

Output (solution):

```text
saving
saved
true
```
