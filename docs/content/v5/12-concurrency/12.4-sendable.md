## Step 1: What crosses to a task
Kind: read

A spawned call's arguments are worked out first, by the caller, and the task gets copies of them, as a function call does (Copies).
Line 12 starts `ship` with `order`; `ship` can't change its parameter, so line 4 copies it into `copy`, as in Passing by value, and line 5 changes that.
Line 15 prints what the task gave back, and line 16 prints `order.qty` afterwards.
Press Run.

`ship` changed only its copy: `order.qty` is still `3`.
Numbers and strings are `Sendable`, and so are arrays, structs and enums made of them: they can cross to a task this way.
A `Ref` isn't: passing one to a task is E0475, as the next step shows.

```lugha
struct Order { item: string, qty: i64 }

fun ship(order: Order): string {
    let mut copy = order;
    copy.qty -= 1;
    "{copy.item}: {copy.qty} left after shipping one"
}

fun main(console: Console) {
    let order = Order { item: "tea", qty: 3 };
    let r = scope s {
        let t = s.spawn(ship(order));
        t.join().unwrap()
    };
    console.println(r.debug());
    console.println(order.qty);
}
```

Output:

```text
Ok("tea: 2 left after shipping one")
3
```

## Step 2: Sharing through a task
Kind: fix (start gives E0475 "a `Ref<i64>` can't be passed to another task: it is a `Ref<i64>`, which two tasks would share" on lines 8 and 9, help "keep shared state in an actor, or send copies through a channel: a `Ref` belongs to one task")

Copies of a `Ref` share one box, as in Ref.
`bump` on line 1 adds 1 to the number in a box, and lines 8 and 9 hand the same box to two tasks.
Press Run.

E0475 on lines 8 and 9: a `Ref` isn't `Sendable`, since two tasks would share it, and a `Ref` belongs to one task.
Here each task can give back its answer instead, and the scope adds them up.
When many tasks need one changing value, the help names two ways: send copies through a channel, which comes next, or keep the value in an actor, at the end of the chapter.
Make line 11 `console.println(r.debug());`.
Replace lines 8 and 9 with `let a = s.spawn(bump(count));`, `let b = s.spawn(bump(count));` and `a.join().unwrap() + b.join().unwrap()`.
Make line 6 `let count = 0;`.
Replace lines 1 to 3 with `fun bump(n: i64): i64 = n + 1;`.
Or press Solve.

Start:

```lugha
fun bump(count: Ref<i64>) {
    count.update(fun(n) = n + 1);
}

fun main(console: Console) {
    let count = Ref.new(0);
    let r = scope s {
        s.spawn(bump(count));
        s.spawn(bump(count));
    };
    console.println(count.get());
}
```

Solution:

```lugha
fun bump(n: i64): i64 = n + 1;

fun main(console: Console) {
    let count = 0;
    let r = scope s {
        let a = s.spawn(bump(count));
        let b = s.spawn(bump(count));
        a.join().unwrap() + b.join().unwrap()
    };
    console.println(r.debug());
}
```

Output (solution):

```text
Ok(2)
```
