## Step 1: scope and spawn
Kind: fix (start gives E0474 "a task starts in a scope" on line 4, help "start it through a scope's handle, `scope s { s.spawn(work(x)) }`, or through the root scope `main` takes (`root: Scope`)")

A task is a function call that runs at the same time as the rest of the program.
Line 4 starts `square(7)` as a task with `spawn`, and line 5 waits for its answer with `join`.
Press Run.

E0474: "a task starts in a scope".
A scope is a block, `scope s { … }`, and its tasks start through its handle `s`, as `s.spawn(square(7))`.
A scope is an expression: its value is a `Result`, `Ok` with what its body gives.
Replace lines 4 and 5 with `let r = scope s {`, then `let t = s.spawn(square(7));` and `t.join().unwrap()` inside it, a closing `};`, and `console.println(r.debug());`, or press Solve.

Start:

```lugha
fun square(n: i64): i64 = n * n;

fun main(console: Console) {
    let t = spawn square(7);
    console.println(t.join().unwrap());
}
```

Solution:

```lugha
fun square(n: i64): i64 = n * n;

fun main(console: Console) {
    let r = scope s {
        let t = s.spawn(square(7));
        t.join().unwrap()
    };
    console.println(r.debug());
}
```

Output (solution):

```text
Ok(49)
```

## Step 2: join
Kind: read

Lines 11 and 12 start two tasks, which run at the same time.
`t.join()` waits for a task to finish and gives `Ok` with what it returned, once it has finished normally, which lines 13 and 14 print.
A task can be joined more than once: line 15 joins both again and adds their answers up as the body's value.
Line 17 prints the scope's value, `Ok` with that sum.
Press Run.

```lugha
fun count(n: i64): i64 {
    let mut sum = 0;
    for i in 0..n {
        sum += i;
    }
    sum
}

fun main(console: Console) {
    let total = scope s {
        let a = s.spawn(count(1_000));
        let b = s.spawn(count(2_000));
        console.println(a.join().debug());
        console.println(b.join().debug());
        a.join().unwrap() + b.join().unwrap()
    };
    console.println(total.debug());
}
```

Output:

```text
Ok(499500)
Ok(1999000)
Ok(2498500)
```

## Step 3: A scope waits
Kind: read

`slow` on line 3 sleeps for 200 milliseconds, with `task.sleep` from Testing with capabilities (outside a test it really sleeps: virtual time is only for tests), then prints.
Line 10 starts it and never joins it, and line 11 prints at once, at the end of the scope's body.
Line 13 prints after the scope.
Line 9 keeps the scope's value in `r` because a scope is a `Result`, and one used as a statement is E0467, as in Result.
Press Run.

The scope doesn't end with its body: it waits for every task it started, so `the task is done` comes before `the scope is done`.

```lugha
import std.task;

fun slow(console: Console) {
    task.sleep(200);
    console.println("the task is done");
}

fun main(console: Console) {
    let r = scope s {
        s.spawn(slow(console));
        console.println("the body is done");
    };
    console.println("the scope is done");
}
```

Output:

```text
the body is done
the task is done
the scope is done
```

## Step 4: The root scope
Kind: read

`main` can also take `root: Scope`, by type like a capability, as on line 8: a scope as long as the program, which the program waits on before it ends.
Line 9 starts `later` in it, and line 10 is `main`'s last line.
Press Run.

`main` returns first, and the program ends only when `later` has finished.

```lugha
import std.task;

fun later(console: Console) {
    task.sleep(200);
    console.println("the task finishes");
}

fun main(console: Console, root: Scope) {
    root.spawn(later(console));
    console.println("main returns");
}
```

Output:

```text
main returns
the task finishes
```

## Step 5: Tasks stay put
Kind: fix (start gives E0472 "a scope or task handle can't be stored in a value" on lines 5 and 6, help "a handle is passed as an argument, and nothing else: keep it a local, and finish the tasks inside the scope that started them")

Line 5 keeps two tasks in an array, and line 6 joins them from it.
Press Run.

E0472: "a scope or task handle can't be stored in a value".
A `Task` or a `Scope` is kept in a local or passed as an argument, and nothing else: it isn't returned, or put in an array, a field or a closure.
To collect the answers of many tasks, each can send its answer on a channel, as Channels shows.
Replace line 5 with `let a = s.spawn(square(2));` and `let b = s.spawn(square(3));`, and line 6 with `a.join().unwrap() + b.join().unwrap()`, or press Solve.

Start:

```lugha
fun square(n: i64): i64 = n * n;

fun main(console: Console) {
    let r = scope s {
        let ts = [s.spawn(square(2)), s.spawn(square(3))];
        ts[0].join().unwrap() + ts[1].join().unwrap()
    };
    console.println(r.debug());
}
```

Solution:

```lugha
fun square(n: i64): i64 = n * n;

fun main(console: Console) {
    let r = scope s {
        let a = s.spawn(square(2));
        let b = s.spawn(square(3));
        a.join().unwrap() + b.join().unwrap()
    };
    console.println(r.debug());
}
```

Output (solution):

```text
Ok(13)
```
