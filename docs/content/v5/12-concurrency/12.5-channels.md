## Step 1: Channels
Kind: read

A channel carries values from one task to another, in order.
`Chan<i64>.new(4)` on line 9 makes one that holds up to four `i64`s, and gives its two ends: a `Sender<i64>`, `tx`, and a `Receiver<i64>`, `rx`.
`produce` on line 1 sends three squares with `out.send`, and closes the channel on line 5 when it's done.
`rx.recv()` on lines 12 to 15 waits for the next value and gives `Some(v)`, or `None` once the channel is closed and empty.
Press Run.

The fourth `recv` gives `None`: three values came, then the close.
Here the channel never fills; when one is full, `send` waits for room.
A channel made with `Chan<i64>.new(0)` holds no values, so each `send` waits until a receiver takes the value.

```lugha
fun produce(out: Sender<i64>, n: i64) {
    for i in 1..n + 1 {
        out.send(i * i);
    }
    out.close();
}

fun main(console: Console) {
    let (tx, rx) = Chan<i64>.new(4);
    let r = scope s {
        s.spawn(produce(tx, 3));
        console.println(rx.recv().debug());
        console.println(rx.recv().debug());
        console.println(rx.recv().debug());
        console.println(rx.recv().debug());
    };
    console.println(r.debug());
}
```

Output:

```text
Some(1)
Some(4)
Some(9)
None
Ok(())
```

## Step 2: Closing a channel
Kind: fix (start ends with a deadlock: stderr `panic: deadlock: every green thread is waiting` and ``  `main` waits to receive on the channel made at src/main.la:8:20``, exit 101)

`for v of rx` on line 12 receives every value until the channel is closed and empty, and adds them up.
This `produce` sends five squares and doesn't close the channel.
A channel stays open until a sender closes it, even after `produce` returns.
Press Run.

`55` never prints: after the fifth value, `main` waits for another, but `produce` has finished and nothing will send again, so the program ends with a deadlock, which select covers.
Once the channel is closed, the loop ends after the last value.
Add `out.close();` after line 4, at the end of `produce`, or press Solve.

Start:

```lugha
fun produce(out: Sender<i64>, n: i64) {
    for i in 1..n + 1 {
        out.send(i * i);
    }
}

fun main(console: Console) {
    let (tx, rx) = Chan<i64>.new(4);
    let r = scope s {
        s.spawn(produce(tx, 5));
        let mut total = 0;
        for v of rx {
            total += v;
        }
        console.println(total);
    };
    console.println(r.debug());
}
```

Solution:

```lugha
fun produce(out: Sender<i64>, n: i64) {
    for i in 1..n + 1 {
        out.send(i * i);
    }
    out.close();
}

fun main(console: Console) {
    let (tx, rx) = Chan<i64>.new(4);
    let r = scope s {
        s.spawn(produce(tx, 5));
        let mut total = 0;
        for v of rx {
            total += v;
        }
        console.println(total);
    };
    console.println(r.debug());
}
```

Output (solution):

```text
55
Ok(())
```

## Step 3: Each end its own job
Kind: fix (start gives E0415 "no method `send` on `Receiver<string>`" on line 3, help "only a `Sender` can `send`; this is the `Receiver` end")

Line 3 sends through `rx`.
Press Run.

E0415: "no method `send` on `Receiver<string>`", and the help says why: only a `Sender` can `send`.
Each end has only its own methods, so a function given a `Receiver` can only receive, and one given a `Sender` only send and close.
Change `rx.send` to `tx.send` on line 3, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let (tx, rx) = Chan<string>.new(2);
    rx.send("hello");
    console.println(rx.recv().debug());
}
```

Solution:

```lugha
fun main(console: Console) {
    let (tx, rx) = Chan<string>.new(2);
    tx.send("hello");
    console.println(rx.recv().debug());
}
```

Output (solution):

```text
Some("hello")
```

## Step 4: try_send and try_recv
Kind: read

`try_send` and `try_recv` never wait: they say what happened instead.
`try_send` gives `.Sent`, `.Full(v)` when there's no room, or `.Closed(v)` when the channel is closed, the last two giving `v` back.
`try_recv` gives `.Ready(v)`, `.Empty` when nothing has come, or `.Closed` when the channel is closed and empty.
The channel on line 2 holds one value, and lines 3 to 9 try each case, closing it on line 7.
Press Run.

```lugha
fun main(console: Console) {
    let (tx, rx) = Chan<i64>.new(1);
    console.println(tx.try_send(1).debug());
    console.println(tx.try_send(2).debug());
    console.println(rx.try_recv().debug());
    console.println(rx.try_recv().debug());
    tx.close();
    console.println(tx.try_send(3).debug());
    console.println(rx.try_recv().debug());
}
```

Output:

```text
Sent
Full(2)
Ready(1)
Empty
Closed(3)
Closed
```
