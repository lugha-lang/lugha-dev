## Step 1: All or nothing
Kind: read

A task that returns a `Result` fails when it gives an `Err`, and a task that panics fails too.
Line 17 starts `worker`, which would sleep two seconds, and line 18 starts `check(-1)`, which gives an `Err` after a tenth of a second.
`worker` defers a line on line 4, as in defer, and prints another on line 6 if it gets that far.
Press Run.

By default a scope is all or nothing: when `check` fails, the scope cancels `worker`, which stops in its sleep and runs its `defer` on the way out.
`worker finished` never prints, and the scope's value is an `Err`, so line 21 prints `true`.

```lugha
import std.task;

fun worker(console: Console): i64 {
    defer console.println("worker cleans up");
    task.sleep(2_000);
    console.println("worker finished");
    1
}

fun check(n: i64): Result<i64, string> {
    task.sleep(100);
    if n < 0 { Err("negative: {n}") } else { Ok(n) }
}

fun main(console: Console) {
    let r = scope s {
        s.spawn(worker(console));
        s.spawn(check(-1));
        console.println("body waits");
    };
    console.println(r.is_err());
}
```

Output:

```text
body waits
worker cleans up
true
```

## Step 2: Failure
Kind: read

A scope's `Err` holds a `Failure`, with the failing task's name in `f.task` and how it failed in `f.kind`.
`f.kind` is `.Error(e)` for a task that gave `Err(e)`, `.Panic(m)` for one that panicked, and `.Deadline` for a scope that ran out of time, which comes in Deadlines.
`report` on line 13 matches on it, and lines 25 to 33 give it three scopes: one whose task fails with an `Err`, one whose task panics, and one whose task is fine.
A task is named after the function it calls, so the first two are `check` and `crash`.
A panic's message ends with where it happened, as in Panics, so `m` here does too.
Press Run.

```lugha
import std.task;

fun check(n: i64): Result<i64, string> =
    if n < 0 { Err("negative: {n}") } else { Ok(n) };

fun crash(n: i64): i64 {
    if n > 2 {
        panic("too big: {n}");
    }
    n
}

fun report(console: Console, r: Result<(), Failure>) {
    match r {
        .Ok(()) => console.println("all done"),
        .Err(f) => match f.kind {
            .Error(e) => console.println("{f.task} returned an error: {e}"),
            .Panic(m) => console.println("{f.task} panicked: {m}"),
            .Deadline => console.println("{f.task} ran out of time"),
        },
    }
}

fun main(console: Console) {
    report(console, scope s {
        s.spawn(check(-1));
    });
    report(console, scope s {
        s.spawn(crash(5));
    });
    report(console, scope s {
        s.spawn(check(4));
    });
}
```

Output:

```text
check returned an error: negative: -1
crash panicked: too big: 5 at src/main.la:8:9
all done
```

## Step 3: independent
Kind: read

`independent` after the scope's name, as on line 13, lets each task fail alone: when one fails, the others run on and the scope stays `Ok`.
Line 14 starts `crash`, which panics at once, and line 15 starts `slow`, which takes 200 milliseconds.
Lines 16 and 17 join each, and a join gives `Err` with why the task stopped, here `Panicked` with its message.
Press Run.

`slow` finishes and gives `Ok(7)` though `crash` failed first, and the scope's value is `Ok(())`.
The panic's message also goes to standard error, as ``task `crash` panicked: …``.

```lugha
import std.task;

fun crash(n: i64): i64 {
    panic("too big: {n}");
}

fun slow(n: i64): i64 {
    task.sleep(200);
    n
}

fun main(console: Console) {
    let r = scope s independent {
        let a = s.spawn(crash(5));
        let b = s.spawn(slow(7));
        console.println(a.join().debug());
        console.println(b.join().debug());
    };
    console.println(r.debug());
}
```

Output (stdout; stderr ``task `crash` panicked: too big: 5 at src/main.la:4:5``):

```text
Err(Panicked("too big: 5 at src/main.la:4:5"))
Ok(7)
Ok(())
```

## Step 4: cancel
Kind: read

`t.cancel(why)` stops one task, with a reason.
Line 11 starts `wait_long`, which would sleep five seconds, and line 13 cancels it a tenth of a second later.
Line 14 joins it, and the join gives `Err` with why the task stopped, as in step 3.
Press Run.

The task stops in its sleep and runs its `defer`, and its join is `Err(Cancelled(Requested("no longer needed")))`, the reason given on line 13.
Cancelling one task doesn't fail the scope: its value is `Ok(())`.

```lugha
import std.task;

fun wait_long(console: Console): i64 {
    defer console.println("stopped waiting");
    task.sleep(5_000);
    1
}

fun main(console: Console) {
    let r = scope s {
        let t = s.spawn(wait_long(console));
        task.sleep(100);
        t.cancel("no longer needed");
        console.println(t.join().debug());
    };
    console.println(r.debug());
}
```

Output:

```text
stopped waiting
Err(Cancelled(Requested("no longer needed")))
Ok(())
```

## Step 5: limit
Kind: read

`limit 2` after the scope's name, as on line 10, lets at most two of its tasks run at once: a third `s.spawn`, on line 13, waits until one of them has finished.
Lines 11 to 14 start four `job`s, each 200 milliseconds long.
Line 9 reads the clock before the scope and line 17 after it, as in Clock, Env and Entropy.
Press Run.

Two at a time, four jobs take at least two rounds of 200 milliseconds, so line 19 prints `true`.
Without `limit 2` all four run at once, in about 200 milliseconds, and it prints `false`.

```lugha
import std.task;

fun job(n: i64): i64 {
    task.sleep(200);
    n * 10
}

fun main(console: Console, clock: Clock) {
    let start = clock.monotonic_ms();
    let r = scope s limit 2 {
        let a = s.spawn(job(1));
        let b = s.spawn(job(2));
        let c = s.spawn(job(3));
        let d = s.spawn(job(4));
        a.join().unwrap() + b.join().unwrap() + c.join().unwrap() + d.join().unwrap()
    };
    let took = clock.monotonic_ms() - start;
    console.println(r.debug());
    console.println(took >= 400);
}
```

Output:

```text
Ok(100)
true
```
