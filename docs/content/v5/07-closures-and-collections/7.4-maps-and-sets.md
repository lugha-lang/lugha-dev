## Step 1: Map literals
Kind: read

A map holds values under keys, written `Map { key: value }`, and keeps its keys in the order they were added.
`ages` on line 2 is a `Map<string, i64>`.
`ages["ann"]` on line 3 reads a value, and line 4 adds a key by assigning to it.
Line 5 changes a value where it is, with `+=`.
An empty `Map {}` takes its type from where it's used, as `[]` does: on line 7, from the type written after `none_yet`.
A map prints through `.debug()`, as an array does.
Press Run.

```lugha
fun main(console: Console) {
    let mut ages = Map { "ann": 31, "bo": 40 };
    console.println(ages["ann"]);
    ages["cy"] = 25;
    ages["bo"] += 1;
    console.println(ages.debug());
    let none_yet: Map<string, i64> = Map {};
    console.println(none_yet.debug());
}
```

Output:

```text
31
Map { "ann": 31, "bo": 41, "cy": 25 }
Map {}
```

## Step 2: Missing keys
Kind: read

`get` on line 3 gives an `Option`: `Some` with the value, or `None` when the key isn't there, as on line 4.
`has` on line 5 only asks whether the key is there.
Line 6 reads a missing key with `[…]`.
Press Run.

Line 6 panics with `no key "dee" in the map`.
When a key may be missing, use `get` or `has`.

```lugha
fun main(console: Console) {
    let ages = Map { "ann": 31, "bo": 40 };
    console.println(ages.get("ann").debug());
    console.println(ages.get("dee").debug());
    console.println(ages.has("dee"));
    console.println(ages["dee"]);
}
```

Output (stdout; stderr `panic: no key "dee" in the map at src/main.la:6:25`, exit 101):

```text
Some(31)
None
false
```

## Step 3: Iterating a map
Kind: fix (start gives E0442 "`for … of mut` can't change a `Map<string, i64>` in place", help "loop over `m.keys()` and assign `m[k] = …`", and E0501 on line 4)

A map can be looped over like an array: each entry is a tuple of key and value, in the order the keys were added.
Line 3 loops with `mut`, meaning to double each price where it is.
Press Run.

`lughac` stops at line 3 with E0442: `for … of mut` can't change a map in place, and the E0501 on line 4 follows from it.
As the help says, loop over `prices.keys()` instead, and assign each `prices[item]`.
Make line 3 `for item of prices.keys() {` and line 4 `prices[item] *= 2;`, or press Solve.
Lines 6 to 8 then read each entry with a plain `for (item, price) of prices`, and line 9 prints `values()`, an array of the values in the same order.

Start:

```lugha
fun main(console: Console) {
    let mut prices = Map { "tea": 3, "milk": 2 };
    for (item, price) of mut prices {
        price *= 2;
    }
    for (item, price) of prices {
        console.println("{item}: {price}");
    }
    console.println(prices.values().debug());
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut prices = Map { "tea": 3, "milk": 2 };
    for item of prices.keys() {
        prices[item] *= 2;
    }
    for (item, price) of prices {
        console.println("{item}: {price}");
    }
    console.println(prices.values().debug());
}
```

Output (solution):

```text
tea: 6
milk: 4
[6, 4]
```

## Step 4: Sets
Kind: read

A set holds distinct values, written `Set { a, b }`, without colons, and keeps them in the order they were added.
`has` on line 3 asks whether a value is in it, and `insert` on lines 4 and 5 returns `true` only when the value is new.
`remove` on line 6 returns `true` when there was something to remove.
Maps have `remove` too, giving back the removed value as an `Option` on line 9, and both have `clear`, which empties them, as line 10 does for `ages`.
Press Run.

```lugha
fun main(console: Console) {
    let mut seen = Set { "red", "blue" };
    console.println(seen.has("red"));
    console.println(seen.insert("green"));
    console.println(seen.insert("red"));
    console.println(seen.remove("blue"));
    console.println(seen.debug());
    let mut ages = Map { "ann": 31, "bo": 40 };
    console.println(ages.remove("bo").debug());
    ages.clear();
    console.println(ages.debug());
}
```

Output:

```text
true
true
false
true
Set { "red", "green" }
Some(40)
Map {}
```

## Step 5: Set operations
Kind: read

`union` on line 4 gives the values in either set.
`intersect` on line 5 keeps the ones in both, and `minus` on line 6 keeps the ones in `a` that aren't in `b`.
Line 7 compares two sets written in different orders, and line 8 two maps.
Press Run.

Both print `true`: `==` compares what the two hold and ignores the order.

```lugha
fun main(console: Console) {
    let a = Set { 1, 2, 3 };
    let b = Set { 2, 3, 4 };
    console.println(a.union(b).debug());
    console.println(a.intersect(b).debug());
    console.println(a.minus(b).debug());
    console.println(Set { 1, 2 } == Set { 2, 1 });
    console.println(Map { "a": 1, "b": 2 } == Map { "b": 2, "a": 1 });
}
```

Output:

```text
Set { 1, 2, 3, 4 }
Set { 2, 3 }
Set { 1 }
true
true
```

## Step 6: Key types
Kind: fix (start gives E0422 "`Point` doesn't implement `Key`" on lines 4 to 7, help "add `with Key` after `Point`'s declaration, or implement it by hand with `impl Key for Point`")

Keys can be integers, strings, `bool`s and `char`s, and a map or set finds each one by its hash and `==`.
`grid` on line 4 uses `Point`s as keys, for the cells of a grid.
Press Run.

E0422 on lines 4 to 7: "`Point` doesn't implement `Key`".
Like `with Eq` in Structs, `with Key` after the declaration gives `Point` what a key needs.
Add `with Key` after the `}` on line 1, or press Solve.
A float is never a key: `Map { 0.25: "small" }` is E0451, whose help gives the reason, "`NaN != NaN`, so a float key could never be found again".

Start:

```lugha
struct Point { x: i64, y: i64 }

fun main(console: Console) {
    let mut grid: Map<Point, char> = Map {};
    grid[Point { x: 0, y: 0 }] = '#';
    grid[Point { x: 1, y: 0 }] = '.';
    console.println(grid[Point { x: 1, y: 0 }]);
}
```

Solution:

```lugha
struct Point { x: i64, y: i64 } with Key

fun main(console: Console) {
    let mut grid: Map<Point, char> = Map {};
    grid[Point { x: 0, y: 0 }] = '#';
    grid[Point { x: 1, y: 0 }] = '.';
    console.println(grid[Point { x: 1, y: 0 }]);
}
```

Output (solution):

```text
.
```
