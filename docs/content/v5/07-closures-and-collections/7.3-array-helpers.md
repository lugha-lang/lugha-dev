## Step 1: map
Kind: read

Arrays have their own `map`, like the one on `Option` in Closures, and it takes a closure too.
It calls the closure on each element and gives back a new array of the results.
Line 3 doubles each price, and line 4 turns each one into a string, so `labels` is a `string[]`.
Line 7 prints `prices` after both.
Press Run.

Neither `map` changed `prices`: line 7 prints it as it was.

```lugha
fun main(console: Console) {
    let prices = [3, 5, 8];
    let doubled = prices.map(fun(p) = p * 2);
    let labels = prices.map(fun(p) = "{p} coins");
    console.println(doubled.debug());
    console.println(labels.debug());
    console.println(prices.debug());
}
```

Output:

```text
[6, 10, 16]
["3 coins", "5 coins", "8 coins"]
[3, 5, 8]
```

## Step 2: filter
Kind: read

`filter` also takes a closure, one that returns a `bool`, and keeps the elements for which it's `true`, in order, in a new array.
Line 3 keeps the even numbers.
`filter` and `map` both give back arrays, so one can follow the other: line 5 keeps the evens, then squares them.
Press Run.

```lugha
fun main(console: Console) {
    let numbers = [1, 2, 3, 4, 5, 6];
    let evens = numbers.filter(fun(n) = n % 2 == 0);
    console.println(evens.debug());
    console.println(numbers.filter(fun(n) = n % 2 == 0).map(fun(n) = n * n).debug());
}
```

Output:

```text
[2, 4, 6]
[4, 16, 36]
```

## Step 3: fold
Kind: read

To turn a whole array into one value, use `fold`.
It starts from the value you give it, calls its closure with the result so far and each element in turn, left to right, and gives back the last result.
Line 3 starts from `0` and adds each number.
Line 4 starts from the first number and keeps the larger of the two each time.
Press Run.

```lugha
fun main(console: Console) {
    let numbers = [4, 9, 2, 7];
    let total = numbers.fold(0, fun(sum, n) = sum + n);
    let largest = numbers.fold(numbers[0], fun(best, n) = if n > best { n } else { best });
    console.println(total);
    console.println(largest);
}
```

Output:

```text
22
9
```

## Step 4: any and all
Kind: read

`any` and `all` take the same kind of closure as `filter`, but give back one `bool`.
`any` on line 3 asks whether some age is under 18.
`all` on line 4 asks whether every age is under 18, and on line 5 whether every age is above `0`.
Press Run.

`any` is `true` because of `17`; `all` on line 4 is `false` because of `34`, and `52` too.

```lugha
fun main(console: Console) {
    let ages = [34, 17, 52];
    console.println(ages.any(fun(a) = a < 18));
    console.println(ages.all(fun(a) = a < 18));
    console.println(ages.all(fun(a) = a > 0));
}
```

Output:

```text
true
false
true
```

## Step 5: Sorting
Kind: fix (start gives E0422 "`Person` doesn't implement `Ord`", help "add `with Ord` after `Person`'s declaration, or implement it by hand with `impl Ord for Person`")

`sort` gives back a new array in ascending order, for numbers and for strings, as lines 4 and 5 show.
Line 7 sorts people.
Press Run.

E0422: "`Person` doesn't implement `Ord`", so there's no order for two `Person`s to follow.
The help offers `with Ord`, which orders by the fields in the order they're declared, here by `name` first.
To sort by age, `sort_by` takes the rule as a closure instead, one that says whether `a` comes before `b`.
Change `people.sort()` on line 7 to `people.sort_by(fun(a, b) = a.age < b.age)`, or press Solve.
It gives back a new array too, and people of the same age keep their order.
Floats have `<` but no order of their own: `[1.5, -2.0, 0.5].sort()` is E0451, whose help says "sort them with `xs.sort_by(f64.total_order)`", and `[1.5, -2.0, 0.5].sort_by(f64.total_order)` gives `[-2.0, 0.5, 1.5]`.

Start:

```lugha
struct Person { name: string, age: i64 }

fun main(console: Console) {
    console.println([3, 1, 2].sort().debug());
    console.println(["pear", "fig", "apple"].sort().debug());
    let people = [Person { name: "Ann", age: 31 }, Person { name: "Ben", age: 25 }];
    console.println(people.sort().debug());
}
```

Solution:

```lugha
struct Person { name: string, age: i64 }

fun main(console: Console) {
    console.println([3, 1, 2].sort().debug());
    console.println(["pear", "fig", "apple"].sort().debug());
    let people = [Person { name: "Ann", age: 31 }, Person { name: "Ben", age: 25 }];
    console.println(people.sort_by(fun(a, b) = a.age < b.age).debug());
}
```

Output (solution):

```text
[1, 2, 3]
["apple", "fig", "pear"]
[Person { name: "Ben", age: 25 }, Person { name: "Ann", age: 31 }]
```
