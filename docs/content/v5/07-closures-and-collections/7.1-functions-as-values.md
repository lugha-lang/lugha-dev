## Step 1: Function types
Kind: read

A function is a value too, and its type is its signature without the names: `double` on line 1 is a `fun(i64): i64`.
Line 6 stores `double` in `f` without calling it, and line 7 calls it through `f`.
`apply` on line 3 takes a function as a parameter, and line 8 passes it `double` by name, as `update` took `add_one` in Ref.
Line 9 prints `f` itself, through `.debug()`.
Press Run.

A function's debug form is `<fun>`, and `console.println(f)` without `.debug()` is E0422, as for an array.
Function values have no `==`: `f == double` is E0404.

```lugha
fun double(n: i64): i64 = n * 2;

fun apply(f: fun(i64): i64, x: i64): i64 = f(x);

fun main(console: Console) {
    let f = double;
    console.println(f(5));
    console.println(apply(double, 21));
    console.println(f.debug());
}
```

Output:

```text
10
42
<fun>
```

## Step 2: Arrays of functions
Kind: read

Functions can sit in an array like any other value.
`steps` on line 6 holds three of them.
Its type, `(fun(i64): i64)[]`, needs the parentheses, because `fun(i64): i64[]` is a function that returns an array.
Line 9 calls each element as `step(n)`, in the array's order, and keeps the result in `n`.
Press Run.

```lugha
fun double(n: i64): i64 = n * 2;
fun square(n: i64): i64 = n * n;
fun negate(n: i64): i64 = -n;

fun main(console: Console) {
    let steps: (fun(i64): i64)[] = [double, square, negate];
    let mut n = 3;
    for step of steps {
        n = step(n);
    }
    console.println(n);
}
```

Output:

```text
-36
```

## Step 3: Variants as functions
Kind: read

A variant that carries data is a function value too: `Shape.Circle` is a `fun(f64): Shape`.
Lines 15 and 16 pass `Shape.Circle` and `Shape.Square` to `apply_all` without calling them, and line 9 calls each one on a size.
`Some`, `Ok` and `Err` are function values the same way, once a written function type says what they hold, as `wrap`'s type does on line 17.
A struct's associated function, such as `Point.new` from Methods, is a value too.
Press Run.

```lugha
enum Shape {
    Circle(f64),
    Square(f64),
}

fun apply_all(make: fun(f64): Shape, sizes: f64[]): Shape[] {
    let mut out: Shape[] = [];
    for s of sizes {
        out.push(make(s));
    }
    out
}

fun main(console: Console) {
    console.println(apply_all(Shape.Circle, [1.0, 2.0]).debug());
    console.println(apply_all(Shape.Square, [3.0]).debug());
    let wrap: fun(f64): Option<f64> = Some;
    console.println(wrap(2.0).debug());
}
```

Output:

```text
[Circle(1.0), Circle(2.0)]
[Square(3.0)]
Some(2.0)
```
