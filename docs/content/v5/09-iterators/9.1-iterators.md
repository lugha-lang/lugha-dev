## Step 1: Iterators
Kind: read

Besides arrays, `for … of` steps through iterators, which hand out their values one at a time.
`range(1, 4)` on line 2 is an iterator over the same numbers as the range `1..4` in Loops, `1` to `3`.
`chars()` on line 5 gives a string's characters, and `bytes()` on line 8 its bytes, as a plain `for … of` over a string does in Bytes.
`iter()` on line 11 makes an iterator over an array's items.
Press Run.

`é` is one character but two bytes, `195` and `169`.

```lugha
fun main(console: Console) {
    for n of range(1, 4) {
        console.println(n);
    }
    for c of "hé".chars() {
        console.println(c);
    }
    for b of "hé".bytes() {
        console.println(b);
    }
    let it = [10, 20].iter();
    for x of it {
        console.println(x);
    }
}
```

Output:

```text
1
2
3
h
é
104
195
169
10
20
```

## Step 2: Chaining iterators
Kind: read

Iterators have `map` and `filter` too, and each gives back another iterator, so they line up one after another.
Line 2 takes the numbers from 1 to 9, keeps the multiples of 3 and squares them.
`collect()` at the end puts the results in an array.
`chain` on line 4 gives one iterator's values, then another's.
Press Run.

```lugha
fun main(console: Console) {
    let squares = range(1, 10).filter(fun(n) = n % 3 == 0).map(fun(n) = n * n).collect();
    console.println(squares.debug());
    let all = [1, 2].iter().chain([3, 4].iter()).collect();
    console.println(all.debug());
}
```

Output:

```text
[9, 36, 81]
[1, 2, 3, 4]
```

## Step 3: enumerate
Kind: read

`enumerate()` pairs each value with its position, counting from 0.
Each item it gives has two fields, `i` for the position and `value` for the value, and line 4 reads both.
Press Run.

```lugha
fun main(console: Console) {
    let names = ["Ann", "Ben", "Cy"];
    for p of names.iter().enumerate() {
        console.println("{p.i}: {p.value}");
    }
}
```

Output:

```text
0: Ann
1: Ben
2: Cy
```

## Step 4: zip
Kind: read

`zip` walks two iterators side by side and gives tuples, which line 4 takes apart into `name` and `age`.
`names` has three names and `ages` only two numbers.
Press Run.

`Cy` isn't printed: `zip` stops at the end of the shorter one.

```lugha
fun main(console: Console) {
    let names = ["Ann", "Ben", "Cy"];
    let ages = [31, 25];
    for (name, age) of names.iter().zip(ages.iter()) {
        console.println("{name} is {age}");
    }
}
```

Output:

```text
Ann is 31
Ben is 25
```

## Step 5: Laziness
Kind: read

On an array, `map` runs its closure at once and makes a new array, as in Array helpers.
Line 2 calls `map` on `[1, 2, 3].iter()` instead, with a closure that prints each number it doubles.
Line 6 prints `made the iterator`, and line 7 takes two values.
Press Run.

No `doubling` line comes before `made the iterator`: `map` on an iterator runs nothing yet.
The closure runs only when line 7 pulls values, and `take(2)` pulls two, so `3` is never doubled.
That's why line 8 can start from a range up to a billion: `skip(1)` passes over the first multiple of 7, and `take(3)` stops pulling once it has three.

```lugha
fun main(console: Console) {
    let doubled = [1, 2, 3].iter().map(fun(n: i64): i64 {
        console.println("doubling {n}");
        n * 2
    });
    console.println("made the iterator");
    console.println(doubled.take(2).collect().debug());
    console.println(range(10, 1000000000).filter(fun(n) = n % 7 == 0).skip(1).take(3).collect().debug());
}
```

Output:

```text
made the iterator
doubling 1
doubling 2
[2, 4]
[21, 28, 35]
```

## Step 6: More adapters
Kind: read

A few more helpers give back an iterator, like `map` and `filter`.
`take_while` on line 3 takes values while its closure holds, and stops at the first that fails, the `9`.
`skip_while` on line 4 skips values while its closure holds.
`flat_map` on line 6 turns each value into an iterator of its own and gives their values in turn, here each word's characters.
`flat_map`'s characters print with their quotes, since a `char` keeps them in a debug form, as a string does.
`bytes()` on line 7, from the first step, gives `u8` numbers.
Press Run.

Once `9` fails, `skip_while` stops checking, so `4` comes through too.
Arrays don't have these, or `take` and `skip`: `xs.take(2)` is E0415, "no method `take` on `i64[]`", so `.iter()` comes first.

```lugha
fun main(console: Console) {
    let temps = [3, 5, 9, 4, 8];
    console.println(temps.iter().take_while(fun(t) = t < 9).collect().debug());
    console.println(temps.iter().skip_while(fun(t) = t < 9).collect().debug());
    let words = ["ab", "cd"];
    console.println(words.iter().flat_map(fun(w) = w.chars()).collect().debug());
    console.println("hi".bytes().collect().debug());
}
```

Output:

```text
[3, 5]
[9, 4, 8]
['a', 'b', 'c', 'd']
[104, 105]
```
