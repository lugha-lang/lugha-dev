## Step 1: impl Iter
Kind: fix (start gives E0411 "cannot iterate over `Countdown`" on line 14, help "`Countdown` has a method `next`, but a loop needs `impl Iter<T> for Countdown { fun next(mut self): Option<T> … }`", and E0415 "no method `filter` on `Countdown`" on line 17)

A type becomes an iterator by implementing `Iter<T>`, where the one method to write is `fun next(mut self): Option<T>`: `Some` with the next value, or `None` when it's done.
The `next` on lines 4 to 10 makes `Countdown` count down from `n`, in a plain `impl Countdown`.
Line 14 loops over a `Countdown`, and line 17 filters one.
Press Run.

E0411 on line 14: "cannot iterate over `Countdown`", and its help says why: it has a method `next`, but a loop needs `impl Iter<T> for Countdown`.
As with operators in Operator overloading, the name alone isn't enough, and without the `impl` there's no `filter` either, E0415 on line 17.
Change `impl Countdown` on line 3 to `impl Iter<i64> for Countdown`, or press Solve.
Then `for … of` calls `next` until it gives `None`, and the helpers from Iterators and Using up an iterator work on it.
A struct literal after `of` keeps its parentheses, as on line 14: without them it's E0205, as in Struct literals in conditions.

Start:

```lugha
struct Countdown { n: i64 }

impl Countdown {
    fun next(mut self): Option<i64> {
        if self.n == 0 {
            return None;
        }
        self.n -= 1;
        Some(self.n + 1)
    }
}

fun main(console: Console) {
    for n of (Countdown { n: 3 }) {
        console.println(n);
    }
    console.println((Countdown { n: 5 }).filter(fun(n) = n % 2 == 1).collect().debug());
}
```

Solution:

```lugha
struct Countdown { n: i64 }

impl Iter<i64> for Countdown {
    fun next(mut self): Option<i64> {
        if self.n == 0 {
            return None;
        }
        self.n -= 1;
        Some(self.n + 1)
    }
}

fun main(console: Console) {
    for n of (Countdown { n: 3 }) {
        console.println(n);
    }
    console.println((Countdown { n: 5 }).filter(fun(n) = n % 2 == 1).collect().debug());
}
```

Output (solution):

```text
3
2
1
[5, 3, 1]
```

## Step 2: Iterators in generic code
Kind: read

`Iter<i64>` is an interface, so it can be a bound, as in Generic functions.
`total` on line 13 takes any `I: Iter<i64>` and adds up what its loop gives.
Line 22 passes a `Countdown`, line 23 a `range`, and line 24 a `map` over an array's iterator: three different iterators, each an `Iter<i64>`.
Press Run.

```lugha
struct Countdown { n: i64 }

impl Iter<i64> for Countdown {
    fun next(mut self): Option<i64> {
        if self.n == 0 {
            return None;
        }
        self.n -= 1;
        Some(self.n + 1)
    }
}

fun total<I: Iter<i64>>(it: I): i64 {
    let mut sum = 0;
    for x of it {
        sum += x;
    }
    sum
}

fun main(console: Console) {
    console.println(total(Countdown { n: 4 }));
    console.println(total(range(1, 5)));
    console.println(total([2, 3].iter().map(fun(x) = x * 10)));
}
```

Output:

```text
10
10
50
```
