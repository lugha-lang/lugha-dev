## Step 1: collect, sum, count and find
Kind: read

Some helpers use an iterator up: they pull its values and give back one answer instead of another iterator.
`sum()` and `count()` on lines 3 and 4 add the values up and count them.
`find` on line 5 gives the first value its closure returns `true` for, as an `Option`, since there may be none.
`min`, `max` and `position` on lines 6 to 8 give `Option`s for the same reason.
`collect()` on line 9, after a `filter`, is one of them too, and `fold`, `any` and `all` from Array helpers work on iterators as well.
Every line uses the same `scores`.
Press Run.

Each helper works on its own copy of the iterator, so every line starts again from `7`, and `count()` still finds four values.

```lugha
fun main(console: Console) {
    let scores = [7, 3, 9, 4].iter();
    console.println(scores.sum());
    console.println(scores.count());
    console.println(scores.find(fun(s) = s > 8).debug());
    console.println(scores.min().debug());
    console.println(scores.max().debug());
    console.println(scores.position(fun(s) = s == 9).debug());
    console.println(scores.filter(fun(s) = s > 5).collect().debug());
}
```

Output:

```text
23
4
Some(9)
Some(3)
Some(9)
Some(2)
[7, 9]
```

## Step 2: collect_map and collect_set
Kind: read

An iterator can end in a set or a map instead of an array.
`collect_set()` on line 3 keeps each name once, in the order first seen.
`collect_map()` on line 5 needs tuples of key and value, and when a key comes twice, it keeps its first place and its later value wins.
Press Run.

```lugha
fun main(console: Console) {
    let names = ["ann", "bo", "ann"];
    console.println(names.iter().collect_set().debug());
    let scores = [("ann", 1), ("bo", 2), ("ann", 3)];
    console.println(scores.iter().collect_map().debug());
}
```

Output:

```text
Set { "ann", "bo" }
Map { "ann": 3, "bo": 2 }
```

## Step 3: The loop's copy
Kind: read

The loop on lines 3 to 5 goes through every value, and lines 6 and 7 use `it` again afterwards.
Press Run.

A plain `for … of`, without `mut`, works on a copy of the iterator, as a helper does: `it` is unchanged, so `count()` still finds three values and `take(1)` still starts from `1`.

```lugha
fun main(console: Console) {
    let it = [1, 2, 3].iter();
    for x of it {
        console.println(x);
    }
    console.println(it.count());
    console.println(it.take(1).collect().debug());
}
```

Output:

```text
1
2
3
3
[1]
```
