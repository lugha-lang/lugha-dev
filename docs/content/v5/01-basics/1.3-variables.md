# 1.3 Variables (v5, Lugha v18)

## Objectives

1. **Variable declaration** *(v4 kept)*: `let`, with the type worked out or written after a colon. [values-and-types]
2. **Mutable variables** *(v4 kept)*: `let mut`, and E0501 without it. [values-and-types]
3. **Assignment** *(v4 kept)*: a statement with no value, so `a = b = 0` is E0204. [values-and-types]
4. **Number literal types** *(v4 kept)*: from what's around it, else `i64` or `f64`; one that doesn't fit is a compile error. [values-and-types]
5. **Shadowing** *(v4 kept)*: a second `let`, and `let x = x + 1;` reads the outer `x`. [values-and-types]
6. **Constants** *(v4 kept)*: `const NAME: T = value;`, and no mutable globals. [values-and-types]

## Step 1: Variable declaration
Kind: read

Every value so far went straight into `console.println`.
`let` gives a value a name instead: line 2 gives `7` the name `width`, and line 3 gives `3` the name `height`, with its type, `i64`, written after a colon.
Press Run.

Line 4 uses the names where the values would go, and prints `21`.
A `let` doesn't need its type written, because `lughac` takes it from the value, as it did for `width`.

```lugha
fun main(console: Console) {
    let width = 7;
    let height: i64 = 3;
    console.println(width * height);
}
```

Output:

```text
21
```

## Step 2: Mutable variables
Kind: fix (start gives E0501 "cannot assign to `count`: it is not mutable", help "make it mutable: `let mut count`")

Line 3 tries to add 1 to `count`.
Press Run.

It doesn't compile, and `lughac` reports E0501.
A variable keeps the value it was given unless it's declared `let mut`.
Add `mut` after `let` on line 2 and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let count = 0;
    count = count + 1;
    console.println(count);
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut count = 0;
    count = count + 1;
    console.println(count);
}
```

Output (solution):

```text
1
```

## Step 3: Assignment
Kind: fix (start gives E0204 "assignment is a statement, not an expression")

Both `a` and `b` are `let mut` this time, and line 4 tries to set both to `0` in one go, with `a = b = 0`.
Press Run.

`lughac` refuses it with E0204, "assignment is a statement, not an expression".
An assignment is only ever a statement, with no value at all, so `b = 0` has nothing for `a` to take.
Split line 4 into two assignments, `a = 0;` and `b = 0;`, one per line, or press Solve.

Start:

```lugha
fun main(console: Console) {
    let mut a = 1;
    let mut b = 2;
    a = b = 0;
    console.println(a + b);
}
```

Solution:

```lugha
fun main(console: Console) {
    let mut a = 1;
    let mut b = 2;
    a = 0;
    b = 0;
    console.println(a + b);
}
```

Output (solution):

```text
0
```

## Step 4: Number literal types
Kind: fix (start gives E0402 "integer literal out of range for u8", help "u8 holds 0 to 255")

A whole number takes its type from what's around it.
Line 2 asks for nothing, so its `7` is an `i64`, the type a whole number gets when nothing decides.
Line 3 asks for a `u8`, a whole number from 0 to 255, and line 4 multiplies `height` by `300`.
Press Run.

`lughac` refuses line 4 with E0402.
The `300` takes its type from `height` on the other side of the `*`, and `300` doesn't fit in a `u8`.
Change `300` to `30` and run again, or press Solve: `scaled` is a `u8` too, and 210 fits.
A whole number never becomes a float, so a float is always written with its `.`, as in `5.0`.

Start:

```lugha
fun main(console: Console) {
    let width = 7;
    let height: u8 = 7;
    let scaled = height * 300;
    console.println(width);
    console.println(scaled);
}
```

Solution:

```lugha
fun main(console: Console) {
    let width = 7;
    let height: u8 = 7;
    let scaled = height * 30;
    console.println(width);
    console.println(scaled);
}
```

Output (solution):

```text
7
210
```

## Step 5: Shadowing
Kind: read

There's another way to give a name a new value without `mut`: declare it again.
Line 3 declares `score` a second time, from the old `score`.
Press Run.

It compiles and prints `15`.
A second `let` makes a new variable that hides the old one, which is called shadowing.
The new `score` starts at the end of its declaration, so `score + 5` on line 3 reads the old one.
Line 5 shadows it again with a string, which `mut` could never do: assigning changes a variable's value but never its type, while shadowing makes a new variable.

```lugha
fun main(console: Console) {
    let score = 10;
    let score = score + 5;
    console.println(score);
    let score = "fifteen";
    console.println(score);
}
```

Output:

```text
15
fifteen
```

## Step 6: Constants
Kind: read

A value the whole program shares is a constant, declared with `const` outside any function, as on line 1.
Its type is always written.
Press Run.

Line 5 reads `MAX_SCORE` like a variable, but nothing can assign to it, and trying is E0501.
`let` is refused outside a function, so a shared value is always a `const`, worked out once before `main` runs.

```lugha
const MAX_SCORE: i64 = 100;

fun main(console: Console) {
    let score = 40;
    console.println(MAX_SCORE - score);
}
```

Output:

```text
60
```
