## Step 1: The main function
Kind: read

A Lugha program starts at `main`, and this one prints `Hello, world`.
Line 1 is a doc comment, `/** … */`, which editors show beside the item that follows it.
When the program starts, `main` is given the console as a parameter, `console: Console` on line 2, and printing goes through it, as `console.println` on line 3.
Press Run.

The output ends with the exit code, 0: this `main` returns nothing, so the program ends with 0 when it reaches the end of `main`.

```lugha
/** Says hello. */
fun main(console: Console) {
    console.println("Hello, world");
}
```

Output:

```text
Hello, world
```

## Step 2: Semicolons
Kind: fix (start gives E0201 "expected `;`, found identifier `console`")

Now there are two `console.println` lines, and line 2 has no semicolon.
Press Run.

`lughac` gives E0201: it expected a `;` where line 3 begins.
Lugha reads a line break the same as a space, so a statement ends at its `;`, not at the end of a line.

Add the `;` on line 2 and run again, or press Solve.
It's also why two statements can share one line, as long as each has its `;`.

Start:

```lugha
fun main(console: Console) {
    console.println("one")
    console.println("two");
}
```

Solution:

```lugha
fun main(console: Console) {
    console.println("one");
    console.println("two");
}
```

Output (solution):

```text
one
two
```

## Step 3: Comments
Kind: read

`//` turns the rest of a line into a comment, as on line 2, and `/* … */` can cover several lines.
In Lugha a `/*` comment can hold another one: line 3 opens a comment, and line 4 opens a second inside it.
Press Run.

Only `one` and `five` print.
Block comments nest, so the `*/` on line 4 closes only the inner comment, and the outer one runs on to line 5.
So you can comment out code that already has a comment in it.

```lugha
fun main(console: Console) {
    console.println("one"); // a comment to the end of the line
    /* console.println("two");
       /* console.println("three"); */
       console.println("four"); */
    console.println("five");
}
```

Output:

```text
one
five
```

## Step 4: Exit codes
Kind: fix (start prints "checking the input" and exits 1)

`main` can also return an `i32`, which becomes the program's exit code.
Here line 3, `1`, has no `;` because it isn't a statement: the last expression in a body, written without a `;`, is the value the body gives back.
Press Run, and the program exits with code 1, which whatever ran it reads as a failure.

Change line 3 to `0` and run again, or press Solve.
There is no `exit` to call: a program ends with a code by returning it from `main`.
`main` returns nothing or an `i32`, and `lughac` refuses anything else with E0304.

Start:

```lugha
fun main(console: Console): i32 {
    console.println("checking the input");
    1
}
```

Output (start):

```text
checking the input
```

Solution:

```lugha
fun main(console: Console): i32 {
    console.println("checking the input");
    0
}
```

Output (solution):

```text
checking the input
```
