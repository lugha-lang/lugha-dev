## Step 1: Integer types
Kind: read

Every value in Lugha has a type, and whole numbers have eight of them.
`i8`, `i16`, `i32` and `i64` hold negative numbers too, and `u8` to `u64` start at zero.
The number in each name is the size in bits, and each type's limits are on its name as `MIN` and `MAX`.
Press Run.

Line 4 prints `255`, the largest number 8 bits can hold, and line 5 shows how far `i64` goes.

```lugha
fun main(console: Console) {
    console.println(i8.MIN);
    console.println(i8.MAX);
    console.println(u8.MAX);
    console.println(i64.MAX);
}
```

Output:

```text
-128
127
255
9223372036854775807
```

## Step 2: Floating-point types
Kind: read

Numbers with a fraction are floats, and they come in two types, `f32` and `f64`.
Press Run.

A number written with a point, like `2.0` on line 2, is an `f64`.
It prints `2.0`: a float always prints with its point, so you can tell it from a whole number.
Line 3 is ten million billion written out in full, and a float that large prints with an exponent, `1.0e16`.
Line 4 prints a `bool`, which is `true` or `false`.

```lugha
fun main(console: Console) {
    console.println(2.0);
    console.println(10000000000000000.0);
    console.println(true);
}
```

Output:

```text
2.0
1.0e16
true
```

## Step 3: Integer literals
Kind: read

Whole numbers print in plain decimal, however you write them.
Lines 2 to 5 use `_` between digits, then `0x`, `0b` and `0o` for hex, binary and octal.
Line 6 writes `017`.
Press Run.

It prints `17`, with warning W0107, because a leading zero changes nothing.
Octal needs `0o`, as on line 5.

```lugha
fun main(console: Console) {
    console.println(1_000_000);
    console.println(0xFF);
    console.println(0b1010);
    console.println(0o17);
    console.println(017);
}
```

Output (with W0107 "a leading zero doesn't make an octal number: this is 17"):

```text
1000000
255
10
15
17
```

## Step 4: Float literals
Kind: fix (start gives E0107 "float literal needs a fractional part", help "write 2.0e5")

Back to floats: line 2 tries to write two hundred thousand as `2e5`.
Press Run.

An exponent makes a float, and a float literal needs a fractional part, so `lughac` refuses `2e5` with E0107.

Write `2.0e5` on line 2 and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    console.println(2e5);
}
```

Solution:

```lugha
fun main(console: Console) {
    console.println(2.0e5);
}
```

Output (solution):

```text
200000.0
```

## Step 5: Characters and strings
Kind: fix (start gives E0102 "unterminated string" on lines 5 and 6, help "strings end on the line they start; write `\n` for a line break")

That leaves text, which has two types.
A `char` in single quotes is one character, as on line 2.
A `string` in double quotes is any text, with escapes such as `\t` for a tab on line 4.
`\u{…}` writes a character by its Unicode number in hex, in a `char` on line 3 and in a string on line 4.
The string on line 5 runs on to line 6.
Press Run.

`lughac` reports E0102 twice, once for each line, because a string ends on the line it starts.
A line break inside a string is written `\n`.

Join lines 5 and 6 with `\n` and run again, or press Solve.

Start:

```lugha
fun main(console: Console) {
    console.println('a');
    console.println('\u{e9}');
    console.println("tab:\tend, caf\u{e9}");
    console.println("first line
second line");
}
```

Solution:

```lugha
fun main(console: Console) {
    console.println('a');
    console.println('\u{e9}');
    console.println("tab:\tend, caf\u{e9}");
    console.println("first line\nsecond line");
}
```

Output (solution):

```text
a
é
tab:	end, café
first line
second line
```
