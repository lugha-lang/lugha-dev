## Step 1: with on your own interfaces
Kind: fix (start gives E0422 "`Book` doesn't implement `Describe`" on line 24, help "add `with Describe` after `Book`'s declaration, or implement it by hand with `impl Describe for Book`")

`with Eq` and `with Key` asked for interfaces the language knows how to build from a type's fields.
Your own interface can be built that way too, once it says how: the `derive` blocks on lines 5, 9 and 15 say how `i64`s, strings and every struct get `Describe`, and the next steps show how they're written.
`tell` on line 21 takes any `T: Describe`, and line 24 passes it a `Book`.
Press Run.

E0422 on line 24: "`Book` doesn't implement `Describe`".
A struct gets an interface from its blocks only when it asks, as it does for `Eq`.
Add `with Describe` after the `}` on line 19, or press Solve.
`impl Describe for Book = derive;` on a line of its own asks the same way.

Start:

```lugha
interface Describe {
    fun describe(self): string;
}

derive Describe for i64 {
    fun describe(self): string = "{self}";
}

derive Describe for string {
    fun describe(self): string = "\"{self}\"";
}

fun part<F: Describe>(ctx: (), name: string, field: F): string = "{name} is {field.describe()}";

derive Describe for struct {
    fun describe(self): string = derive.fields(self, (), part).join(", ");
}

struct Book { title: string, pages: i64 }

fun tell<T: Describe>(x: T): string = x.describe();

fun main(console: Console) {
    console.println(tell(Book { title: "Dune", pages: 412 }));
}
```

Solution:


## Step 2: Derive blocks
Kind: read

A derive block says, in one place, how a type gets an interface's items.
Line 5 says how every `i64` gets `Describe`, and line 9 does the same for `string`.
`tell` on line 13 takes any `T: Describe`, so lines 16 and 17 call it with either.
A block's items are reached through the interface: through a bound such as `tell`'s, or by naming it, as `Describe.describe(7)` on line 18 does.
Press Run.

```lugha
interface Describe {
    fun describe(self): string;
}

derive Describe for i64 {
    fun describe(self): string = "the number {self}";
}

derive Describe for string {
    fun describe(self): string = "the text \"{self}\"";
}

fun tell<T: Describe>(x: T): string = x.describe();

fun main(console: Console) {
    console.println(tell("hi"));
    console.println(tell(5));
    console.println(Describe.describe(7));
}
```

Output:

```text
the text "hi"
the number 5
the number 7
```

## Step 3: Deriving for structs
Kind: fix (start gives E0451 "`Book` doesn't meet `Describe`: `price` is `f64`, which no `derive Describe` block covers" on line 19, help "`Describe` has blocks for `i64`, `string` and structs")

`derive Describe for struct` on line 15 covers every struct that asks.
Inside it, `derive.fields(self, (), part)` calls `part` once per field, in order, and gives back an array of the results.
`part` on line 13 is passed as a value, as in Functions as values, and gets the second argument as `ctx`, then the field's name and value.
Here `ctx` is `()`, nothing; derive.build, in step 8, puts it to use.
`part` is generic over one `F: Describe`, since each field has its own type.
Line 19's `Book` now has a `price`, an `f64`.
Press Run.

E0451 on line 19, where `Book` asks: "`price` is `f64`, which no `derive Describe` block covers".
A struct gets `Describe` only when each of its fields does.
After line 11, add a `derive Describe for f64` block with `fun describe(self): string = "{self}";` in it, or press Solve.
A struct's `describe` is reached only through the interface: `Book { … }.describe()` is E0415.

## Step 4: Deriving for enums
Kind: read

`derive Describe for enum` on line 15 covers every enum that asks, as `Shape` does on line 22.
`derive.variant(self, (), part)` on line 17 gives a tuple: the variant's name, and an array of what `part` returns for each payload.
Each payload has no name of its own, so `part` gets the variant's name, unused here.
`Dot` has no payloads, so its array is empty.
`derive.index(self)` on line 18 is the variant's position in the enum, counting from 0.
Press Run.

```lugha
interface Describe {
    fun describe(self): string;
}

derive Describe for i64 {
    fun describe(self): string = "{self}";
}

derive Describe for string {
    fun describe(self): string = "\"{self}\"";
}

fun part<F: Describe>(ctx: (), name: string, field: F): string = field.describe();

derive Describe for enum {
    fun describe(self): string {
        let (name, parts) = derive.variant(self, (), part);
        return "variant {derive.index(self)}, {name}({parts.join(", ")})";
    }
}

enum Shape { Dot, Square(i64), Label(string, i64) } with Describe

fun tell<T: Describe>(x: T): string = x.describe();

fun main(console: Console) {
    console.println(tell(Shape.Dot));
    console.println(tell(Shape.Square(3)));
    console.println(tell(Shape.Label("door", 2)));
}
```

Output:

```text
variant 0, Dot()
variant 1, Square(3)
variant 2, Label("door", 2)
```
