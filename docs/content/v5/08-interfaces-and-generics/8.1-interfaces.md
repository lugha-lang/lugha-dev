## Step 1: Interface declaration
Kind: read

An interface names a set of methods that different types can share.
`Shape` on lines 1 to 4 lists two, with their signatures and no bodies.
`Circle` implements it with `impl Shape for Circle` on lines 8 to 11, which gives each method its body, and line 15 calls them with a dot, like the methods in Methods.
An interface's methods can use `Self` for the type that implements it, as in `fun bigger(self, other: Self): bool`.
Press Run.

```lugha
interface Shape {
    fun area(self): f64;
    fun name(self): string;
}

struct Circle { r: f64 }

impl Shape for Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
    fun name(self): string = "circle";
}

fun main(console: Console) {
    let c = Circle { r: 1.0 };
    console.println("{c.name()}: {c.area()}");
}
```

Output:

```text
circle: 3.14
```

## Step 2: Implementing an interface
Kind: fix (start gives E0422 "`Circle` doesn't implement `Shape`", help "add `impl Shape for Circle { … }`")

`describe` on line 13 takes any `Shape`, and line 16 passes it a `Circle`.
This time `Circle`'s methods on lines 8 to 11 are in a plain `impl Circle`, with the same names and signatures as `Shape`'s.
Press Run.

E0422: "`Circle` doesn't implement `Shape`".
Having methods with the right names isn't enough: a type implements an interface only through an `impl Shape for …` block.
Change `impl Circle` on line 8 to `impl Shape for Circle`, or press Solve.
An `impl Shape for Circle` that leaves a method out is E0422 too, at the block, and its help names the missing method.

Start:

```lugha
interface Shape {
    fun area(self): f64;
    fun name(self): string;
}

struct Circle { r: f64 }

impl Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
    fun name(self): string = "circle";
}

fun describe(s: Shape): string = "{s.name()} of area {s.area()}";

fun main(console: Console) {
    console.println(describe(Circle { r: 1.0 }));
}
```

Solution:

```lugha
interface Shape {
    fun area(self): f64;
    fun name(self): string;
}

struct Circle { r: f64 }

impl Shape for Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
    fun name(self): string = "circle";
}

fun describe(s: Shape): string = "{s.name()} of area {s.area()}";

fun main(console: Console) {
    console.println(describe(Circle { r: 1.0 }));
}
```

Output (solution):

```text
circle of area 3.14
```

## Step 3: Where an impl lives
Kind: fix (start gives E0459 "this `impl Display for …` must be written in the module that declares `Display`")

A program can be split into modules, which come in Modules in chapter 11; every program so far has been one.
An `impl` is written in the module that declares the interface or the one that declares the type.
Line 1 implements `Display` for `bool`, so that `true` would print as `yes`; `Display` is the interface `console.println` prints through.
Press Run.

E0459: "this `impl Display for …` must be written in the module that declares `Display`".
`Display` and `bool` both come with the language, so neither is declared in this program, and no `impl` here can implement one for the other.
Declare an interface of your own instead: above line 1, write an interface `Label` with one method, `fun label(self): string;`, then change line 1 to `impl Label for bool {`, `show` on line 2 to `label`, and line 6 to print `true.label()`, or press Solve.
For a type you declare yourself, `impl Display` is allowed, as Equality, ordering and printing shows later in this chapter.

Start:

```lugha
impl Display for bool {
    fun show(self): string = if self { "yes" } else { "no" };
}

fun main(console: Console) {
    console.println(true);
}
```

Solution:

```lugha
interface Label {
    fun label(self): string;
}

impl Label for bool {
    fun label(self): string = if self { "yes" } else { "no" };
}

fun main(console: Console) {
    console.println(true.label());
}
```

Output (solution):

```text
yes
```

## Step 4: Default methods
Kind: read

An interface can give a method a body, which is then its default.
`describe` on line 3 has one, and it calls `area` on `self`.
`Circle`'s `impl` on lines 9 to 11 has no `describe`, so line 19 uses the default.
`Square`'s `impl` writes its own on line 15, which line 20 calls.
Press Run.

```lugha
interface Shape {
    fun area(self): f64;
    fun describe(self): string = "a shape of area {self.area()}";
}

struct Circle { r: f64 }
struct Square { side: f64 }

impl Shape for Circle {
    fun area(self): f64 = 3.14 * self.r * self.r;
}

impl Shape for Square {
    fun area(self): f64 = self.side * self.side;
    fun describe(self): string = "a square with side {self.side}";
}

fun main(console: Console) {
    console.println(Circle { r: 1.0 }.describe());
    console.println(Square { side: 2.0 }.describe());
}
```

Output:

```text
a shape of area 3.14
a square with side 2.0
```

## Step 5: Interfaces extending interfaces
Kind: fix (start gives E0415 "no method `name` on `Dog`" on line 17, and E0422 "`Dog` implements `Pet` but not `Named`, which `Pet` extends", help "add `with Named`, or write `impl Named for Dog { … }`")

`Pet` on line 5 extends `Named`: `interface Pet: Named` means every `Pet` is a `Named` too.
Line 11 implements `Pet` for `Dog`, and line 17 calls both `name` and `sound`.
Press Run.

E0422 on line 11: "`Dog` implements `Pet` but not `Named`, which `Pet` extends".
Implementing `Pet` doesn't implement `Named` for you, and E0415 on line 17 follows: `Dog` has no `name`.
Above line 11, add an `impl Named for Dog` block with `fun name(self): string = "dog";` in it, or press Solve.
Each interface gets its own block: `name` written inside `impl Pet for Dog` is E0422, "`name` isn't an item of `Pet`", and the help's `with Named` is E0462 here, since `with` needs derive blocks, which come in Deriving.

Start:

```lugha
interface Named {
    fun name(self): string;
}

interface Pet: Named {
    fun sound(self): string;
}

struct Dog {}

impl Pet for Dog {
    fun sound(self): string = "woof";
}

fun main(console: Console) {
    let d = Dog {};
    console.println("the {d.name()} says {d.sound()}");
}
```

Solution:

```lugha
interface Named {
    fun name(self): string;
}

interface Pet: Named {
    fun sound(self): string;
}

struct Dog {}

impl Named for Dog {
    fun name(self): string = "dog";
}

impl Pet for Dog {
    fun sound(self): string = "woof";
}

fun main(console: Console) {
    let d = Dog {};
    console.println("the {d.name()} says {d.sound()}");
}
```

Output (solution):

```text
the dog says woof
```
