## Step 1: Deep equality
Kind: read

`==` reaches into a value's parts, so line 4 compares two `Point`s field by field, as `with Eq` did in Structs.
Arrays compare element by element, as on lines 5 and 6, and `Some(a)` equals `Some(b)` when `a` equals `b`.
Line 7 divides zero by zero, which gives a float that isn't a number, `NaN`, and line 8 compares it with itself.
A `Ref` box, a function and an interface value have no `==`, and nor does an array or an `Option` that holds one.
Press Run.

Line 8 prints `false`: `NaN` is equal to nothing, itself included.
`==` works on a value only when each of its parts has `Eq`: comparing two arrays of `Point`s, with no `with Eq` on `Point`, is E0422, naming `Point`.

```lugha
struct Point { x: i64, y: i64 } with Eq

fun main(console: Console) {
    console.println(Point { x: 1, y: 2 } == Point { x: 1, y: 2 });
    console.println([Some(1), None] == [Some(1), None]);
    console.println([[1, 2], [3]] != [[1, 2], [4]]);
    let nan = 0.0 / 0.0;
    console.println(nan == nan);
}
```

Output:

```text
true
true
true
false
```

## Step 2: with Eq, with Ord and with Key
Kind: read

`with` after a declaration asks for an interface built from the fields.
`with Eq` compares them, `with Ord` orders by the fields, in the order they're declared, and `with Key` hashes them so the type can be a map key or a set value.
`Ord` and `Key` both extend `Eq`, so `Version` on line 1 has `==` too, and so does `Tag` on line 2.
Line 6 prints a sorted copy and leaves `versions` as it was.
Line 7 compares two versions with `<`, line 8 checks one for equality, and line 9 puts two equal tags in a set.
Press Run.

`major` is declared first, so it decides first: 1.9 and 1.10 sort before 2.0.
Between those two, `minor` decides, and 9 comes before 10.
The set on line 9 keeps one of the two equal tags.

```lugha
struct Version { major: i64, minor: i64 } with Ord
struct Tag { name: string } with Key

fun main(console: Console) {
    let versions = [Version { major: 2, minor: 0 }, Version { major: 1, minor: 9 }, Version { major: 1, minor: 10 }];
    console.println(versions.sort().debug());
    console.println(versions[1] < versions[2]);
    console.println(versions[0] == Version { major: 2, minor: 0 });
    let tags = Set { Tag { name: "new" }, Tag { name: "new" } };
    console.println(tags.len);
}
```

Output:

```text
[Version { major: 1, minor: 9 }, Version { major: 1, minor: 10 }, Version { major: 2, minor: 0 }]
true
true
1
```

## Step 3: impl Eq and impl Key
Kind: fix (start gives E0422 "`User` doesn't implement `Key`" on line 11, help "add `with Key` after `User`'s declaration, or implement it by hand with `impl Key for User`")

A type can decide what equal means for itself by writing `Eq` by hand.
`impl Eq for User` on lines 3 to 5 counts two users as equal when their `id`s are, whatever their names.
Line 10 compares two of them, and line 11 puts both in a set.
Press Run.

E0422 on line 11: "`User` doesn't implement `Key`", which a set value needs.
`with Key` would hash every field, `name` too, so two users equal by `id` would hash differently, and equal values must hash the same.
So `Key` is written by hand as well: its `hash` adds to `h`, a `Hasher`, the same fields `eq` compares, here `h.add(self.id);`.
After line 5, add an `impl Key for User` block with `fun hash(self, mut h: Hasher) { h.add(self.id); }` in it, or press Solve.

Start:

```lugha
struct User { id: i64, name: string }

impl Eq for User {
    fun eq(self, other: User): bool = self.id == other.id;
}

fun main(console: Console) {
    let a = User { id: 7, name: "Ann" };
    let b = User { id: 7, name: "Ann B." };
    console.println(a == b);
    console.println(Set { a, b }.len);
}
```

Solution:

```lugha
struct User { id: i64, name: string }

impl Eq for User {
    fun eq(self, other: User): bool = self.id == other.id;
}

impl Key for User {
    fun hash(self, mut h: Hasher) {
        h.add(self.id);
    }
}

fun main(console: Console) {
    let a = User { id: 7, name: "Ann" };
    let b = User { id: 7, name: "Ann B." };
    console.println(a == b);
    console.println(Set { a, b }.len);
}
```

Output (solution):

```text
true
1
```

## Step 4: impl Ord
Kind: fix (start runs with warning W0108 "`Version`'s `==` and `<` can disagree" on line 1, help "write `impl Eq for Version` comparing what `cmp` compares, so `a == b` exactly when `a.cmp(b)` is `Ordering.Equal`; or derive both, `with Ord`")

`Ord` written by hand is one method, `cmp`, which gives back `Ordering.Less`, `Ordering.Equal` or `Ordering.Greater`.
`cmp` on line 4 orders versions by `major` alone, so 1.9 and 1.10 count as one release line, and `sort` on line 17 uses it, as do `<`, `<=`, `>` and `>=`.
`Version` gets `==` from `with Eq` on line 1, and lines 20 and 21 compare 1.9 and 1.10 both ways.
Press Run.

It runs, with W0108: "`Version`'s `==` and `<` can disagree".
Line 20 prints `false`, since the derived `==` compares `minor` too, and line 21 `false`, since `cmp` finds neither less: the two are neither equal nor ordered.
As the help says, write `Eq` to compare what `cmp` compares.
Remove `with Eq` from line 1, and after it add an `impl Eq for Version` block with `fun eq(self, other: Version): bool = self.major == other.major;`, or press Solve.

Start:

```lugha
struct Version { major: i64, minor: i64 } with Eq

impl Ord for Version {
    fun cmp(self, other: Version): Ordering {
        if self.major < other.major {
            Ordering.Less
        } else if self.major > other.major {
            Ordering.Greater
        } else {
            Ordering.Equal
        }
    }
}

fun main(console: Console) {
    let releases = [Version { major: 2, minor: 0 }, Version { major: 1, minor: 9 }, Version { major: 1, minor: 10 }];
    console.println(releases.sort().debug());
    let a = releases[1];
    let b = releases[2];
    console.println(a == b);
    console.println(a < b || b < a);
}
```

Output (start, with W0108):

```text
[Version { major: 1, minor: 9 }, Version { major: 1, minor: 10 }, Version { major: 2, minor: 0 }]
false
false
```

Solution:

```lugha
struct Version { major: i64, minor: i64 }

impl Eq for Version {
    fun eq(self, other: Version): bool = self.major == other.major;
}

impl Ord for Version {
    fun cmp(self, other: Version): Ordering {
        if self.major < other.major {
            Ordering.Less
        } else if self.major > other.major {
            Ordering.Greater
        } else {
            Ordering.Equal
        }
    }
}

fun main(console: Console) {
    let releases = [Version { major: 2, minor: 0 }, Version { major: 1, minor: 9 }, Version { major: 1, minor: 10 }];
    console.println(releases.sort().debug());
    let a = releases[1];
    let b = releases[2];
    console.println(a == b);
    console.println(a < b || b < a);
}
```

Output (solution):

```text
[Version { major: 1, minor: 9 }, Version { major: 1, minor: 10 }, Version { major: 2, minor: 0 }]
true
false
```

## Step 5: impl Display
Kind: read

`console.println` and `"{x}"` print a value through `Display`, one method, `fun show(self): string`.
`impl Display for Version` on lines 3 to 5 shows a version as `v1.10`.
Line 9 prints one, and line 10 puts one in a string.
Line 11 prints an array of versions through `.debug()`.
Press Run.

A debug form never uses `Display`: the array on line 11 shows each `Version` with its fields.

```lugha
struct Version { major: i64, minor: i64 }

impl Display for Version {
    fun show(self): string = "v{self.major}.{self.minor}";
}

fun main(console: Console) {
    let v = Version { major: 1, minor: 10 };
    console.println(v);
    console.println("running {v}");
    console.println([v, Version { major: 2, minor: 0 }].debug());
}
```

Output:

```text
v1.10
running v1.10
[Version { major: 1, minor: 10 }, Version { major: 2, minor: 0 }]
```

## Step 6: impl Debug
Kind: read

A debug form can be written by hand too, with `impl Debug for Version` and its one method, `debug`, on lines 3 to 5.
Line 9 prints a version's debug form, line 10 an array's, and line 11 an `Option`'s.
Press Run.

The hand-written form is used wherever a `Version`'s debug form is, inside the array and the `Option` too.

```lugha
struct Version { major: i64, minor: i64 }

impl Debug for Version {
    fun debug(self): string = "v{self.major}.{self.minor}";
}

fun main(console: Console) {
    let v = Version { major: 1, minor: 10 };
    console.println(v.debug());
    console.println([v, Version { major: 2, minor: 0 }].debug());
    console.println(Some(v).debug());
}
```

Output:

```text
v1.10
[v1.10, v2.0]
Some(v1.10)
```
