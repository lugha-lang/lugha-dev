## Step 1: Arithmetic operators
Kind: fix (start gives E0404 "cannot apply `+` to Vec2" on line 10 and "cannot apply `+=` to Vec2" on line 11, help "write `impl Add<…> for Vec2 { fun add(…) }`")

An operator on a type of your own goes through an interface: `+` through `Add`, whose one method is `add`.
`-`, `*`, `/` and `%` go through `Sub`, `Mul`, `Div` and `Rem` the same way, and a leading `-` through `Neg`.
`Vec2` has an `add` of its own, in a plain `impl Vec2` on lines 3 to 5, and line 10 adds two `Vec2`s.
Press Run.

E0404 on line 10, "cannot apply `+` to Vec2", and on line 11, "cannot apply `+=` to Vec2".
As in Interfaces, a method with the right name isn't enough: `+` needs the `impl`.
Change `impl Vec2` on line 3 to `impl Add for Vec2`, or press Solve.
`b += a` on line 11 then works too, as `b = b + a`.

Start:

```lugha
struct Vec2 { x: f64, y: f64 }

impl Vec2 {
    fun add(self, other: Vec2): Vec2 = Vec2 { x: self.x + other.x, y: self.y + other.y };
}

fun main(console: Console) {
    let a = Vec2 { x: 1.0, y: 2.0 };
    let mut b = Vec2 { x: 3.0, y: 4.0 };
    console.println((a + b).debug());
    b += a;
    console.println(b.debug());
}
```

Solution:

```lugha
struct Vec2 { x: f64, y: f64 }

impl Add for Vec2 {
    fun add(self, other: Vec2): Vec2 = Vec2 { x: self.x + other.x, y: self.y + other.y };
}

fun main(console: Console) {
    let a = Vec2 { x: 1.0, y: 2.0 };
    let mut b = Vec2 { x: 3.0, y: 4.0 };
    console.println((a + b).debug());
    b += a;
    console.println(b.debug());
}
```

Output (solution):

```text
Vec2 { x: 4.0, y: 6.0 }
Vec2 { x: 4.0, y: 6.0 }
```

## Step 2: Mixed operands
Kind: read

`Add` alone means `Add<Vec2>`, a `Vec2` on both sides; `Mul<f64>` says the right-hand operand is an `f64`.
A type can have one block for each right-hand type: `Mul<f64>` on line 3 scales the vector, and `Mul<Vec2>` on line 7 gives a number.
For a number before `*`, `impl Mul<Vec2> for f64` on line 11 makes `2.0 * v` work too, and its `mul` on line 12 turns the operands round and uses line 3's block.
`Mul` and `f64` both come with the language, but a block like this may also be written where its right-hand type is declared, and `Vec2` is declared here.
`v.mul(2.0)` on line 20 calls the method by name, and picks the same block as `v * 2.0`.
Press Run.

The right-hand operand picks a block by its exact type: `v * 2` would be E0404, "no `impl Mul` of `Vec2` takes this operand", since `2` is an integer.

```lugha
struct Vec2 { x: f64, y: f64 }

impl Mul<f64> for Vec2 {
    fun mul(self, k: f64): Vec2 = Vec2 { x: self.x * k, y: self.y * k };
}

impl Mul<Vec2> for Vec2 {
    fun mul(self, other: Vec2): f64 = self.x * other.x + self.y * other.y;
}

impl Mul<Vec2> for f64 {
    fun mul(self, v: Vec2): Vec2 = v * self;
}

fun main(console: Console) {
    let v = Vec2 { x: 1.0, y: 2.0 };
    console.println((v * 2.0).debug());
    console.println((2.0 * v).debug());
    console.println(v * v);
    console.println(v.mul(2.0).debug());
}
```

Output:

```text
Vec2 { x: 2.0, y: 4.0 }
Vec2 { x: 2.0, y: 4.0 }
5.0
Vec2 { x: 2.0, y: 4.0 }
```

## Step 3: Index operators
Kind: read

`[ ]` is an operator too, but unlike `+` it needs no interface: it goes through two methods of the type's own, `index` and `set_index`.
`set_index` makes `grid[1, 0] = 5` on line 17 write a value, and `index` makes line 19 read it back.
`set_index` takes `mut self`, so `grid` needs `let mut`, as an array does.
Several indexes, as in `grid[1, 0]`, arrive as one tuple, which lines 5 and 10 take apart as `x` and `y`, and a single index is a plain parameter, such as `at: i64`.
They're ordinary methods too: lines 20 and 21 call `set_index` and `index` by name, with the tuple written out.
Press Run.

```lugha
struct Grid { width: i64, cells: i64[] }

impl Grid {
    fun index(self, at: (i64, i64)): i64 {
        let (x, y) = at;
        self.cells[y * self.width + x]
    }

    fun set_index(mut self, at: (i64, i64), value: i64) {
        let (x, y) = at;
        self.cells[y * self.width + x] = value;
    }
}

fun main(console: Console) {
    let mut grid = Grid { width: 3, cells: [0; 6] };
    grid[1, 0] = 5;
    grid[2, 1] = 7;
    console.println(grid[1, 0]);
    grid.set_index((0, 1), 9);
    console.println(grid.index((0, 1)));
    console.println(grid.cells.debug());
}
```

Output:

```text
5
9
[0, 5, 0, 9, 0, 7]
```
