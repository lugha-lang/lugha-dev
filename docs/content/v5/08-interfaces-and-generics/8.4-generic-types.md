# 8.4 Generic types (v5, Lugha v18)

## Objectives

1. **Generic structs** *(v4 kept)*: `Pair<T>`; a bare `Pair` in a type is E0418. [generics]
2. **Generic enums** *(v4 kept)*: `List<T>`. [generics]
3. **Generic impl blocks** *(changed)*: `impl<T: Num> Stack<T>`; `impl Stack<T: Num>` is E0214. [generics; m222]

---

## Step 1: Generic structs
Kind: fix (start gives E0418 "`Pair` takes 1 type argument but 0 were given", twice on line 3)

A struct can take a type parameter as a function does: `Pair<T>` on line 1 holds two values of one type, `T`.
Line 6 builds a pair of numbers and line 7 a pair of strings, and `T` comes from the fields, as it came from a function's arguments.
In a type, though, a generic struct is written with its argument, as in `Pair<i64>`.
Line 3 writes a bare `Pair` as a type twice, for `p` and for what `swap_pair` gives back.
Press Run.

Both of line 3's `Pair`s are E0418, "`Pair` takes 1 type argument but 0 were given".
`swap_pair` is called with both pairs, so it has to be generic itself.
On line 3, add `<T>` after `swap_pair` and write `Pair<T>` for the parameter's type and the return type, or press Solve.
The `Pair { … }` after `=` stays as it is: it takes `T` from its fields, as line 6 does.

Start:

```lugha
struct Pair<T> { left: T, right: T }

fun swap_pair(p: Pair): Pair = Pair { left: p.right, right: p.left };

fun main(console: Console) {
    let numbers = Pair { left: 1, right: 2 };
    let words = Pair { left: "tea", right: "milk" };
    console.println(swap_pair(numbers).debug());
    console.println(swap_pair(words).debug());
}
```

Solution:

```lugha
struct Pair<T> { left: T, right: T }

fun swap_pair<T>(p: Pair<T>): Pair<T> = Pair { left: p.right, right: p.left };

fun main(console: Console) {
    let numbers = Pair { left: 1, right: 2 };
    let words = Pair { left: "tea", right: "milk" };
    console.println(swap_pair(numbers).debug());
    console.println(swap_pair(words).debug());
}
```

Output (solution):

```text
Pair { left: 2, right: 1 }
Pair { left: "milk", right: "tea" }
```

## Step 2: Generic enums
Kind: read

Enums take type parameters in the same place.
`List<T>` on lines 1 to 4 is the list from Recursive enums, which held only numbers, now holding any type.
Line 14 builds a list of strings, and `size` on line 6, generic itself as `swap_pair` was, counts it.
`Option<T>`, which `first` gave back in Generic functions, is declared this way too.
Press Run.

```lugha
enum List<T> {
    Nil,
    Cons(T, List<T>),
}

fun size<T>(list: List<T>): i64 {
    match list {
        .Nil => 0,
        .Cons(_, rest) => 1 + size(rest),
    }
}

fun main(console: Console) {
    let words = List.Cons("tea", List.Cons("milk", List.Nil));
    console.println(words.debug());
    console.println(size(words));
}
```

Output:

```text
Cons("tea", Cons("milk", Nil))
2
```

## Step 3: Generic impl blocks
Kind: fix (start gives E0214 "a generic `impl` names its type parameters after `impl`", help "write `impl<T: Num> Stack<T>`")

Methods for a generic type go in an `impl` block that names its parameter after `impl`, as `impl<T> Stack<T>` on line 3 does.
There `T` stands for the element type, and `Self` for `Stack<T>`.
Line 23's `Stack<i64>` fills in `T` for `Stack.new()`, as `: string[]` did for `empty`.
A second block on line 18 adds a bound, so that `total` exists only for stacks of numbers, but writes `T`, with its bound, inside `Stack<…>` rather than after `impl`.
Press Run.

E0214: "a generic `impl` names its type parameters after `impl`", bounds included.
Change line 18 to `impl<T: Num> Stack<T> {`, or press Solve.
`total`'s `0` is a `T`, as `Num` allows, and calling `total` on `words` would be E0419, "`string` doesn't satisfy `Num`", the code for a built-in type that misses a bound.

Start:

```lugha
struct Stack<T> { items: T[] }

impl<T> Stack<T> {
    fun new(): Self = Self { items: [] };

    fun push(mut self, item: T) {
        self.items.push(item);
    }

    fun top(self): Option<T> {
        if self.items.len == 0 {
            return None;
        }
        Some(self.items[self.items.len - 1])
    }
}

impl Stack<T: Num> {
    fun total(self): T = self.items.fold(0, fun(sum, x) = sum + x);
}

fun main(console: Console) {
    let mut numbers: Stack<i64> = Stack.new();
    numbers.push(3);
    numbers.push(4);
    console.println(numbers.top().debug());
    console.println(numbers.total());
    let mut words: Stack<string> = Stack.new();
    words.push("tea");
    console.println(words.top().debug());
}
```

Solution:

```lugha
struct Stack<T> { items: T[] }

impl<T> Stack<T> {
    fun new(): Self = Self { items: [] };

    fun push(mut self, item: T) {
        self.items.push(item);
    }

    fun top(self): Option<T> {
        if self.items.len == 0 {
            return None;
        }
        Some(self.items[self.items.len - 1])
    }
}

impl<T: Num> Stack<T> {
    fun total(self): T = self.items.fold(0, fun(sum, x) = sum + x);
}

fun main(console: Console) {
    let mut numbers: Stack<i64> = Stack.new();
    numbers.push(3);
    numbers.push(4);
    console.println(numbers.top().debug());
    console.println(numbers.total());
    let mut words: Stack<string> = Stack.new();
    words.push("tea");
    console.println(words.top().debug());
}
```

Output (solution):

```text
Some(4)
7
Some("tea")
```
